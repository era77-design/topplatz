Installing npm, the Node.js package manager, is typically done by installing Node.js itself, as npm comes bundled with it. This guide will walk you through the process for various operating systems, ensuring you can manage your JavaScript projects effortlessly.

## What You Need

- Internet connection
- Administrator/sudo privileges
- Terminal or Command Prompt

## Steps

### Step 1: Understand npm and Node.js Bundling

npm (Node Package Manager) is the default package manager for Node.js. It comes pre-installed when you install Node.js, meaning you typically don't install npm separately. Therefore, the primary step to get npm is to install Node.js on your system.

### Step 2: Download the Node.js Installer

Visit the official Node.js website (nodejs.org) and download the appropriate installer for your operating system. It's generally recommended to choose the LTS (Long Term Support) version, as it's more stable and maintained for most development needs.

### Step 3: Run the Node.js Installation Wizard (Windows/macOS)

For Windows and macOS, simply run the downloaded `.msi` or `.pkg` file. Follow the prompts in the installation wizard, accepting the license agreement and choosing the default installation options. This process will install both Node.js and npm on your system, making them available from your command line.

> 💡 **Tip:** Ensure you have administrator privileges to complete the installation successfully, especially on Windows.

### Step 4: Install Node.js on Linux (Ubuntu/Debian)

For Linux distributions like Ubuntu, it's often best to use a package manager. First, update your package list by running: `sudo apt update`. Then, install Node.js and npm using: `sudo apt install nodejs npm`. This method ensures you get the versions available in your distribution's repositories. For more detailed OS-specific instructions, refer to [How to Install npm: A Step-by-Step Guide for All OS](/en/how-to-install-npm).

### Step 5: Verify Your npm and Node.js Installation

After the installation is complete, open your terminal or command prompt. Type `node -v` and press Enter to check the Node.js version. Then, type `npm -v` and press Enter to check the npm version. Both commands should return version numbers, confirming a successful installation and proper path configuration.

### Step 6: Update npm to the Latest Version (Optional)

While npm comes bundled with Node.js, it might not always be the absolute latest version. To update npm to its newest stable release, run the command: `npm install -g npm@latest`. The `-g` flag ensures it's installed globally across your system.

> 💡 **Tip:** Regularly updating npm can provide access to new features, performance improvements, and important security patches.


## Tips & Tricks

- Always use the LTS (Long Term Support) version of Node.js for production environments due to its stability and extended maintenance.
- Consider using `nvm` (Node Version Manager) if you need to switch between different Node.js and npm versions frequently for various projects.
- Understand the difference between global (`npm install -g`) and local (`npm install`) package installation. Global packages are available system-wide, while local packages are specific to a project directory.

## Warnings

- ⚠️ Always download Node.js installers from the official website (nodejs.org) to ensure authenticity and avoid potential malware.
- ⚠️ Running `npm install -g` commands requires administrator or sudo privileges. Be cautious about what you install globally, as it can affect your entire system.

## Frequently Asked Questions

**What is npm and why do I need it?**

npm stands for Node Package Manager, and it's the world's largest software registry. Developers use npm to share and reuse code, manage project dependencies, and automate development tasks. It's essential for virtually any modern JavaScript project.

**Do I need to install Node.js before installing npm?**

Yes, npm is automatically installed when you install Node.js. You do not typically install npm as a separate standalone package. Therefore, the first step to getting npm is always to install Node.js.

**How to install npm in Windows?**

To install npm in Windows, you simply download the Node.js `.msi` installer from the official Node.js website and run it. The installer will guide you through the process, and npm will be included automatically with your Node.js installation.

**How to install npm on Mac?**

Installing npm on a Mac involves downloading the Node.js `.pkg` installer from the Node.js website. Run the installer, follow the on-screen instructions, and both Node.js and npm will be set up on your system, ready for use in your terminal.

**How to install npm on Ubuntu?**

To install npm on Ubuntu, open your terminal and run `sudo apt update` followed by `sudo apt install nodejs npm`. This will install Node.js and npm from Ubuntu's default repositories. For newer versions, consider using NodeSource repositories.

**How do I check if npm is installed correctly?**

Open your terminal or command prompt and type `npm -v`. If npm is installed correctly, it will display the version number. If it's not installed or not found, you'll receive an error message indicating it's not recognized.

**Can I update npm without updating Node.js?**

Yes, you can update npm independently of Node.js. Open your terminal and run `npm install -g npm@latest`. This command will update your global npm installation to the newest stable version available without affecting your Node.js version.

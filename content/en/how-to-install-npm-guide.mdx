To install npm, you primarily need to install Node.js, as npm (Node Package Manager) comes bundled with every Node.js installation. This process typically involves downloading an official installer for Windows and macOS, or using a package manager for Linux distributions like Ubuntu, ensuring you get the latest stable versions of both. For a more in-depth, platform-specific guide, you can refer to our article: [How to Install npm: Step-by-Step for Windows, Mac & Linux](/en/how-to-install-npm-windows-mac-linux).

## What You Need

- Computer with internet access
- Administrator privileges
- Web browser
- Terminal or Command Prompt

## Steps

### Step 1: Check for Existing Node.js and npm Installation

Before you begin, it's a good practice to check if Node.js and npm are already installed on your system. Open your terminal (macOS/Linux) or Command Prompt (Windows) and type `node -v` and then `npm -v`. If version numbers are displayed, they are installed. If you receive an error or no output, you can proceed with the installation.

### Step 2: Download Node.js Installer (Windows & macOS)

Navigate to the official Node.js website (nodejs.org) in your web browser. You'll typically see two recommended versions: the LTS (Long Term Support) version and the Current version. For most users, the LTS version is highly recommended for its stability. Download the appropriate installer (.msi for Windows, .pkg for macOS) for your operating system.

### Step 3: Install Node.js (Windows & macOS)

Locate the downloaded Node.js installer file and run it. Follow the on-screen prompts, accepting the license agreement and the default installation settings. It's generally safe to keep all components selected, as this ensures npm is also installed alongside Node.js. The installer will guide you through the process until completion.

> 💡 **Tip:** Ensure you have administrator rights on your system to complete the installation successfully.

### Step 4: Install Node.js on Linux (Ubuntu/Debian)

For Ubuntu and Debian-based systems, it's recommended to use NodeSource repositories for the latest stable versions. First, update your package list with `sudo apt update`. Then, follow the NodeSource instructions to add their PPA, and finally install Node.js (which includes npm) by running `sudo apt install nodejs`. This command automatically handles the npm dependency.

> 💡 **Tip:** Other Linux distributions might use different package managers like `yum` or `dnf`. Refer to their specific documentation for installation commands.

### Step 5: Verify the Installation

After the installation is complete for your operating system, reopen your terminal or Command Prompt to ensure the system path is updated. Run `node -v` and `npm -v` again. You should now see the version numbers for both Node.js and npm, confirming a successful installation. If you encounter issues, try restarting your computer.

### Step 6: Update npm to the Latest Version

While npm is installed with Node.js, it often receives updates independently. To ensure you have the very latest stable version of npm, run the command `npm install -g npm@latest` in your terminal or command prompt. The `-g` flag ensures it's installed globally on your system, making it available for all your projects.

> 💡 **Tip:** Regularly updating npm helps you access new features, performance improvements, and important bug fixes.


## Tips & Tricks

- Always download Node.js from the official website (nodejs.org) to ensure authenticity and security.
- The LTS (Long Term Support) version of Node.js is generally recommended for production environments due to its stability and longer maintenance period.
- If you encounter permission errors on Linux or macOS when using `npm`, try prepending `sudo` to your `npm` commands (e.g., `sudo npm install -g <package>`), but use it sparingly and understand its implications.
- Consider using a Node Version Manager (like `nvm` for macOS/Linux or `nvm-windows` for Windows) if you need to switch between different Node.js versions frequently for various projects.

## Warnings

- ⚠️ Ensure you have a stable internet connection during the download and installation process to prevent corrupted files.
- ⚠️ Always use administrator or root privileges when installing system-wide software like Node.js to avoid installation failures.
- ⚠️ Be cautious when installing packages globally with `npm install -g` as they can sometimes conflict with other system-level tools or require elevated permissions.

## Frequently Asked Questions

**How to install npm in Windows?**

To install npm in Windows, you need to download and run the Node.js `.msi` installer from the official nodejs.org website. npm comes bundled with Node.js, so once Node.js is successfully installed, npm will also be available for use in your Command Prompt or PowerShell.

**How to install npm on Mac?**

Installing npm on Mac involves downloading the Node.js `.pkg` installer from nodejs.org and following the straightforward installation wizard. Alternatively, experienced users can utilize Homebrew by running `brew install node` in the terminal, which conveniently installs both Node.js and npm.

**How to install npm in Ubuntu?**

To install npm in Ubuntu, the recommended method is to use NodeSource repositories for the latest stable versions. First, update your package list with `sudo apt update`, then add the NodeSource PPA, and finally install Node.js (which includes npm) using `sudo apt install nodejs`.

**What is npm and why do I need it?**

npm stands for Node Package Manager, and it's the default package manager for JavaScript's runtime Node.js. You need it to easily install, manage, and share reusable code packages (libraries, frameworks, tools) for your Node.js projects, significantly streamlining development workflows.

**What if I already have Node.js installed?**

If you already have Node.js installed, npm should also be available on your system. You can verify their versions by running `node -v` and `npm -v` in your terminal. If your npm version is outdated, you can update it separately using the command `npm install -g npm@latest`.

**How do I update npm to the latest version?**

To update npm to its latest stable version, simply open your terminal or command prompt and execute the command `npm install -g npm@latest`. This command globally updates npm across your system without directly affecting your existing Node.js installation.

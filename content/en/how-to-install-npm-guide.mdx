npm (Node Package Manager) is the default package manager for Node.js, essential for managing project dependencies and sharing code. Installing npm typically involves installing Node.js, as npm is bundled with it. This guide will walk you through the process on various operating systems.

## What You Need

- Computer (Windows, macOS, or Linux)
- Internet connection
- Administrator/sudo privileges

## Steps

### Step 1: Understand npm and Node.js

Before you begin, it's important to know that npm comes bundled with Node.js. Therefore, installing Node.js is the primary step to get npm on your system. Node.js is a JavaScript runtime environment that allows you to run JavaScript code outside of a web browser, and npm is its package manager for installing and managing libraries.

> 💡 **Tip:** For a more in-depth understanding, you can refer to a complete guide on [How to Install npm: A Complete Guide for Developers](/en/how-to-install-npm).

### Step 2: Install Node.js (and npm) on Windows

For Windows users, the simplest method is to download the official Node.js installer from the Node.js website (nodejs.org). Choose the LTS (Long Term Support) version, as it's the most stable. Run the .msi installer and follow the on-screen prompts, accepting the default installation options. This will install both Node.js and npm.

> 💡 **Tip:** Ensure you have administrator privileges to run the installer successfully.

### Step 3: Install Node.js (and npm) on macOS

Mac users can also download the official .pkg installer from the Node.js website and follow the installation wizard. Alternatively, Homebrew, a popular package manager for macOS, provides a convenient way to install Node.js. Open your terminal and run `brew install node` to install both Node.js and npm.

> 💡 **Tip:** If you don't have Homebrew, install it first by following instructions on brew.sh.

### Step 4: Install Node.js (and npm) on Linux (Ubuntu/Debian)

For Ubuntu or Debian-based systems, it's recommended to use the NodeSource PPA to get the latest stable versions. First, update your package list with `sudo apt update`. Then, add the NodeSource PPA (e.g., `curl -fsSL https://deb.nodesource.com/setup_lts.x | sudo -E bash -`) and finally install Node.js with `sudo apt install nodejs`. This command installs both Node.js and npm.

> 💡 **Tip:** Replace `lts.x` with the specific LTS version number if you need a non-latest LTS release.

### Step 5: Verify Node.js and npm Installation

After the installation is complete, open your terminal or command prompt to verify that both Node.js and npm were installed correctly. Type `node -v` and press Enter to check the Node.js version. Then, type `npm -v` and press Enter to check the npm version. You should see version numbers displayed for both.

> 💡 **Tip:** If you receive 'command not found' errors, try restarting your terminal or computer, or check your system's PATH environment variable.

### Step 6: Update npm to the Latest Version (Optional)

While npm is installed with Node.js, its version might not be the absolute latest. It's often a good practice to update npm independently. You can do this by running `npm install -g npm@latest` in your terminal. The `-g` flag ensures npm is installed globally, making it available for all your projects.

> 💡 **Tip:** Regularly updating npm can provide access to new features, bug fixes, and security enhancements.

### Step 7: Install Your First npm Package

To confirm npm is fully functional, try installing a simple package. For example, you can install a global utility like `nodemon` which automatically restarts your Node.js application. Run `npm install -g nodemon` in your terminal. This command downloads and installs the `nodemon` package globally, making it available from any directory.

> 💡 **Tip:** Always be mindful of global vs. local package installations. Most project-specific dependencies should be installed locally without the `-g` flag.


## Tips & Tricks

- Always use the LTS (Long Term Support) version of Node.js for production environments, as it offers the most stability and support.
- Consider using a Node Version Manager (NVM) like `nvm` for Linux/macOS or `nvm-windows` for Windows. This allows you to easily switch between different Node.js and npm versions for various projects.
- Before running `npm install` in a project, always ensure you have a `package.json` file. This file lists all the project's dependencies.

## Warnings

- ⚠️ Always download installers from the official Node.js website (nodejs.org) to avoid potential security risks.
- ⚠️ When using `sudo` or administrator privileges, be cautious as these commands can make system-wide changes.
- ⚠️ Ensure your system's PATH variable is correctly configured if Node.js or npm commands are not recognized after installation.

## Frequently Asked Questions

**What is npm and why do I need it?**

npm (Node Package Manager) is the default package manager for Node.js, used for installing, sharing, and managing code packages. You need it to handle project dependencies, making it easy to integrate and reuse code from other developers.

**How to install npm in Windows?**

To install npm in Windows, download and run the official Node.js `.msi` installer from nodejs.org. npm is bundled with Node.js, so installing Node.js will automatically install npm on your system.

**How to install npm on Mac?**

You can install npm on Mac by downloading the official Node.js `.pkg` installer from nodejs.org, or by using Homebrew. With Homebrew, open your terminal and run `brew install node`, which installs both Node.js and npm.

**How to install npm on Ubuntu?**

To install npm on Ubuntu, use the NodeSource PPA for the latest stable version. First, update your package list, then add the NodeSource PPA, and finally run `sudo apt install nodejs` in your terminal to install both Node.js and npm.

**How do I verify if npm is installed correctly?**

After installation, open your terminal or command prompt and type `npm -v`. If npm is installed correctly, you will see its version number displayed, confirming a successful installation.

**Can I update npm separately from Node.js?**

Yes, you can update npm independently of Node.js. To update npm to its latest version, open your terminal and run the command `npm install -g npm@latest`.

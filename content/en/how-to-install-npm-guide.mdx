Installing npm (Node Package Manager) is typically done by installing Node.js, as npm is bundled with it. This guide will walk you through the most straightforward methods to get npm up and running on your system, whether you're on Windows, macOS, or a Linux distribution. You'll be ready to manage your JavaScript packages in no time.

## What You Need

- Computer with internet access
- Administrator/sudo privileges
- Command Line Interface (CLI)

## Steps

### Step 1: Check for Existing Node.js and npm

Before proceeding, it's good practice to check if Node.js and npm are already installed on your system. Open your terminal or command prompt and run `node -v` and `npm -v`. If you see version numbers, they are installed. If not, or if you get a 'command not found' error, you'll need to install them.

### Step 2: Download the Official Node.js Installer

The easiest and most recommended way to install npm is by installing Node.js, as npm comes bundled with it. Visit the official Node.js website (nodejs.org) and download the 'LTS' (Long Term Support) version appropriate for your operating system (Windows, macOS). The LTS version is stable and recommended for most users.

> 💡 **Tip:** Ensure you download the correct architecture (e.g., x64) for your system.

### Step 3: Run the Node.js Installer

Locate the downloaded installer file (e.g., `.msi` for Windows, `.pkg` for macOS) and run it. Follow the on-screen prompts, accepting the license agreement and default installation settings. The installer will automatically set up Node.js and npm, and configure necessary PATH variables so they are accessible from your command line.

### Step 4: Verify the Installation

After the installation completes, close and reopen your terminal or command prompt to ensure the PATH changes are loaded. Then, run `node -v` and `npm -v` again. You should now see the installed version numbers for both Node.js and npm, confirming a successful installation. If you encounter issues, restart your computer and try again.

### Step 5: Update npm to the Latest Version

While npm is installed with Node.js, it's often beneficial to update npm itself to its latest stable version independently. Open your terminal or command prompt and execute the command: `npm install -g npm@latest`. This command globally installs the newest npm version, ensuring you have access to the latest features and bug fixes.

> 💡 **Tip:** On macOS or Linux, you might need to use `sudo npm install -g npm@latest` if you encounter permission errors.

### Step 6: Explore npm Usage

With npm successfully installed, you're ready to start managing JavaScript packages. You can now install project dependencies using `npm install [package-name]`, initialize new projects with `npm init`, and run scripts defined in your `package.json` file. Explore the npm documentation for a deeper dive into its capabilities. For more detailed instructions on specific platforms, check out our [How to Install npm: A Complete Guide for All Platforms](/en/how-to-install-npm).


## Tips & Tricks

- Always use the LTS (Long Term Support) version of Node.js for stability in production environments.
- If you're managing multiple Node.js versions, consider using a version manager like `nvm` (Node Version Manager) for easier switching between them.
- Regularly update npm to ensure you have the latest features and security patches by running `npm install -g npm@latest`.

## Warnings

- ⚠️ Avoid installing Node.js and npm using `sudo` directly on Linux/macOS unless absolutely necessary, as it can lead to permission issues. Use `nvm` or ensure your user has proper permissions.

## Frequently Asked Questions

**How to install npm in Windows?**

The simplest way to install npm in Windows is by downloading and running the official Node.js installer from nodejs.org. This installer bundles npm and automatically configures your system PATH. After installation, restart your command prompt and verify with `npm -v`.

**How to install npm on Mac?**

To install npm on Mac, download the macOS installer from the official Node.js website (nodejs.org) and follow the installation wizard. Alternatively, for more flexibility, consider using Homebrew with `brew install node` or a Node.js version manager like `nvm`.

**How to install npm on Ubuntu?**

On Ubuntu, you can install npm by first installing Node.js. The recommended method is to use NodeSource repositories for the latest versions: `curl -fsSL https://deb.nodesource.com/setup_lts.x | sudo -E bash -` followed by `sudo apt-get install -y nodejs`. This will install both Node.js and npm.

**Is npm automatically installed with Node.js?**

Yes, npm (Node Package Manager) is automatically bundled and installed alongside Node.js when you use the official Node.js installers or most package managers. This ensures you have the necessary tools to manage JavaScript packages right after installing Node.js.

**How can I check if npm is already installed?**

To check if npm is installed, open your terminal or command prompt and type `npm -v`. If npm is installed, it will display its version number. If it's not installed, you'll typically receive a 'command not found' error message.

**What is the difference between Node.js and npm?**

Node.js is a JavaScript runtime environment that allows you to execute JavaScript code outside of a web browser. npm, or Node Package Manager, is the default package manager for Node.js, used to install, share, and manage project dependencies and packages.

**Do I need to update npm separately after installing Node.js?**

While npm is installed with Node.js, it's often a good practice to update npm to its latest version independently. You can do this by running `npm install -g npm@latest` in your terminal, which ensures you have the most current features and bug fixes.

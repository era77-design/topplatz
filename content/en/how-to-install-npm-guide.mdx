To install npm, you first need to install Node.js, as npm is bundled with it. Download the appropriate Node.js installer for your operating system (Windows, macOS, or Linux) from the official Node.js website and follow the installation prompts. After successful installation, verify both Node.js and npm versions in your terminal.

## What You Need

- Computer with internet access
- Command Line Interface (CLI) / Terminal

## Steps

### Step 1: Understand Node.js and npm

Before you begin, it's important to understand that npm (Node Package Manager) is automatically installed when you install Node.js. Node.js is a JavaScript runtime built on Chrome's V8 JavaScript engine, allowing you to run JavaScript on the server side. npm is the default package manager for Node.js, used for managing project dependencies and sharing tools.

### Step 2: Download Node.js Installer

Visit the official Node.js website (nodejs.org) to download the appropriate installer for your operating system. It's highly recommended to download the LTS (Long Term Support) version, which is stable and receives continuous updates. Choose the installer package that matches your Windows, macOS, or Linux architecture (e.g., 64-bit).

### Step 3: Install Node.js (and npm)

Run the downloaded Node.js installer. For Windows and macOS, simply follow the on-screen prompts, accepting the default installation options. The installer will automatically add Node.js and npm to your system's PATH environment variable. For Linux, you might use a package manager like `apt` or `yum` (see FAQ for OS-specific details), or compile from source. Ensure the installation completes without errors.

> 💡 **Tip:** Accepting default installation options usually works best for most users. This ensures all necessary components, including npm, are installed correctly.

### Step 4: Verify Node.js and npm Installation

After the installation is complete, open your Command Line Interface (CLI) or Terminal. To verify that Node.js is installed, type `node -v` and press Enter. To verify npm, type `npm -v` and press Enter. You should see version numbers displayed for both, confirming successful installation. If you encounter errors like 'command not found', you might need to restart your terminal or check your system's PATH variable.

### Step 5: Update npm to the Latest Version (Recommended)

While npm is installed with Node.js, it's often a slightly older version. To ensure you have the latest features and security updates, it's good practice to update npm itself. In your terminal, run the command `npm install -g npm@latest`. The `-g` flag means it will be installed globally, making the latest npm version available system-wide. You might need administrator privileges for this command.

> 💡 **Tip:** Keeping npm updated helps prevent compatibility issues with newer packages and ensures you benefit from performance improvements and bug fixes.

### Step 6: Start Using npm for Your Projects

With npm successfully installed and updated, you're ready to start using it for your development projects. You can initialize a new project with `npm init`, install packages with `npm install <package-name>`, and run scripts defined in your `package.json` file. Explore the vast npm registry to find packages that suit your needs. For more detailed guides on specific operating systems, refer to our comprehensive resources like [How to Install npm: A Step-by-Step Guide for All OS](/en/how-to-install-npm).


## Tips & Tricks

- Always prefer the LTS (Long Term Support) version of Node.js for production environments, as it offers greater stability and reliability.
- Regularly update npm to its latest version to leverage new features, performance improvements, and critical security patches.
- Understand the difference between global (`npm install -g`) and local (`npm install`) package installations. Global packages are tools available system-wide, while local packages are project-specific dependencies.

## Warnings

- ⚠️ Always download Node.js installers from the official nodejs.org website to prevent malware or corrupted files.
- ⚠️ Be cautious when using `sudo` (Linux/macOS) or running your terminal as an administrator (Windows) for npm commands. Only use elevated privileges when absolutely necessary, especially for global installations, to avoid potential system-wide issues.

## Frequently Asked Questions

**How do I install npm in Windows?**

To install npm in Windows, download the official Node.js .msi installer from nodejs.org. Run the installer and follow the prompts, accepting the default options. npm will be installed automatically along with Node.js and added to your system's PATH.

**How do I install npm on Mac?**

On a Mac, you can install npm by downloading the Node.js .pkg installer from nodejs.org and running it. Alternatively, you can use Homebrew with the command `brew install node`, which will install both Node.js and npm.

**How do I install npm on Ubuntu?**

To install npm on Ubuntu, it's recommended to use a Node Version Manager (NVM) or the official Node.js PPA. For a quick install, you can use `sudo apt update && sudo apt install nodejs npm`. However, for more control and newer versions, NVM is preferred.

**Why is npm installed with Node.js?**

npm is the default package manager for Node.js and is essential for managing Node.js project dependencies. Because of its integral role in the Node.js ecosystem, it is bundled directly with the Node.js installer to ensure users have immediate access to package management functionalities upon installation.

**What should I do if `npm -v` shows an error?**

If `npm -v` shows an error like 'command not found', first restart your terminal or command prompt. If the issue persists, verify that Node.js was installed correctly and that its installation directory is included in your system's PATH environment variable. Reinstalling Node.js is often a quick fix.

**Can I install npm without Node.js?**

No, you cannot install npm without Node.js. npm is the Node Package Manager, and it requires Node.js to function. It is bundled as part of the Node.js installation package, so installing Node.js inherently installs npm.

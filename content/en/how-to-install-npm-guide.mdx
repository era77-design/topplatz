Installing npm (Node Package Manager) is typically done by installing Node.js, as npm is bundled with it. This guide will walk you through the process of downloading and installing Node.js, which automatically provides you with npm.

## What You Need

- Computer with internet access
- Administrator privileges (for installation)

## Steps

### Step 1: Check for Existing Node.js and npm Installation

Before you begin, it's a good practice to check if Node.js and npm are already installed on your system. Open your terminal or command prompt and type `node -v` and then `npm -v`. If versions are displayed, they are installed. If not, or if the versions are very old, proceed with the installation.

### Step 2: Download the Node.js Installer

Navigate to the official Node.js website (nodejs.org) in your web browser. You'll typically see two download options: the LTS (Long Term Support) version and the Current version. For most users, the LTS version is recommended as it's more stable and thoroughly tested. Download the installer appropriate for your operating system (Windows, macOS, or Linux).

### Step 3: Run the Node.js Installer

Once the download is complete, locate the installer file (e.g., `.msi` for Windows, `.pkg` for macOS, or a tarball for Linux). Double-click the installer to begin the installation process. You might need to grant administrator permissions for the installer to run.

> 💡 **Tip:** Close any open terminals or command prompts before running the installer to ensure the environment variables are updated correctly after installation.

### Step 4: Follow the Installation Wizard Prompts

The installer will guide you through several steps. It's generally safe to accept the default settings for most users. These defaults include installing Node.js runtime, npm package manager, and adding to PATH. Click 'Next' or 'Continue' through the license agreement, destination folder, and setup type.

### Step 5: Complete the Installation

Once you've made your selections, click 'Install' to begin copying the files. The installation process usually takes a few minutes. After it's complete, click 'Finish' or 'Close' to exit the installer.

### Step 6: Verify the Installation

Open a *new* terminal or command prompt window. This is important because the environment variables need to refresh. Type `node -v` and press Enter. Then, type `npm -v` and press Enter. You should now see the version numbers for both Node.js and npm, confirming a successful installation.

### Step 7: Update npm (Optional but Recommended)

Even though npm is installed with Node.js, it's often updated more frequently. To ensure you have the latest stable version of npm, run the command `npm install -g npm@latest` in your terminal. This command globally updates npm to its newest available version, providing access to the latest features and bug fixes.


## Tips & Tricks

- Always use the LTS (Long Term Support) version of Node.js for production environments, as it offers greater stability and longer maintenance periods.
- If you encounter permission errors during npm package installation, try running your terminal or command prompt as an administrator.
- Consider using a Node Version Manager (like nvm for macOS/Linux or nvm-windows) if you need to switch between different Node.js and npm versions for various projects.

## Warnings

- ⚠️ Ensure you have sufficient administrator or root privileges to install software on your system, otherwise the installation may fail.
- ⚠️ If you have an existing, very old version of Node.js and npm, consider uninstalling it before installing a new version to prevent potential conflicts, especially on Windows.

## Frequently Asked Questions

**How to install npm in Windows?**

To install npm in Windows, you simply download the `.msi` installer for Node.js from the official Node.js website (nodejs.org). Run the installer and follow the prompts, accepting the default options. Node.js comes bundled with npm, so installing Node.js automatically installs npm for you. For more detailed platform-specific instructions, see [How to Install npm: Step-by-Step for Windows, Mac & Linux](/en/how-to-install-npm-windows-mac-linux).

**How to install npm on Mac?**

Installing npm on Mac involves downloading the `.pkg` installer from nodejs.org. Execute the installer and proceed through the installation wizard, which will set up both Node.js and npm on your macOS system. After installation, open a new terminal to verify by typing `node -v` and `npm -v`.

**How to install npm on Ubuntu?**

On Ubuntu, the recommended way to install npm is by first installing Node.js. You can do this via your package manager. For instance, you might use `sudo apt update`, then `sudo apt install nodejs npm` or use a Node.js version manager like `nvm` for more flexibility. This method ensures both Node.js and npm are correctly set up on your Ubuntu system. For specific commands and other Linux distributions, refer to [How to Install npm: Step-by-Step Guide for All OS](/en/how-to-install-npm-guide-all-os).

**Do I need Node.js to install npm?**

Yes, npm (Node Package Manager) is distributed with Node.js. The most common and recommended way to get npm is by installing Node.js. When you install Node.js, npm is automatically included and set up on your system, ready for use.

**How do I check if npm is installed correctly?**

After installation, open a new terminal or command prompt window. Type `npm -v` and press Enter. If you see a version number displayed (e.g., `8.1.2`), then npm is installed correctly and is accessible from your system's PATH.

**What is npm used for?**

npm is the default package manager for Node.js and the world's largest software registry. It's used to install, manage, and share JavaScript packages (libraries, frameworks, tools) for your projects. Developers use it to easily add external dependencies to their applications and manage project-specific packages.

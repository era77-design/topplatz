Installing npm, the Node Package Manager, is typically done by installing Node.js, which bundles npm with it. This process is straightforward and works across various operating systems like Windows, macOS, and Linux, enabling you to manage JavaScript packages efficiently for your projects.

## What You Need

- Internet connection
- Administrator/sudo privileges
- Web browser
- Terminal or Command Prompt

## Steps

### Step 1: Step 1: Check for Existing Node.js and npm Installation

Before starting, it's a good idea to check if Node.js and npm are already installed on your system. Open your terminal (macOS/Linux) or Command Prompt/PowerShell (Windows) and type `node -v` and then `npm -v`. If you see version numbers, you already have them installed. If not, or if the versions are very old, proceed with the installation.

> 💡 **Tip:** If you see version numbers, you might only need to update npm, which can be done with `npm install -g npm@latest`.

### Step 2: Step 2: Download the Node.js Installer

The simplest way to install npm is to install Node.js, as npm comes bundled with it. Visit the official Node.js website (nodejs.org) in your web browser. You'll typically see two recommended versions: an LTS (Long Term Support) version and a Current version. For most users, the LTS version is recommended for stability. Download the installer package appropriate for your operating system (Windows, macOS).

> 💡 **Tip:** The website automatically detects your OS, making it easy to choose the correct download.

### Step 3: Step 3: Install Node.js on Windows or macOS

Once the installer file is downloaded, locate it in your Downloads folder and double-click to run it. Follow the on-screen prompts, accepting the license agreement and clicking 'Next' through the installation wizard. It's generally safe to accept the default installation settings, which include Node.js runtime, npm package manager, and add to PATH. Complete the installation, then restart your terminal or command prompt.

> 💡 **Tip:** Ensure 'Add to PATH' is checked during installation to make Node.js and npm commands accessible from any directory.

### Step 4: Step 4: Install Node.js on Linux (e.g., Ubuntu)

For Linux distributions like Ubuntu, it's often best to use your system's package manager. First, update your package list: `sudo apt update`. Then, you can install Node.js and npm with `sudo apt install nodejs npm`. Alternatively, for the latest LTS version, consider using NodeSource repositories for more up-to-date packages. For a comprehensive guide, see [How to Install npm: A Complete Guide for All OS](/en/how-to-install-npm-complete-guide).

> 💡 **Tip:** Using NodeSource ensures you get a more recent and officially supported version of Node.js than what might be in your distribution's default repositories.

### Step 5: Step 5: Verify the Installation

After the installation is complete, open a new terminal or command prompt window. Type `node -v` and press Enter. You should see the installed Node.js version. Then, type `npm -v` and press Enter. You should see the npm version. If both commands return version numbers, Node.js and npm have been successfully installed and are ready for use.

> 💡 **Tip:** If you encounter a 'command not found' error, ensure Node.js was added to your system's PATH environment variable and that you opened a new terminal session.

### Step 6: Step 6: Update npm (Optional but Recommended)

While npm is bundled with Node.js, it's often updated more frequently. To ensure you have the latest version of npm, you can update it independently. Open your terminal or command prompt and run the command: `npm install -g npm@latest`. The `-g` flag means it will be installed globally, making it available system-wide.

> 💡 **Tip:** Keeping npm updated helps you access the latest features and bug fixes, improving your package management experience.


## Tips & Tricks

- **Use NVM for Version Management:** If you work on multiple projects that require different Node.js versions, consider using Node Version Manager (NVM). It allows you to easily switch between Node.js and npm versions.
- **Understand npm's Role:** npm is crucial for JavaScript development, allowing you to install, manage, and share packages (libraries, frameworks, tools) for your projects.
- **Troubleshoot PATH Issues:** If `node -v` or `npm -v` don't work, verify that the Node.js installation directory is included in your system's PATH environment variable.

## Warnings

- ⚠️ Always download installers from the official Node.js website (nodejs.org) to avoid malware or outdated versions.
- ⚠️ Ensure you have administrator (Windows) or sudo (Linux/macOS) privileges to install software system-wide.

## Frequently Asked Questions

**How do I install npm in Windows?**

To install npm in Windows, download the Node.js `.msi` installer from the official Node.js website (nodejs.org). Run the installer and follow the prompts, accepting default settings. npm is bundled with Node.js and will be installed automatically.

**How do I install npm on Mac?**

Installing npm on Mac involves downloading the Node.js `.pkg` installer from nodejs.org. Execute the package installer, follow the instructions, and accept the default options to install both Node.js and npm on your macOS system.

**How do I install npm on Ubuntu?**

You can install npm on Ubuntu by first updating your package list with `sudo apt update`, then running `sudo apt install nodejs npm`. For the latest versions, consider using NodeSource repositories.

**What is npm and why do I need it?**

npm (Node Package Manager) is the default package manager for Node.js. You need it to install, update, and manage JavaScript packages (libraries, frameworks, tools) that your projects depend on, making development more efficient and organized.

**Can I install npm without Node.js?**

While it's technically possible to install npm separately, it's highly recommended to install Node.js, as npm is typically bundled with it and designed to work in conjunction with the Node.js runtime. Installing Node.js is the standard and easiest method.

**How do I update npm to the latest version?**

To update npm to its latest version, open your terminal or command prompt and execute the command `npm install -g npm@latest`. This command globally installs the most recent stable version of npm on your system.

**What should I do if `npm -v` shows "command not found"?**

If `npm -v` returns "command not found," it likely means Node.js and npm were not added to your system's PATH environment variable, or your terminal session wasn't refreshed. Try opening a new terminal window or, if the issue persists, manually add the Node.js installation directory to your PATH.

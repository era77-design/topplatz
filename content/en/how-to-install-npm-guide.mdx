To install npm, you typically install Node.js, which bundles npm automatically. Download the appropriate Node.js installer for your operating system from the official Node.js website and follow the installation prompts. After installation, you can verify npm by running a simple command in your terminal. For a more detailed breakdown specific to your operating system, refer to our comprehensive guide: [How to Install npm: Step-by-Step Guide for All OS](/en/how-to-install-npm-guide-all-os).

## What You Need

- A computer (Windows, macOS, or Linux)
- Internet connection
- Administrator or sudo privileges

## Steps

### Step 1: Download the Node.js Installer

Begin by visiting the official Node.js website (nodejs.org). On the homepage, you'll see two download options: the LTS (Long Term Support) version and the Current version. The LTS version is recommended for most users due to its stability and ongoing support, while the Current version includes the latest features. Choose the installer appropriate for your operating system (Windows, macOS, or Linux).

> 💡 **Tip:** Always download Node.js from the official website to ensure you get a legitimate and secure version.

### Step 2: Run the Node.js Installer

Once the download is complete, locate the installer file in your downloads folder and double-click it to begin the installation process. For Windows, this will be an .msi file; for macOS, a .pkg file. On Linux, you might use a package manager or a pre-compiled binary, but the Node.js website often provides instructions for direct installation.

> 💡 **Tip:** Ensure you have administrator rights or sudo privileges to run the installer successfully, as it needs to modify system files.

### Step 3: Follow the Installation Wizard

The installer wizard will guide you through several steps. Generally, you can accept the default settings for most options. This includes agreeing to the license agreement, choosing the installation destination folder, and selecting the components to install. Crucially, ensure that "Node.js runtime" and "npm package manager" are selected, as npm is bundled with Node.js.

> 💡 **Tip:** It's usually safe to keep the default installation path, but you can change it if you have specific system organization preferences.

### Step 4: Complete the Installation

Click "Install" to begin the file transfer and configuration process. This may take a few minutes depending on your system speed. Once completed, you will see a confirmation message indicating that Node.js and npm have been successfully installed. Click "Finish" to exit the installer.

> 💡 **Tip:** If prompted, restart your computer after installation to ensure all environment variables are correctly updated, especially on Windows.

### Step 5: Verify Node.js and npm Installation

Open your terminal or command prompt (on Windows, Mac, or Linux). Type `node -v` and press Enter. This command should display the installed Node.js version. Next, type `npm -v` and press Enter. This will show the installed npm version. If both commands return version numbers, Node.js and npm are successfully installed and configured.

> 💡 **Tip:** If the commands don't work, try closing and reopening your terminal, or restarting your computer, to refresh the system's PATH environment variable.

### Step 6: Update npm (Optional but Recommended)

While npm comes bundled with Node.js, it's often updated more frequently. To ensure you have the latest and most stable version of npm, you can update it using npm itself. In your terminal, run the command `npm install -g npm@latest`. The `-g` flag ensures npm is installed globally, making it available system-wide.

> 💡 **Tip:** Regularly updating npm helps you access new features, performance improvements, and security patches.


## Tips & Tricks

- Consider using a Node Version Manager (like `nvm` for Linux/macOS or `nvm-windows` for Windows) if you need to switch between different Node.js and npm versions for various projects.
- Always run `npm update` within your project directories to keep local dependencies up-to-date.
- If you encounter permissions errors during global package installation, you might need to fix npm's permissions or use `sudo` (on Linux/macOS) with caution.

## Warnings

- ⚠️ Installing Node.js and npm requires administrator or sudo privileges, as it modifies system files. Be careful to only download from official sources.
- ⚠️ Avoid installing npm directly through `apt-get install npm` on Ubuntu/Debian without Node.js, as it might install an outdated version or one not tied to a modern Node.js installation. Always prefer the Node.js installer or nvm.

## Frequently Asked Questions

**How to install npm in Windows?**

To install npm on Windows, download the official Node.js .msi installer from nodejs.org. Run the installer and follow the prompts, ensuring npm is selected as a component. Node.js bundles npm, so installing Node.js automatically installs npm.

**How to install npm on Mac?**

On a Mac, you can install npm by downloading the Node.js .pkg installer from the official Node.js website. Execute the installer and proceed through the installation wizard. Alternatively, Homebrew users can install Node.js and npm with `brew install node`.

**How to install npm on Ubuntu?**

For Ubuntu, the most reliable way to install npm is by first installing Node.js. You can use a Node.js version manager like `nvm` or download the pre-compiled binaries from nodejs.org. Avoid `sudo apt install npm` directly as it often provides an outdated version.

**What is npm and why do I need it?**

npm stands for Node Package Manager. It's the default package manager for Node.js, used to install, manage, and share JavaScript packages (libraries and tools) for your projects. You need it to easily integrate third-party code and manage project dependencies.

**How can I check if npm is already installed?**

Open your terminal or command prompt and type `npm -v` then press Enter. If npm is installed, it will display its version number. If you receive an error message like "command not found," npm is not installed or not correctly configured in your system's PATH.

**Can I install npm without Node.js?**

No, npm is distributed with Node.js. When you install Node.js, npm is automatically installed alongside it. There isn't a separate standalone installer for npm that doesn't rely on Node.js being present.

**What should I do if npm commands don't work after installation?**

First, try closing and reopening your terminal or command prompt. If that doesn't work, restart your computer to ensure all environment variables are refreshed. Double-check that Node.js and npm were successfully installed by verifying their versions (`node -v` and `npm -v`).

To install npm, you primarily install Node.js, which includes npm as part of its distribution. Download the recommended Node.js installer for your operating system (Windows, macOS, or Linux) from the official Node.js website, then run the installer and follow the prompts. After installation, verify npm's presence by checking its version in your terminal.

## What You Need

- Computer with internet access
- Administrator or sudo privileges
- Terminal or Command Prompt

## Steps

### Step 1: Understand Node.js and npm

npm, or Node Package Manager, is the default package manager for Node.js, a JavaScript runtime environment. When you install Node.js, npm is automatically installed alongside it, making it the primary method for managing project dependencies and running scripts. This guide focuses on installing Node.js to get npm.

### Step 2: Download Node.js Installer

Visit the official Node.js website (nodejs.org) and download the Long Term Support (LTS) version installer appropriate for your operating system. The LTS version is recommended for most users due to its stability and long-term support for development and production environments.

### Step 3: Run the Node.js Installer

For Windows and Mac, locate the downloaded installer file (e.g., .msi for Windows, .pkg for Mac) and double-click it. Follow the on-screen instructions, accepting the license agreement and default installation paths. Ensure that 'npm package manager' is selected for installation, which it usually is by default. For Linux (Ubuntu/Debian), you can often use `sudo apt update && sudo apt install nodejs npm` in your terminal.

### Step 4: Verify the Installation

Open a new terminal or command prompt window after the installation is complete. Type `node -v` and press Enter to check the Node.js version, then type `npm -v` and press Enter to check the npm version. If both commands return version numbers, Node.js and npm are successfully installed and ready to use.

> 💡 **Tip:** If you encounter a 'command not found' error, try restarting your terminal or computer, or ensure Node.js was added to your system's PATH environment variable during installation. For more detailed platform-specific troubleshooting, see [How to Install npm: Step-by-Step for Windows, Mac & Linux](/en/how-to-install-npm-windows-mac-linux).

### Step 5: Update npm (Optional but Recommended)

Although npm comes bundled with Node.js, it's often updated more frequently than Node.js itself. To ensure you have the latest stable version of npm, run `npm install -g npm@latest` in your terminal. This command updates npm globally, providing access to the newest features and bug fixes.

### Step 6: Start Using npm

With npm successfully installed, you can now use it to manage your JavaScript projects. Common tasks include initializing new projects (`npm init`), installing packages (`npm install <package-name>`), and running scripts defined in your project's `package.json` file. Explore the vast npm registry for libraries and tools to enhance your development workflow.


## Tips & Tricks

- Always download Node.js from the official website (nodejs.org) to ensure security and authenticity of the installer.
- Consider using a Node Version Manager (NVM) like nvm for Linux/macOS or nvm-windows for Windows if you need to switch between different Node.js versions for various projects.
- After installation, if commands like `node -v` or `npm -v` don't work, close and reopen your terminal or command prompt to refresh environment variables.
- The LTS (Long Term Support) version of Node.js is generally recommended for production environments due to its stability and longer maintenance period.

## Warnings

- ⚠️ Always ensure you have administrator or sudo privileges before running installers or package manager commands to avoid permission errors during installation.
- ⚠️ Be cautious when installing packages globally (`npm install -g`) as they can sometimes conflict with other global packages or system-wide settings. Prefer local installation for project dependencies whenever possible.

## Frequently Asked Questions

**How do I install npm in Windows?**

To install npm in Windows, download the official Node.js `.msi` installer from nodejs.org. Run the installer, accept the default settings, and ensure the "npm package manager" component is selected. After installation, open a new Command Prompt or PowerShell and type `npm -v` to verify.

**What are the steps to install npm on Mac?**

To install npm on Mac, download the official Node.js `.pkg` installer from nodejs.org. Double-click the installer, follow the on-screen prompts, and complete the installation. Open a new Terminal window and run `npm -v` to confirm npm is installed and working correctly.

**How can I install npm on Ubuntu?**

To install npm on Ubuntu, the recommended method is to use your system's package manager. Open a terminal and run `sudo apt update` followed by `sudo apt install nodejs npm`. This will install both Node.js and npm from Ubuntu's repositories.

**Why do I need to install Node.js to get npm?**

npm is the default package manager for Node.js. It comes bundled with the Node.js installation package because it's an integral part of the Node.js ecosystem, used for managing project dependencies and running development scripts within Node.js projects.

**What should I do if `npm -v` returns 'command not found'?**

If `npm -v` returns 'command not found', first try closing and reopening your terminal or command prompt. If the issue persists, ensure Node.js was added to your system's PATH environment variable during installation. You might need to reinstall Node.js, ensuring that the option to add to PATH is selected.

**Can I install npm without Node.js?**

While technically possible to install npm separately, it's highly discouraged and generally not recommended. npm is designed to work with Node.js and relies on its runtime environment. The standard and most reliable way to get npm is by installing Node.js.

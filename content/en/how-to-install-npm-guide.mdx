Installing npm (Node Package Manager) is straightforward as it comes bundled with Node.js. This guide will walk you through the process, ensuring you have npm ready to manage your JavaScript packages. For a more comprehensive overview across all systems, check out [How to Install npm: A Step-by-Step Guide for All OS](/en/how-to-install-npm).

## What You Need

- Computer (Windows, macOS, or Linux)
- Internet connection
- Administrator privileges

## Steps

### Step 1: Download Node.js Installer

npm is distributed with Node.js, so the first step is to download the Node.js installer for your operating system. Visit the official Node.js website (nodejs.org) and choose the LTS (Long Term Support) version, which is recommended for most users due to its stability. The website should automatically detect your OS and recommend the appropriate installer.

### Step 2: Run the Node.js Installer

Once the download is complete, locate the installer file (e.g., .msi for Windows, .pkg for macOS, or a tarball for Linux). Double-click to run it. This will launch the Node.js Setup Wizard, which will guide you through the installation process on your specific system.

### Step 3: Follow the Installation Wizard Prompts

The setup wizard will present you with a series of prompts. Generally, you can accept the default settings, including the installation location and the components to install (Node.js runtime, npm package manager, and corepack). Read each step carefully and click 'Next' or 'Continue' to proceed until the installation begins.

### Step 4: Complete the Installation

Allow the installer to complete the process. This may take a few minutes depending on your system. Once finished, you will typically see a 'Finish' or 'Close' button. Click this to exit the setup wizard. It's often a good practice to restart your terminal or command prompt after installation to ensure that the new path variables are correctly loaded.

### Step 5: Verify Node.js and npm Installation

Open a new terminal or command prompt window. To verify that Node.js and npm have been successfully installed, type `node -v` and press Enter. Then, type `npm -v` and press Enter. Both commands should display their respective version numbers, indicating a successful installation and confirming they are accessible from your system's PATH.

### Step 6: Update npm to the Latest Version (Optional but Recommended)

While npm comes bundled with Node.js, it might not always be the very latest version. To update npm to its newest stable release, open your terminal or command prompt and run the command: `npm install -g npm@latest`. The `-g` flag ensures npm is installed globally, making it available system-wide. This step helps you benefit from the latest features and bug fixes.


## Tips & Tricks

- Always download Node.js from the official website (nodejs.org) to ensure you get a legitimate and secure version.
- If you encounter issues, ensure your system's PATH environment variable includes the Node.js installation directory. Restarting your computer can sometimes resolve PATH-related problems.
- For advanced users, version managers like nvm (Node Version Manager) allow you to install and switch between multiple Node.js and npm versions easily.

## Warnings

- ⚠️ Ensure you have administrator privileges to install Node.js and npm, as the installer needs to write to system directories.
- ⚠️ Avoid installing Node.js and npm using unofficial sources or outdated guides, as this can lead to security vulnerabilities or broken installations.
- ⚠️ When using `npm install -g` for global packages, be aware that these packages are available system-wide and can sometimes conflict with project-specific versions.

## Frequently Asked Questions

**How do I install npm in Windows?**

To install npm in Windows, download the official Node.js .msi installer from nodejs.org. Run the installer and follow the wizard prompts, accepting the default options. npm is automatically included with the Node.js installation.

**How do I install npm on Mac?**

On a Mac, you can install npm by downloading the Node.js .pkg installer from nodejs.org. Execute the installer and proceed through the installation steps. npm will be installed alongside Node.js, making it ready for use.

**How do I install npm on Ubuntu?**

For Ubuntu, the recommended way to install npm is to first install Node.js. You can use the official NodeSource repositories or `sudo apt install nodejs npm` (though the latter might provide an older version). After installation, verify with `node -v` and `npm -v`.

**How do I verify if npm is installed correctly?**

After installation, open your terminal or command prompt and type `node -v` and then `npm -v`. If both commands return version numbers, it indicates that Node.js and npm have been successfully installed and are accessible in your system's PATH.

**Why do I need Node.js to install npm?**

npm is the package manager for Node.js, and it's built using Node.js itself. Therefore, npm relies on the Node.js runtime to function. When you install Node.js, npm is automatically bundled with it to ensure compatibility and ease of use.

**What should I do if npm is not recognized after installation?**

If npm is not recognized, first try restarting your terminal or command prompt, or even your computer. This ensures that your system's PATH environment variables are updated. If the issue persists, you might need to manually check or adjust your system's PATH to include the Node.js installation directory.

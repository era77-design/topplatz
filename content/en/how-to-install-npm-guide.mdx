To install npm, you typically install Node.js, which bundles npm automatically. Download the recommended Node.js installer for your operating system (Windows, macOS, or Linux) from the official Node.js website and run it. This process will set up both Node.js and npm on your system.

## What You Need

- Computer with internet access
- Node.js installer (downloaded)

## Steps

### Step 1: Understand npm's Relationship with Node.js

npm, the Node Package Manager, is automatically installed when you install Node.js. This means you don't typically install npm as a standalone application. Node.js provides the JavaScript runtime environment, and npm is the default package manager for Node.js. Therefore, your primary goal is to install Node.js.

> 💡 **Tip:** Before proceeding, check if Node.js and npm are already installed by opening your terminal or command prompt and typing `node -v` and `npm -v`.

### Step 2: Download the Node.js Installer

Navigate to the official Node.js website (nodejs.org) in your web browser. You will typically see two download options: the LTS (Long Term Support) version and the Current version. For most users, especially those new to Node.js and npm, the LTS version is recommended due to its stability and ongoing support. Download the installer package appropriate for your operating system (Windows, macOS, or Linux).

> 💡 **Tip:** Always download installers from the official Node.js website to ensure authenticity and security.

### Step 3: Run the Node.js Installer

Once the download is complete, locate the installer file (e.g., .msi for Windows, .pkg for macOS, or a script for Linux) and run it. Follow the prompts in the installation wizard. For most users, accepting the default installation settings is perfectly fine. The installer will guide you through the process, including accepting the license agreement and choosing the installation directory. For more detailed, platform-specific steps, refer to our guide: [How to Install npm: Step-by-Step for Windows, Mac & Linux](/en/how-to-install-npm-windows-mac-linux).

> 💡 **Tip:** Ensure that the option to install npm package manager is selected if it appears as a separate choice (it usually is by default).

### Step 4: Verify Node.js and npm Installation

After the installation finishes, open a new terminal or command prompt window. It's important to open a new one as the environment variables might not be updated in existing windows. Type `node -v` and press Enter. You should see the installed Node.js version. Then, type `npm -v` and press Enter. This will display the installed npm version, confirming a successful installation.

> 💡 **Tip:** If you encounter 'command not found' errors, try restarting your computer, especially on Windows, to ensure environment variables are properly loaded.

### Step 5: Update npm to the Latest Version (Recommended)

Even though npm is installed with Node.js, it's often a slightly older version. It's good practice to update npm itself to its latest stable version. In your terminal or command prompt, run the command: `npm install -g npm@latest`. The `-g` flag ensures npm is updated globally. This command will fetch and install the newest version of npm.

> 💡 **Tip:** Keeping npm updated ensures you have access to the latest features, bug fixes, and security patches.

### Step 6: Explore Using NVM for Version Management (Advanced)

For developers who need to work with multiple Node.js versions on the same machine, Node Version Manager (NVM) is an excellent tool. NVM allows you to install, switch, and manage different Node.js and npm versions easily. This is particularly useful for testing projects against various Node.js environments. While not strictly part of the initial installation, it's a valuable next step for more complex development workflows.

> 💡 **Tip:** Consider NVM if you foresee needing to manage different Node.js versions for various projects, as it offers greater flexibility. For a more comprehensive guide on the overall process, see: [How to Install npm: A Simple Step-by-Step Guide](/en/how-to-install-npm-step-by-step).


## Tips & Tricks

- Always download Node.js installers from the official website (nodejs.org) to prevent security risks.
- Regularly update npm using `npm install -g npm@latest` to benefit from the newest features and security fixes.
- Understand the difference between global (`-g`) and local package installations; global packages are available system-wide, while local packages are specific to a project directory.

## Warnings

- ⚠️ Ensure you have administrative privileges to run the Node.js installer, as it needs to modify system files and environment variables.
- ⚠️ Be cautious when using `sudo` on Linux or running as Administrator on Windows for npm commands; generally, only use it when strictly necessary to avoid permission issues.

## Frequently Asked Questions

**How to install npm?**

To install npm, you primarily need to install Node.js, as npm is bundled with it. Download the appropriate Node.js installer from the official website for your operating system and follow the installation wizard's steps.

**How to install npm in Windows?**

To install npm in Windows, download the .msi installer from the Node.js website. Run the installer and follow the prompts, accepting the default options. Once Node.js is installed, npm will also be available on your system.

**How to install npm on Mac?**

To install npm on Mac, download the .pkg installer from the Node.js website and run it, following the installation wizard. Alternatively, you can use Homebrew by running `brew install node` in your terminal, which will install both Node.js and npm.

**How to install npm in Ubuntu?**

To install npm in Ubuntu, you can use the package manager with `sudo apt update && sudo apt install nodejs npm`. For the latest versions, it's recommended to use the NodeSource PPA by following their installation instructions, which ensures you get the most up-to-date Node.js and npm.

**How do I check if npm is already installed?**

Open your terminal or command prompt and type `npm -v`. If npm is installed, it will display its version number. If you receive a 'command not found' error, npm is not installed or not correctly configured in your system's PATH.

**What is the difference between npm and Node.js?**

Node.js is a JavaScript runtime environment that allows you to execute JavaScript code outside of a web browser. npm (Node Package Manager) is the default package manager for Node.js, used to install, manage, and share packages (libraries or modules) of JavaScript code.

**Should I update npm after installation?**

Yes, it is highly recommended to update npm to its latest version after installing Node.js. The version bundled with Node.js might not be the most current, and updating ensures you have the latest features, bug fixes, and security improvements. Use `npm install -g npm@latest`.

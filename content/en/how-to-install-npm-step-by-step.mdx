Installing npm (Node Package Manager) is typically done by installing Node.js, as npm comes bundled with it. This process ensures you have the necessary tools to manage JavaScript packages for your development projects.

## What You Need

- Internet connection
- Administrator or root access to your computer
- Web browser

## Steps

### Step 1: Check for Existing Node.js and npm Installation

Before you begin, it's a good practice to check if Node.js and npm are already installed on your system. Open your terminal or command prompt and type `node -v` and then `npm -v`. If versions are returned, they are installed. If not, or if you wish to update, proceed with the installation.

> 💡 **Tip:** If you see version numbers, you may only need to update npm by running `npm install -g npm@latest`.

### Step 2: Download the Node.js Installer

Navigate to the official Node.js website (nodejs.org) in your web browser. You'll typically see two recommended versions for download: the LTS (Long Term Support) version and the Current version. For most users, the LTS version is recommended as it's more stable and thoroughly tested.

> 💡 **Tip:** Always download installers from the official Node.js website to ensure security and authenticity.

### Step 3: Run the Node.js Installer

Once the download is complete, locate the installer file (e.g., `.msi` for Windows, `.pkg` for macOS, or a `.tar.gz` for Linux). Double-click the installer and follow the on-screen prompts. Accept the license agreement, choose the installation directory (default is usually fine), and ensure that 'npm package manager' is selected for installation, which it is by default.

> 💡 **Tip:** On macOS, you might be asked for your administrator password during the installation process. On Linux, you might use a package manager like `apt` or `yum` instead of a direct installer.

### Step 4: Complete the Installation Process

Continue through the installation wizard, clicking 'Next' and 'Install' as prompted. The installer will copy all necessary files to your system. Once the installation finishes, click 'Finish' to exit the setup wizard.

> 💡 **Tip:** It's often a good idea to restart your terminal or command prompt after installation to ensure that the system's PATH variable is updated correctly.

### Step 5: Verify Node.js and npm Installation

After the installation is complete, open a new terminal or command prompt window. Type `node -v` and press Enter. Then, type `npm -v` and press Enter. You should now see the version numbers for Node.js and npm, confirming that they have been successfully installed on your system.

> 💡 **Tip:** If you encounter errors, ensure your system's PATH variable includes the Node.js installation directory. For a comprehensive guide, refer to [How to Install npm: Step-by-Step Guide for All Platforms](/en/how-to-install-npm-guide-all-platforms).

### Step 6: Update npm to the Latest Version (Optional)

Although npm comes bundled with Node.js, it might not always be the very latest version. To update npm independently, open your terminal or command prompt and run the command `npm install -g npm@latest`. This command globally installs the most recent version of npm.

> 💡 **Tip:** Updating npm regularly helps you access the newest features, bug fixes, and security patches.


## Tips & Tricks

- Always use the official Node.js website for downloads to avoid malicious software.
- If you encounter issues on Linux, consider using your distribution's package manager (e.g., `sudo apt install nodejs npm` for Debian/Ubuntu) for easier installation and updates.
- Ensure you have sufficient disk space before starting the installation process.
- After installing or updating, close and reopen your terminal or command prompt to ensure environment variables are refreshed.
- For advanced users, NVM (Node Version Manager) allows you to easily switch between different Node.js and npm versions on the same machine.

## Warnings

- ⚠️ Do not install Node.js and npm from untrusted sources, as this can compromise your system's security.
- ⚠️ Running `npm install -g` commands without understanding their impact can sometimes lead to permissions issues or conflicts with other global packages. Use `sudo` on Linux/macOS only when necessary and with caution.

## Frequently Asked Questions

**How do I install npm in Windows?**

To install npm in Windows, download the official Node.js `.msi` installer from nodejs.org. Run the installer and follow the prompts; npm is included by default. After installation, verify by typing `npm -v` in your command prompt.

**What is the process to install npm on a Mac?**

Installing npm on a Mac involves downloading the Node.js `.pkg` installer from nodejs.org. Execute the installer and follow the instructions. Once completed, open your terminal and run `npm -v` to confirm the installation.

**Can you explain how to install npm on Ubuntu?**

On Ubuntu, you can install npm by first installing Node.js. The recommended way is to use `sudo apt update` followed by `sudo apt install nodejs npm`. Alternatively, you can download the Node.js tarball from the official website and compile it or use a tool like NVM.

**Do I need to install npm separately from Node.js?**

No, npm comes bundled with Node.js. When you install Node.js using the official installer, npm is automatically installed alongside it, making the process straightforward.

**How can I check if npm is already installed on my system?**

To check if npm is installed, open your terminal or command prompt and type `npm -v`. If npm is installed, it will display its version number. If not, you'll receive an error message.

**What should I do if npm isn't working after installation?**

If npm isn't working, first try restarting your terminal or computer. Ensure that the Node.js installation directory is correctly added to your system's PATH environment variable. Re-running the installer or consulting official documentation can also help troubleshoot.

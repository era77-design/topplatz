npm, or Node Package Manager, is the default package manager for Node.js and the world's largest software registry. Installing npm is straightforward, as it typically comes bundled with Node.js, making it an essential tool for JavaScript development.

## What You Need

- Internet connection
- Command line interface (Terminal, PowerShell, CMD)
- Administrator or sudo privileges (for installation)

## Steps

### Step 1: Check for Existing Node.js and npm Installation

Before you begin, it's good practice to check if Node.js and npm are already installed on your system. Open your command line interface (Terminal on macOS/Linux, Command Prompt or PowerShell on Windows) and type `node -v` and then `npm -v`. If versions are displayed, you might already have them. If not, or if the versions are outdated, proceed with the installation.

### Step 2: Download the Node.js Installer

The simplest and most recommended way to install npm is by installing Node.js, as npm is included with it. Visit the official Node.js website (nodejs.org) and download the LTS (Long Term Support) version installer for your operating system. The LTS version is stable and recommended for most users.

### Step 3: Run the Node.js Installer

Locate the downloaded Node.js installer file (e.g., `.msi` for Windows, `.pkg` for macOS) and run it. Follow the on-screen prompts. Accept the license agreement, choose the default installation directory, and ensure that 'npm package manager' is selected as a component to install. Complete the installation process.

### Step 4: Verify the Installation

After the installation is complete, open a *new* command line window (close any existing ones and reopen). This ensures that your system's PATH environment variable is updated. Type `node -v` and `npm -v` again. You should now see the version numbers for both Node.js and npm, confirming a successful installation. If you encounter issues, ensure you've restarted your terminal.

### Step 5: Update npm to the Latest Version

While npm comes bundled with Node.js, it's often a slightly older version. To ensure you have the latest features and bug fixes, it's a good idea to update npm itself. In your command line, run `npm install -g npm@latest`. The `-g` flag means it will be installed globally, making it available system-wide. After the update, verify the version again with `npm -v`.

### Step 6: Install a Sample Package (Optional)

To further test your npm installation, you can try installing a simple package. Create a new directory for a test project, navigate into it in your terminal, and run `npm init -y` to create a `package.json` file. Then, try installing a package like `lodash` by typing `npm install lodash`. This will download and install the package locally to your project, demonstrating npm's functionality. For a more comprehensive guide, check out [How to Install npm: A Complete Guide for Developers](/en/how-to-install-npm-complete-guide).


## Tips & Tricks

- Always use the LTS (Long Term Support) version of Node.js for stability in production environments.
- Consider using a Node.js version manager like `nvm` (Node Version Manager) for macOS/Linux or `nvm-windows` for Windows if you need to switch between different Node.js and npm versions for various projects. This offers greater flexibility.
- Restart your command line interface after installing Node.js/npm or updating environment variables to ensure changes are recognized.

## Warnings

- ⚠️ Avoid using `sudo` or administrator privileges for npm commands unless explicitly required, especially for global package installations, as it can lead to permission issues.
- ⚠️ Be cautious when installing packages from unknown sources to prevent security vulnerabilities or malicious code.

## Frequently Asked Questions

**How to install npm in Windows?**

To install npm in Windows, download the official Node.js MSI installer from nodejs.org. Run the installer, accept the default settings, and ensure that the 'npm package manager' component is selected. After installation, open a new Command Prompt or PowerShell window and type `npm -v` to verify.

**How to install npm on Mac?**

On a Mac, the easiest way to install npm is by downloading the Node.js `.pkg` installer from nodejs.org. Follow the installation wizard. Alternatively, you can use Homebrew with `brew install node` which will also install npm. Verify by opening a new Terminal and running `npm -v`.

**How to install npm on Ubuntu?**

To install npm on Ubuntu, it's recommended to first install Node.js. You can use `curl -fsSL https://deb.nodesource.com/setup_lts.x | sudo -E bash -` followed by `sudo apt-get install -y nodejs`. This method ensures you get the latest LTS version of Node.js and npm. Verify with `npm -v` in your terminal.

**What is npm and why do I need it?**

npm (Node Package Manager) is a command-line utility for interacting with the npm registry, which hosts over a million open-source packages. You need it to install, manage, and share JavaScript libraries and tools for your projects, simplifying development workflows and dependency management.

**Do I need to install Node.js separately to get npm?**

Yes, npm is bundled and installed automatically when you install Node.js. It is not typically installed as a standalone package. Therefore, installing Node.js is the primary step to get npm on your system.

**How do I update npm to its latest version?**

To update npm to its latest version, open your command line and run the command `npm install -g npm@latest`. The `-g` flag ensures the update is applied globally across your system. After the update, you can verify the new version by typing `npm -v`.

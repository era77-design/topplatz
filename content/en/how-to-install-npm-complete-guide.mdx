To install npm, you typically need to install Node.js first, as npm (Node Package Manager) is bundled with Node.js. This process involves downloading the appropriate Node.js installer for your operating system and running it, then verifying the installation via your command line.

## What You Need

- A computer (Windows, macOS, or Linux)
- An internet connection
- Administrator privileges
- Command Line Interface (CLI) or Terminal access

## Steps

### Step 1: Understand npm and Node.js

npm, which stands for Node Package Manager, is the default package manager for Node.js. It's used to install, share, and manage project dependencies. Since npm is bundled with Node.js, the primary way to install npm is by installing Node.js itself. This ensures you get a compatible version of both tools.

> 💡 **Tip:** For a more in-depth look at what npm is, check out our guide: [How to Install npm: A Beginner's Step-by-Step Guide](/en/how-to-install-npm-beginner-guide).

### Step 2: Download and Install Node.js

Visit the official Node.js website (nodejs.org) to download the installer. It's recommended to choose the LTS (Long Term Support) version, as it's more stable for most users. Download the installer specific to your operating system (Windows, macOS, or Linux). Run the downloaded installer and follow the on-screen prompts, accepting the default installation settings unless you have specific reasons to change them. This process will automatically install both Node.js and npm on your system.

### Step 3: Verify the Installation

After the installation is complete, open your command line interface (Terminal on macOS/Linux, Command Prompt or PowerShell on Windows). Type `node -v` and press Enter to check the Node.js version. Then, type `npm -v` and press Enter to check the npm version. If both commands return version numbers, Node.js and npm have been successfully installed and are accessible from your system's PATH. If you encounter an error, restart your terminal or computer and try again.

### Step 4: Update npm to the Latest Version

While npm comes bundled with Node.js, it's often updated more frequently. It's good practice to update npm to its latest stable version after installation. In your command line, run the command `npm install -g npm@latest`. The `-g` flag ensures npm is installed globally, making it available for all your projects. This command will fetch and install the newest version of npm, keeping your package manager up-to-date.

### Step 5: Install Your First npm Package

To confirm npm is fully functional, try installing a simple package globally. For example, you can install a utility like `nodemon` by running `npm install -g nodemon` in your terminal. This command downloads and installs the `nodemon` package, which automatically restarts your Node.js application when file changes are detected. After installation, you can verify it by typing `nodemon -v`. This step confirms that npm can successfully fetch and install packages from the npm registry.

### Step 6: Troubleshoot Common Issues

If you encounter issues like 'command not found' or permission errors, double-check your system's PATH environment variables to ensure Node.js and npm directories are included. For permission errors, especially on macOS/Linux, avoid using `sudo` with npm unless absolutely necessary, or consider fixing npm permissions. Reinstalling Node.js can often resolve persistent issues. Always refer to the official Node.js and npm documentation for the most up-to-date troubleshooting advice.


## Tips & Tricks

- Always install the LTS (Long Term Support) version of Node.js for stability in production environments.
- Use a Node Version Manager (like NVM for macOS/Linux or NVM-Windows) if you need to switch between different Node.js and npm versions for various projects.
- Regularly update npm using `npm install -g npm@latest` to benefit from the latest features and security patches.
- Clear your npm cache using `npm cache clean --force` if you encounter issues with package installations.
- If you're having trouble, a comprehensive guide is available here: [How to Install npm: A Step-by-Step Guide for All OS](/en/how-to-install-npm).

## Warnings

- ⚠️ Be cautious when running `npm` commands with `sudo` (on macOS/Linux) as it can lead to permission issues for future installations. It's better to fix npm permissions or use a Node Version Manager.
- ⚠️ Ensure your internet connection is stable during the download and installation process to avoid corrupted files.

## Frequently Asked Questions

**How to install npm in Windows?**

To install npm in Windows, download the official Node.js `.msi` installer from nodejs.org. Run the installer and follow the prompts, accepting default settings. This will automatically install both Node.js and npm on your system.

**How to install npm on Mac?**

On a Mac, the easiest way to install npm is by downloading the Node.js `.pkg` installer from nodejs.org and running it. Alternatively, you can use Homebrew by running `brew install node` in your terminal, which also installs npm.

**How to install npm in Ubuntu?**

To install npm in Ubuntu, you can use your system's package manager. Open your terminal and run `sudo apt update && sudo apt install nodejs npm`. This command will install both Node.js and npm from the Ubuntu repositories.

**What is the easiest way to install npm?**

The easiest way to install npm for most users is by installing Node.js from its official website (nodejs.org). npm is bundled with Node.js, so once Node.js is installed, npm will also be available on your system.

**Do I need to install Node.js separately to get npm?**

No, you typically do not need to install Node.js and npm separately. npm is bundled as part of the Node.js installation package. When you install Node.js, npm is automatically installed alongside it.

**How do I check if npm is already installed?**

To check if npm is installed, open your command line or terminal and type `npm -v` then press Enter. If npm is installed, it will display its version number. If not, you'll usually see an error message like "command not found".

**What if I get a 'command not found' error after installing Node.js?**

If you get a 'command not found' error, try restarting your terminal or even your computer. This often resolves issues with environment variables not being updated. If the problem persists, ensure Node.js was added to your system's PATH during installation.

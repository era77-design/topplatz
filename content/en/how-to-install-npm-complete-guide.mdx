Installing npm (Node Package Manager) is straightforward as it comes bundled with Node.js. By installing Node.js, you automatically get npm, which is essential for managing JavaScript packages and project dependencies. This guide will walk you through the process on various operating systems, ensuring you're ready to start your development journey.

## What You Need

- Computer with internet access
- Administrator or root privileges (for installation)
- Terminal or Command Prompt

## Steps

### Step 1: Check for Existing Node.js and npm Installation

Before proceeding, it's wise to check if Node.js and npm are already installed on your system. Open your terminal (macOS/Linux) or Command Prompt/PowerShell (Windows) and type `node -v` and then `npm -v`. If versions are displayed, they are installed; otherwise, you'll see an error message indicating they're not found, meaning you need to install them.

### Step 2: Download the Node.js Installer

npm is distributed with Node.js, so you'll need to download the Node.js installer. Visit the official Node.js website (nodejs.org) and download the LTS (Long Term Support) version, which is recommended for most users due to its stability. Ensure you select the installer appropriate for your operating system (Windows, macOS, or Linux).

### Step 3: Install Node.js and npm on Windows or macOS

For Windows and macOS, the installation process is guided by an installer wizard. Locate the downloaded `.msi` (Windows) or `.pkg` (macOS) file and double-click to run it. Follow the on-screen prompts, accepting the default installation options. The wizard will automatically install both Node.js and npm on your system.

### Step 4: Install Node.js and npm on Ubuntu (and other Linux distributions)

To install npm on Ubuntu, it's recommended to use NodeSource's binary distribution for a more up-to-date version than what's available in the default apt repositories. First, update your package list with `sudo apt update`. Then, add the NodeSource repository for Node.js LTS (e.g., Node.js 18.x) and install it using `sudo apt install nodejs` which will also install npm. For other Linux distributions, consult their specific package manager instructions.

> 💡 **Tip:** For a quick setup, consider reviewing [How to Install npm: A Quick Start Guide for All OS](/en/how-to-install-npm-quick-start) to ensure all prerequisites are met.

### Step 5: Verify the Installation

After the installation is complete, open a new terminal or Command Prompt window. This ensures that your system's PATH environment variable is updated. Run `node -v` and `npm -v` again. You should now see the installed versions of Node.js and npm, confirming a successful installation. If you encounter issues, restart your computer and try again.

### Step 6: Update npm to the Latest Version (Optional but Recommended)

While npm is installed with Node.js, it might not be the absolute latest version. It's a good practice to update npm periodically. To update npm, open your terminal and run the command: `npm install -g npm@latest`. This command globally installs the newest version of npm, keeping your package manager up-to-date with the latest features and bug fixes.


## Tips & Tricks

- Always download Node.js from the official website to avoid potential security risks.
- Consider using a Node Version Manager (NVM) if you need to switch between different Node.js and npm versions for various projects. This is especially useful for developers managing multiple projects.
- If `npm` commands are not recognized after installation, ensure that the Node.js installation directory is correctly added to your system's PATH environment variable. Restarting your terminal or computer often resolves this.

## Warnings

- ⚠️ Always use `sudo` (Linux/macOS) or run your Command Prompt as Administrator (Windows) when installing global packages or Node.js itself, but be cautious with `sudo npm` for general package installation to avoid permission issues later.

## Frequently Asked Questions

**How to install npm in Windows?**

To install npm in Windows, download the official Node.js `.msi` installer from nodejs.org. Run the installer and follow the wizard, accepting the default options. This will automatically install Node.js and npm on your system.

**How to install npm on Mac?**

Installing npm on Mac involves downloading the Node.js `.pkg` installer from nodejs.org. Execute the installer and proceed through the steps. Both Node.js and npm will be installed, making them available in your terminal.

**How to install npm on Ubuntu?**

On Ubuntu, the recommended way to install npm is by first adding the NodeSource repository and then using `sudo apt install nodejs`. This method ensures you get a recent version of Node.js, which includes npm, directly from a reliable source.

**What is npm and why do I need it?**

npm (Node Package Manager) is the default package manager for Node.js. You need it to install, share, and manage project dependencies and packages in JavaScript development. It's crucial for building modern web applications and tools.

**How do I update npm after installation?**

To update npm to its latest version, open your terminal or command prompt and run `npm install -g npm@latest`. The `-g` flag ensures it's installed globally, making the updated version available system-wide.

**What if npm is not recognized after installation?**

If npm is not recognized, it usually means your system's PATH environment variable hasn't been updated or refreshed. Try opening a new terminal window, restarting your computer, or manually adding the Node.js installation directory to your PATH.

**Can I install npm without installing Node.js?**

No, npm is bundled with Node.js and cannot be installed independently. When you install Node.js, npm is automatically included. They work together as core components of the Node.js ecosystem.

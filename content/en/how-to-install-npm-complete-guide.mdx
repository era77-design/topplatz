npm (Node Package Manager) is the default package manager for Node.js, essential for managing JavaScript libraries and dependencies. To install npm, you typically install Node.js first, as npm is bundled with it. This guide provides a step-by-step process for setting up npm on various operating systems. For a more detailed look at OS-specific installations, refer to our [How to Install npm: Step-by-Step Guide for All OS](/en/how-to-install-npm-guide-all-os).

## What You Need

- Computer (Windows, macOS, or Linux)
- Internet connection
- Command Line Interface (Terminal/PowerShell)

## Steps

### Step 1: Understand npm and Node.js

npm is the package manager for JavaScript, and it comes bundled with Node.js. This means that when you install Node.js, npm is automatically installed alongside it. Node.js is a JavaScript runtime that allows you to run JavaScript code outside of a web browser, making it crucial for server-side development and building command-line tools. For a more foundational understanding, check out our [How to Install npm: A Beginner's Step-by-Step Guide](/en/how-to-install-npm).

> 💡 **Tip:** Always check the official Node.js website for the latest stable version.

### Step 2: Download Node.js (and npm)

Visit the official Node.js website (nodejs.org) to download the appropriate installer for your operating system. You'll typically see two versions: LTS (Long Term Support) and Current. For most users, the LTS version is recommended as it offers greater stability and reliability for production environments.

> 💡 **Tip:** Choose the LTS version unless you need specific features from the latest Current release.

### Step 3: Run the Node.js Installer

Once the download is complete, locate the installer file and run it. Follow the on-screen prompts, accepting the license agreement and choosing the installation location. The installer will automatically configure Node.js and npm for your system. Ensure that the 'npm package manager' component is selected during installation, though it usually is by default.

### Step 4: Verify the Installation

After the installation finishes, open your command line interface (Terminal on macOS/Linux, Command Prompt or PowerShell on Windows). Type `node -v` and press Enter to check the Node.js version. Then, type `npm -v` and press Enter to check the npm version. If both commands return version numbers, Node.js and npm have been successfully installed.

> 💡 **Tip:** Restart your terminal or computer if the commands don't work immediately after installation.

### Step 5: Update npm (Optional but Recommended)

While npm comes bundled with Node.js, it's often a good practice to update npm to its latest version independently. This ensures you have access to the newest features, bug fixes, and security improvements. To update npm, run the command `npm install -g npm@latest` in your terminal. The `-g` flag ensures it's installed globally.

> 💡 **Tip:** Regularly updating npm helps prevent potential issues with package installations and dependency management.

### Step 6: Test npm with a Sample Package

To confirm npm is fully functional, try installing a simple global package. A common choice is `create-react-app` or `nodemon`. For example, run `npm install -g create-react-app`. This command will download and install the package globally, making it available for use across your projects.

> 💡 **Tip:** If you encounter permission errors, especially on macOS/Linux, you might need to use `sudo npm install -g <package-name>`. Be cautious when using `sudo`.

### Step 7: Start Using npm

With npm successfully installed and verified, you can now use it to manage dependencies for your JavaScript projects. Navigate to your project directory in the terminal and run `npm init` to create a `package.json` file, then use `npm install <package-name>` to add specific libraries to your project.

> 💡 **Tip:** Explore the npm registry at npmjs.com to discover millions of open-source packages.


## Tips & Tricks

- Always install the LTS version of Node.js for stability in production environments.
- Keep your npm version updated using `npm install -g npm@latest` to benefit from the latest features and security patches.
- If you encounter permission issues on macOS or Linux, consider using NVM (Node Version Manager) to manage Node.js and npm installations without `sudo`.
- For specific project needs, you can use `.npmrc` files to configure npm behavior, such as proxy settings or private registries.
- Remember that `npm install` (without a package name) installs all dependencies listed in your `package.json` file.

## Warnings

- ⚠️ Be cautious when using `sudo` with npm commands, as it grants elevated privileges and can sometimes lead to permission issues with globally installed packages. Consider using a Node Version Manager (like NVM) instead.
- ⚠️ Installing Node.js and npm through unofficial sources or outdated guides can lead to security vulnerabilities or compatibility problems. Always refer to the official Node.js website.

## Frequently Asked Questions

**How do I install npm in Windows?**

To install npm in Windows, download the Node.js MSI installer from the official Node.js website (nodejs.org). Run the installer and follow the prompts, as npm is bundled with Node.js. After installation, verify by opening Command Prompt or PowerShell and typing `npm -v`.

**How do I install npm on Mac?**

On a Mac, you can install npm by downloading the Node.js package installer (.pkg) from nodejs.org. Alternatively, use a package manager like Homebrew (`brew install node`) or a Node Version Manager (NVM). After installation, open Terminal and check with `npm -v`.

**How do I install npm on Ubuntu?**

To install npm on Ubuntu, the recommended way is to first install Node.js. You can do this by using `curl` to add the Node.js PPA (Personal Package Archive) and then installing via `apt`, or by downloading the binary from the Node.js website. Once Node.js is installed, npm will be available.

**Why is npm not installing with Node.js?**

If npm isn't installing with Node.js, it's possible that the "npm package manager" component was deselected during the Node.js installation process. Re-run the Node.js installer and ensure this option is checked. Alternatively, your PATH environment variable might not be correctly configured, preventing your system from finding the npm executable.

**What is the difference between npm and Node.js?**

Node.js is a JavaScript runtime environment that allows you to execute JavaScript code outside of a web browser. npm, or Node Package Manager, is the default package manager for Node.js, used for installing, sharing, and managing code packages (libraries and modules) for your Node.js projects.

**Can I install npm without Node.js?**

Generally, no. npm is tightly coupled with Node.js and is distributed as part of the Node.js installation. While there might be highly specialized or manual ways to get npm, it's not the intended or recommended method. Always install Node.js to get npm.

**How do I update npm?**

To update npm to its latest version, open your command line interface and run the command `npm install -g npm@latest`. The `-g` flag ensures the update is applied globally across your system, providing you with the most current features and bug fixes.

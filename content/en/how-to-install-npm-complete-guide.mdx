To install npm, you typically install Node.js, which includes npm by default. Download the appropriate Node.js installer for your operating system from the official Node.js website and follow the installation prompts. After installation, verify npm by running `npm -v` in your terminal.

## What You Need

- Computer with internet access
- Node.js installer (downloaded)
- Command Line Interface (CLI) / Terminal

## Steps

### Step 1: Understand npm and Node.js

Before you begin, it's important to understand that npm (Node Package Manager) is the default package manager for Node.js. This means that when you install Node.js, npm is automatically installed alongside it. npm helps you manage your project's dependencies and share your own packages.

> 💡 **Tip:** The primary way to get npm is by installing Node.js, so focus on the Node.js installation process.

### Step 2: Download the Node.js Installer

Navigate to the official Node.js website (nodejs.org) in your web browser. You'll typically see two recommended versions: the LTS (Long Term Support) version and the Current version. For most users and production environments, the LTS version is recommended for its stability. Download the installer appropriate for your operating system (Windows, macOS, or Linux).

> 💡 **Tip:** Always download Node.js from the official website to ensure authenticity and security. The LTS version is generally preferred for new installations.

### Step 3: Install Node.js on Your System

Run the downloaded Node.js installer. For Windows and macOS, this usually involves double-clicking the file and following the on-screen prompts, accepting the license agreement, and using the default installation options. For Linux, you might use a package manager or a NodeSource PPA. For detailed OS-specific instructions, refer to [How to Install npm: Step-by-Step for Windows, Mac & Linux](/en/how-to-install-npm-windows-mac-linux).

> 💡 **Tip:** Close any open terminal or command prompt windows before running the installer to ensure that the system's PATH variable is updated correctly.

### Step 4: Verify npm Installation

After the installation is complete, open a new terminal or command prompt window. Type `node -v` and press Enter to check the Node.js version. Then, type `npm -v` and press Enter to check the npm version. If both commands return version numbers, Node.js and npm have been successfully installed.

> 💡 **Tip:** If you receive a 'command not found' error, try restarting your computer. This often helps your system recognize the newly added PATH variables.

### Step 5: Update npm to the Latest Version (Recommended)

While npm comes bundled with Node.js, it is often updated more frequently than Node.js itself. To ensure you have the latest features and bug fixes, it's a good practice to update npm. Open your terminal and run the command: `npm install -g npm@latest`.

> 💡 **Tip:** The `-g` flag ensures npm is installed globally, making it available system-wide. You might need to run this command with administrator privileges on some systems.

### Step 6: Start Using npm

With npm successfully installed and updated, you're ready to start managing your JavaScript projects. You can use `npm init` to create a new `package.json` file for your project, or `npm install <package-name>` to add dependencies. Explore the vast npm registry to find packages for your development needs. For more comprehensive guidance, see [How to Install npm: A Comprehensive Step-by-Step Guide](/en/how-to-install-npm).

> 💡 **Tip:** Familiarize yourself with common npm commands like `npm install`, `npm run`, and `npm uninstall` to efficiently manage your project dependencies.


## Tips & Tricks

- For development, consider using a Node Version Manager (like nvm for Linux/macOS or nvm-windows for Windows) to easily switch between different Node.js and npm versions for various projects.
- If you encounter permission errors when installing global packages, try configuring npm's default directory for global packages instead of using `sudo` or running your terminal as an administrator.
- Regularly check for updates to Node.js and npm to benefit from performance improvements, security patches, and new features.

## Warnings

- ⚠️ Avoid installing Node.js and npm using `sudo` directly for global packages unless absolutely necessary, as it can lead to permission issues. Consider using a Node Version Manager or configuring npm's default directory for global packages if you face permission errors without `sudo`.

## Frequently Asked Questions

**How do I install npm?**

npm is typically installed automatically when you install Node.js. Download the Node.js installer from nodejs.org, run it, and follow the on-screen prompts to complete the installation. After installation, verify by checking the npm version in your terminal.

**How to install npm in Windows?**

On Windows, download the `.msi` installer from the official Node.js website. Run the installer, accept the license agreement, and proceed with the default installation options. npm will be included as part of the Node.js installation.

**How to install npm on Mac?**

For macOS, download the `.pkg` installer from nodejs.org and run the package installer, following the guided steps. Alternatively, you can use Homebrew by running `brew install node` in your terminal, which will also install npm.

**How to install npm in Ubuntu?**

To install npm on Ubuntu, it's recommended to install Node.js using a NodeSource PPA for the latest versions. Alternatively, you can use `sudo apt install nodejs npm` from the default repositories, though this might provide an older version of Node.js and npm.

**How can I verify if npm is installed correctly?**

Open your terminal or command prompt and type `npm -v`. If npm is installed, it will display its version number. You can also type `node -v` to check the Node.js version, confirming both are operational.

**Do I need to install npm separately after installing Node.js?**

No, npm is bundled with Node.js. When you install Node.js using the official installer, npm is automatically installed alongside it. You only need to update npm separately if you want the very latest version, as npm updates independently.

**What is the recommended way to install Node.js and npm?**

The official and most recommended method is to download the appropriate installer for your operating system directly from the Node.js website (nodejs.org). This ensures you get a stable release and a complete installation package, including npm.

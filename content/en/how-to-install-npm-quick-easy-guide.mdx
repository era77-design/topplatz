To install npm, you typically install Node.js, which bundles npm by default. This process involves downloading the appropriate Node.js installer for your operating system and following the setup wizard, or using a package manager for Linux. Once Node.js is installed, npm will be ready for use, allowing you to manage JavaScript packages for your projects. For a more detailed walkthrough, you can also refer to our [How to Install npm: A Step-by-Step Guide for Developers](/en/how-to-install-npm-step-by-step-guide).

## What You Need

- Computer (Windows, macOS, or Linux)
- Internet connection
- Terminal or Command Prompt

## Steps

### Step 1: Understand npm and Node.js Relationship

npm, the Node Package Manager, is automatically installed when you install Node.js. This means you don't typically install npm separately. Node.js is a JavaScript runtime environment that allows you to run JavaScript on the server side, and npm is its default package manager for managing project dependencies.

### Step 2: Download Node.js Installer

Navigate to the official Node.js website (nodejs.org) in your web browser. On the homepage, you will see two recommended versions for download: the LTS (Long Term Support) version and the Current version. For most users, the LTS version is recommended as it's more stable and supported for a longer period. Download the installer appropriate for your operating system (Windows, macOS).

### Step 3: Install Node.js on Windows or macOS

Once the Node.js installer is downloaded, locate the file (usually in your Downloads folder) and double-click it to begin the installation process. Follow the prompts in the installation wizard, accepting the license agreement and the default installation location. Ensure that the 'npm package manager' component is selected for installation, which it is by default. Complete the installation, and Node.js along with npm will be set up on your system.

### Step 4: Install Node.js on Linux (e.g., Ubuntu)

For Linux distributions like Ubuntu, it's often best to use your system's package manager. Open your terminal and first update your package list with `sudo apt update`. Then, you can install Node.js and npm using `sudo apt install nodejs npm`. This command will fetch and install the stable versions available in your distribution's repositories. Some distributions might require additional steps to get the latest Node.js versions; consult official Node.js documentation for specific instructions for your distro.

### Step 5: Verify Node.js and npm Installation

After the installation is complete, open your terminal or command prompt to verify that both Node.js and npm have been successfully installed. Type `node -v` and press Enter; this should display the installed Node.js version. Next, type `npm -v` and press Enter; this should show the installed npm version. If both commands return version numbers, your installation was successful.

### Step 6: Update npm to the Latest Version (Optional)

While npm is installed with Node.js, it might not always be the very latest version. It's good practice to update npm periodically. In your terminal or command prompt, run the command `npm install -g npm@latest`. The `-g` flag ensures that npm is updated globally. This command will download and install the newest stable version of npm, keeping your package manager up-to-date.


## Tips & Tricks

- Always use the official Node.js website (nodejs.org) for downloads to ensure you get legitimate and secure installers.
- If you encounter permission errors when installing packages globally, especially on Linux or macOS, you might need to use `sudo` before your `npm install -g` command, or consider configuring npm for a non-sudo global installation.
- For managing multiple Node.js versions on a single machine, consider using a Node Version Manager (NVM) like nvm (for macOS/Linux) or nvm-windows (for Windows).
- On Windows, if commands are not recognized after installation, try restarting your terminal or even your computer to ensure environment variables are fully updated.

## Warnings

- ⚠️ Ensure you have administrator or sudo privileges when running the Node.js installer or using package managers to install Node.js and npm.
- ⚠️ Be cautious when installing packages globally (`npm install -g`) as they can affect all projects on your system. Prefer local installation (`npm install`) for project-specific dependencies.

## Frequently Asked Questions

**How do I install npm?**

You install npm by installing Node.js, as npm comes bundled with it. Download the Node.js installer from nodejs.org, run it, and follow the setup wizard. For Linux, use your distribution's package manager like `sudo apt install nodejs npm`.

**How to install npm in Windows?**

To install npm in Windows, download the Node.js `.msi` installer from nodejs.org. Run the installer, accept the default settings, and ensure the 'npm package manager' component is selected. After installation, verify by opening Command Prompt and typing `npm -v`.

**How to install npm on Mac?**

To install npm on Mac, download the Node.js `.pkg` installer from nodejs.org. Double-click the installer and follow the on-screen instructions to complete the setup. Once finished, open your Terminal and use `npm -v` to confirm npm is installed.

**How to install npm on Ubuntu?**

To install npm on Ubuntu, open your terminal and run `sudo apt update` followed by `sudo apt install nodejs npm`. This will install Node.js and npm from Ubuntu's repositories. You can verify the installation with `node -v` and `npm -v`.

**What is npm and why do I need it?**

npm (Node Package Manager) is the default package manager for Node.js. You need it to discover, install, publish, and manage JavaScript packages (libraries, frameworks, and tools) that your projects depend on, making development more efficient and modular.

**How do I update npm to the latest version?**

To update npm to its latest version, open your terminal or command prompt and execute the command `npm install -g npm@latest`. The `-g` flag ensures that the update is applied globally to your system.

**What should I do if npm commands are not recognized after installation?**

If npm commands are not recognized, first try restarting your terminal or command prompt. On Windows, a system restart might be necessary to update environment variables. Ensure Node.js was installed correctly and its installation directory is included in your system's PATH variable. You can also refer to our [How to Install npm: A Quick Start Guide](/en/how-to-install-npm-quick-start) for troubleshooting.

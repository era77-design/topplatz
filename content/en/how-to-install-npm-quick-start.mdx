Installing npm, the Node.js package manager, is essential for web development, allowing you to manage project dependencies efficiently. The simplest way to install npm is by installing Node.js, which bundles npm automatically. This guide will walk you through the process on various operating systems.

## What You Need

- Computer with internet access
- Administrator/sudo privileges
- Web browser
- Terminal or Command Prompt

## Steps

### Step 1: Understand the Node.js and npm Relationship

npm, which stands for Node Package Manager, is automatically installed when you install Node.js. Node.js is an open-source, cross-platform JavaScript runtime environment that executes JavaScript code outside a web browser. Therefore, to get npm, you simply need to install Node.js.

> 💡 **Tip:** For a more in-depth overview of npm and its functionalities, refer to our comprehensive guide: [How to Install npm: A Complete Guide for All OS](/en/how-to-install-npm-complete-guide).

### Step 2: Download the Node.js Installer

Navigate to the official Node.js website (nodejs.org) in your web browser. You will typically see two recommended versions: the LTS (Long Term Support) version, which is stable and recommended for most users, and the Current version, which includes the latest features. Download the LTS version suitable for your operating system.

### Step 3: Install Node.js on Windows or macOS

Once the Node.js installer is downloaded, locate the file (e.g., `.msi` for Windows, `.pkg` for macOS) and run it. Follow the on-screen instructions, accepting the default installation settings. This process will install both Node.js and npm on your system.

> 💡 **Tip:** It's generally safe to accept the default installation paths unless you have specific reasons to change them.

### Step 4: Install Node.js on Linux (e.g., Ubuntu/Debian)

For Linux distributions like Ubuntu, the recommended way to install Node.js and npm is via the NodeSource repository. Open your terminal and run the following commands to add the repository and install Node.js:
```bash
curl -fsSL https://deb.nodesource.com/setup_lts.x | sudo -E bash -
sudo apt-get install -y nodejs
```
This ensures you get a recent, stable version.

> 💡 **Tip:** For other Linux distributions, consult the Node.js website for specific installation instructions using their respective package managers (e.g., `dnf` for Fedora, `pacman` for Arch Linux).

### Step 5: Verify the Installation

After the installation completes, open a new terminal or command prompt window. Type `node -v` and press Enter to check the Node.js version, then type `npm -v` and press Enter to check the npm version. Both commands should display version numbers, confirming a successful installation.

> 💡 **Tip:** If you see "command not found" errors, try restarting your computer or checking your system's PATH environment variable to ensure Node.js and npm are accessible.

### Step 6: Update npm to the Latest Version (Optional)

While npm is installed with Node.js, it's often a good practice to update npm to its very latest version independently. Open your terminal or command prompt and run `npm install -g npm@latest`. The `-g` flag ensures npm is updated globally across your system.

> 💡 **Tip:** Keeping npm updated ensures you have access to the newest features, bug fixes, and security patches for managing your project dependencies.


## Tips & Tricks

- Always download Node.js from the official website (nodejs.org) to ensure authenticity and security.
- After installing Node.js, always open a new terminal or command prompt window to ensure your system's PATH environment variable is updated.
- If you encounter issues, try reinstalling Node.js or consulting the official Node.js documentation for troubleshooting tips.

## Warnings

- ⚠️ Ensure you have administrative or sudo privileges on your system to perform the installation successfully.
- ⚠️ Only download installation files from the official Node.js website to avoid potential security risks from unofficial sources.

## Frequently Asked Questions

**How do I install npm?**

The easiest and recommended way to install npm is by downloading and installing Node.js from its official website. npm is bundled with Node.js, so installing one automatically installs the other.

**How to install npm in Windows?**

To install npm in Windows, download the Windows Installer (.msi) from the official Node.js website. Run the installer and follow the on-screen prompts, accepting the default settings to complete the installation.

**How to install npm on Mac?**

On macOS, you can install npm by downloading the macOS Installer (.pkg) from the Node.js official site and running it. Alternatively, if you use Homebrew, you can install Node.js (and thus npm) with the command `brew install node`.

**How to install npm on Ubuntu?**

To install npm on Ubuntu, the recommended method is to use NodeSource repositories. First, add the repository using `curl`, then update your package list and install Node.js (which includes npm) via `sudo apt install nodejs`.

**What is the best way to install npm?**

For most users, installing the Long Term Support (LTS) version of Node.js directly from the official Node.js website is the best way to install npm. This ensures you get a stable version of both Node.js and its bundled npm.

**How do I verify if npm is installed?**

After installation, open your terminal or command prompt and type `npm -v`. This command will display the installed npm version, confirming a successful installation. You can also verify Node.js with `node -v`.

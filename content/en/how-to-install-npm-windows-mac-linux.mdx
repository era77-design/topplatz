npm (Node Package Manager) is the default package manager for Node.js, essential for managing project dependencies and sharing code. This guide provides a straightforward, step-by-step process to install npm on various operating systems, including Windows, macOS, and Linux. For a more comprehensive overview of npm installation across all operating systems, refer to our [How to Install npm: Step-by-Step Guide for All OS](/en/how-to-install-npm-guide-all-os).

## What You Need

- Internet connection
- Command Line Interface (Terminal, PowerShell, or Command Prompt)
- Node.js installer (npm is bundled with it)

## Steps

### Step 1: Understand npm and its Relationship with Node.js

npm is the package manager for the JavaScript runtime environment Node.js. It comes bundled with Node.js, meaning that when you install Node.js, npm is automatically installed alongside it. This simplifies the installation process significantly, as you typically only need to install one package.

### Step 2: Download the Node.js Installer

Visit the official Node.js website (nodejs.org) to download the appropriate installer for your operating system. It's generally recommended to choose the LTS (Long Term Support) version, as it offers the most stability and is suitable for most users. Select the installer file that matches your system (e.g., .msi for Windows, .pkg for macOS, or binaries for Linux).

### Step 3: Install Node.js on Your System

Run the downloaded installer. For Windows and macOS, simply follow the on-screen prompts, accepting the license agreement and default installation locations. For Linux, you might use your system's package manager (e.g., `sudo apt install nodejs npm` for Debian/Ubuntu-based systems, or follow instructions for other distributions) or manually install the downloaded binaries.

> 💡 **Tip:** For most users, accepting the default installation options during the setup wizard is perfectly fine. These options ensure that Node.js and npm are correctly configured and added to your system's PATH.

### Step 4: Verify Node.js and npm Installation

Once the installation is complete, open your command line interface (Terminal on macOS/Linux, Command Prompt or PowerShell on Windows). Type `node -v` and press Enter to check the Node.js version. Then, type `npm -v` and press Enter to check the npm version. Both commands should display version numbers, confirming a successful installation.

> 💡 **Tip:** If the commands are not recognized, try closing and reopening your terminal or command prompt. Sometimes, the system's PATH environment variable needs to refresh to recognize new installations.

### Step 5: Update npm to the Latest Version (Optional but Recommended)

Although npm comes bundled with Node.js, it's often updated more frequently than Node.js itself. To ensure you have the latest features and security patches for npm, you can update it independently. Open your command line and run: `npm install -g npm@latest`.

> 💡 **Tip:** The `-g` flag means 'global' installation, making npm available across your entire system. This is the standard way to update npm itself.

### Step 6: Test npm by Initializing a Project (Optional)

To further confirm npm's functionality, you can quickly initialize a new project. Navigate to an empty directory in your terminal and run `npm init -y`. This command creates a `package.json` file, which is the heart of any npm project. You can then try installing a simple package like `npm install lodash` to see it in action.

> 💡 **Tip:** The `package.json` file tracks your project's metadata and dependencies. The `-y` flag answers 'yes' to all prompts, quickly generating the file.


## Tips & Tricks

- Always prefer the LTS (Long Term Support) version of Node.js for production environments due to its stability and extended support.
- If you plan to work with multiple Node.js versions, consider using a Node Version Manager (NVM). It allows you to easily install, switch, and manage different Node.js and npm versions.
- Regularly update npm using `npm install -g npm@latest` to benefit from the newest features, performance improvements, and security fixes.

## Warnings

- ⚠️ Be cautious when running `npm install -g <package-name>` as it installs packages globally, which can sometimes lead to permission issues or conflicts between projects. Understand a package's purpose before installing it globally.
- ⚠️ Ensure you have administrative privileges (or use `sudo` on Linux/macOS) when running global npm commands if you encounter permission errors during installation or updates.

## Frequently Asked Questions

**How do I install npm?**

You typically install npm by installing Node.js, as npm is bundled with it. Download the Node.js installer from nodejs.org, run it, and follow the setup wizard. npm will be included automatically.

**How to install npm in Windows?**

To install npm in Windows, download the Windows Installer (.msi) for Node.js from the official nodejs.org website. Run the installer and follow the prompts, accepting the default settings. npm will be installed along with Node.js.

**How to install npm on Mac?**

For macOS, download the macOS Installer (.pkg) from the Node.js official website. Execute the installer and proceed through the installation wizard. npm will be automatically bundled with your Node.js installation.

**How to install npm on Ubuntu?**

On Ubuntu, the recommended way to install npm is by first installing Node.js through your terminal. You can use `sudo apt update` followed by `sudo apt install nodejs npm`. This command ensures both Node.js and npm are installed and configured correctly.

**Can I install npm without Node.js?**

While it's technically possible, it is not recommended to install npm without Node.js. npm is designed to work as the package manager for Node.js and relies on its runtime environment. The easiest and most supported method is to install Node.js, which includes npm.

**How do I verify if npm is installed correctly?**

After installation, open your terminal or command prompt and type `npm -v`. If npm is installed correctly, it will display its version number. You can also check the Node.js version with `node -v`.

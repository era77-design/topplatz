Installing npm (Node Package Manager) is a crucial step for JavaScript developers and anyone working with Node.js projects. Since npm is bundled with Node.js, the primary method involves installing Node.js itself. This guide will walk you through the straightforward process on various operating systems, ensuring you're ready to manage your project dependencies.

## What You Need

- Computer with internet access
- Administrator privileges
- Terminal or Command Prompt

## Steps

### Step 1: Check for Existing Node.js and npm Installation

Before you begin, it's good practice to check if Node.js and npm are already installed on your system. Open your terminal (macOS/Linux) or Command Prompt/PowerShell (Windows) and type `node -v` and then `npm -v`. If you see version numbers, they are installed. If not, or if the versions are very old, proceed with a fresh installation or update.

### Step 2: Download the Node.js Installer

The recommended way to install npm is by installing Node.js, which comes with npm bundled. Visit the official Node.js website (nodejs.org) and download the LTS (Long Term Support) version installer for your operating system. This ensures stability and includes the latest stable npm version. For a more in-depth look, check out this [How to Install npm: A Step-by-Step Guide for All OS](/en/how-to-install-npm).

### Step 3: Install on Windows or macOS

Locate the downloaded Node.js installer file (usually a `.msi` for Windows or `.pkg` for macOS) and double-click to run it. Follow the on-screen prompts, accepting the license agreement and default installation settings. The installer will automatically configure Node.js and npm, adding them to your system's PATH. Restart your terminal after installation for changes to take effect.

### Step 4: Install on Ubuntu or Other Linux Distributions

For Linux, the recommended method is to use NodeSource's binary distributions for better compatibility and newer versions than default repository packages. First, install `curl` if you don't have it: `sudo apt install curl`. Then, use `curl -fsSL https://deb.nodesource.com/setup_lts.x | sudo -E bash -` to add the NodeSource repository, followed by `sudo apt install nodejs` to install Node.js and npm. This ensures you get a stable and up-to-date version.

### Step 5: Verify the Installation

After the installation is complete, open a new terminal or command prompt window. Type `node -v` and press Enter, then type `npm -v` and press Enter. You should now see the installed version numbers for both Node.js and npm, confirming a successful installation. If you encounter issues, ensure your system's PATH environment variable is correctly configured.

### Step 6: Update npm to the Latest Version (Optional but Recommended)

While npm comes bundled with Node.js, it's often updated more frequently than Node.js itself. To ensure you have the very latest version of npm, you can update it independently. In your terminal, run the command `npm install -g npm@latest`. This command globally installs the newest npm version, keeping your package manager up-to-date with the latest features and bug fixes. For developers, keeping npm current is an essential practice.


## Tips & Tricks

- Always install the LTS (Long Term Support) version of Node.js for most projects, as it offers the best stability and ongoing support.
- If you manage multiple Node.js versions, consider using a version manager like NVM (Node Version Manager) for easier switching between environments.
- After installing or updating npm, always restart your terminal or command prompt to ensure that the system recognizes the new paths and versions.

## Warnings

- ⚠️ Always download installers from the official Node.js website (nodejs.org) to avoid potential security risks from unofficial sources.
- ⚠️ Be cautious when running `sudo` commands on Linux, as they grant elevated privileges and should only be used when necessary and with trusted sources.

## Frequently Asked Questions

**How do I install npm on Windows?**

To install npm on Windows, download the `.msi` installer from the official Node.js website (nodejs.org). Run the installer, follow the prompts, and accept the default settings. Node.js, along with npm, will be automatically installed and added to your system's PATH.

**What's the easiest way to install npm on macOS?**

The easiest way to install npm on macOS is by downloading and running the `.pkg` installer from nodejs.org. The graphical installer guides you through the process, ensuring Node.js and npm are correctly set up on your system.

**How can I install npm on Ubuntu or other Linux distributions?**

For Ubuntu, the recommended method is to use NodeSource's repository. First, add the repository using `curl -fsSL https://deb.nodesource.com/setup_lts.x | sudo -E bash -`, then install Node.js and npm with `sudo apt install nodejs`. This provides a more up-to-date version than the default system repositories.

**What is npm and why do I need it?**

npm stands for Node Package Manager, and it's the default package manager for Node.js. You need it to install, manage, and share reusable code packages (libraries, frameworks, tools) for your JavaScript projects, making development faster and more efficient. It's an essential tool for almost all modern web development workflows.

**How do I update npm to the latest version?**

To update npm to its latest version, open your terminal or command prompt and run the command `npm install -g npm@latest`. The `-g` flag ensures it's installed globally, making it available system-wide. This keeps your package manager up-to-date with new features and bug fixes.

**Do I need to install Node.js and npm separately?**

No, you do not need to install Node.js and npm separately. When you install Node.js using its official installer or package manager, npm is automatically included and installed alongside it. npm is bundled with Node.js, so installing one typically installs the other.

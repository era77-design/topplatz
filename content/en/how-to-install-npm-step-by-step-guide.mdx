To install npm, you first need to install Node.js, as npm is bundled with it. Download the appropriate Node.js installer for your operating system from the official website. Once Node.js is installed, npm will be automatically available for use in your terminal or command prompt. For a comprehensive overview, see our [How to Install npm: A Step-by-Step Guide for All Platforms](/en/how-to-install-npm-guide-all-platforms).

## What You Need

- Computer
- Internet connection
- Web browser
- Administrator privileges (for installation)

## Steps

### Step 1: Check for Existing Node.js and npm Installation

Before proceeding with a new installation, it's good practice to check if Node.js and npm are already present on your system. Open your terminal or command prompt and execute the commands `node -v` and `npm -v` separately. If you receive version numbers as output, it indicates they are installed. If you get an error, they are not, or they are not correctly configured in your system's PATH.

> 💡 **Tip:** If you have an older version of Node.js or npm, consider using a version manager like `nvm` (Node Version Manager) to manage multiple versions, or uninstalling the old version before installing a new one.

### Step 2: Download the Node.js Installer

npm comes bundled with Node.js, meaning you cannot install npm without first installing Node.js. Visit the official Node.js website (nodejs.org) and download the Long Term Support (LTS) version installer for your specific operating system. The LTS version is highly recommended for most users due to its stability and long-term support. For detailed instructions tailored to your OS, refer to our [How to Install npm: Step-by-Step for Windows, Mac & Linux](/en/how-to-install-npm-windows-mac-linux) guide.

> 💡 **Tip:** Always ensure you download the correct installer file (.msi for Windows, .pkg for macOS, or specific packages for Linux distributions) that matches your system architecture (e.g., 64-bit).

### Step 3: Run the Node.js Installer

Locate the downloaded Node.js installer file and execute it. Follow the prompts provided by the installation wizard. For most users, accepting the default installation settings is sufficient and recommended, as it will correctly set up Node.js and npm, along with updating your system's PATH environment variable. The wizard will guide you through the entire setup process.

> 💡 **Tip:** On Windows, you might need to right-click the installer and select 'Run as administrator' to ensure it has the necessary permissions. On macOS, simply double-clicking the .pkg file will start the installation.

### Step 4: Verify the Installation

After the installation process is complete, it is crucial to reopen your terminal or command prompt. This step ensures that your system recognizes the newly updated PATH environment variables. Once reopened, type `node -v` and `npm -v` again. You should now see the installed version numbers for both Node.js and npm, confirming that the installation was successful and they are ready for use.

> 💡 **Tip:** If you still encounter 'command not found' errors, try restarting your computer completely. This can sometimes resolve issues with environment variables not being refreshed.

### Step 5: Update npm (Optional but Recommended)

While npm is installed with Node.js, it often receives updates more frequently than Node.js itself. To ensure you're running the latest stable version of npm, which includes the newest features and bug fixes, open your terminal or command prompt and execute the command `npm install -g npm@latest`. This command globally updates npm to its most recent stable release.

> 💡 **Tip:** Keeping npm updated can prevent compatibility issues with newer packages and provide access to performance improvements and security patches.


## Tips & Tricks

- Always use the LTS (Long Term Support) version of Node.js for production applications, as it provides maximum stability and extended maintenance.
- If you encounter permission errors when running npm commands on Linux or macOS, you might need to use `sudo` (e.g., `sudo npm install -g <package>`), but be cautious as this grants elevated privileges.
- Consider using a Node Version Manager (NVM) like `nvm` (for macOS/Linux) or `nvm-windows` if you need to switch between different Node.js and npm versions for various projects.

## Warnings

- ⚠️ Be cautious when running commands with `sudo` on Linux/macOS, as it grants elevated privileges and can potentially affect system files if used incorrectly.
- ⚠️ Always download Node.js installers from the official Node.js website (nodejs.org) to ensure you are getting legitimate software and to avoid malware or corrupted files.

## Frequently Asked Questions

**How do I install npm?**

You install npm by first installing Node.js, as npm is automatically included with Node.js. Visit the official Node.js website, download the installer for your operating system, and follow the installation wizard. After Node.js is installed, npm will be available in your terminal or command prompt.

**How to install npm in Windows?**

To install npm in Windows, download the Windows installer (.msi file) from the official Node.js website. Run the installer, follow the prompts, and accept the default settings. Once Node.js is installed, npm will be accessible via Command Prompt or PowerShell, ready for use.

**How to install npm on Mac?**

To install npm on Mac, download the macOS installer (.pkg file) from the official Node.js website. Double-click the package to initiate the installer and follow the on-screen instructions. After the installation completes, verify by typing `npm -v` in your terminal to confirm npm is correctly installed.

**How to install npm in Ubuntu or on Ubuntu?**

To install npm on Ubuntu, it's generally recommended to first install Node.js using a version manager like NVM, which also installs npm. Alternatively, you can use `sudo apt update` followed by `sudo apt install nodejs npm` through your terminal, though this method might provide an older version of Node.js and npm.

**What are the prerequisites to install npm?**

The main prerequisites to install npm are a computer with an internet connection to download the Node.js installer and sufficient administrator privileges to run the installation package. Since npm comes bundled with Node.js, no separate npm-specific prerequisites are typically needed.

**Can I install npm without Node.js?**

No, you cannot install npm without Node.js. npm (Node Package Manager) is distributed as an integral part of Node.js. This means that when you install Node.js, npm is automatically installed alongside it, and they are designed to function together.

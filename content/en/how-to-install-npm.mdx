To install npm, you typically install Node.js, which bundles npm with it. The recommended method is to download the official Node.js installer for your operating system (Windows, macOS, or Linux) and follow the installation wizard. This ensures you get a stable version of both Node.js and npm, providing a simple, step-by-step installation process. For a more detailed walkthrough, consider checking out our [How to Install npm: A Simple Step-by-Step Guide](/en/how-to-install-npm-step-by-step).

## What You Need

- Computer with internet access
- Administrator or sudo privileges
- Terminal or Command Prompt

## Steps

### Step 1: Understand Node.js and npm Relationship

Before you begin, it's important to know that npm (Node Package Manager) is automatically installed when you install Node.js. Node.js is a JavaScript runtime environment that allows you to run JavaScript code outside of a web browser. npm is the default package manager for Node.js, used to manage your project's dependencies and share tools.

### Step 2: Download the Node.js Installer

Navigate to the official Node.js website (nodejs.org) in your web browser. You will typically see two recommended versions: an LTS (Long Term Support) version and a Current version. For most users, the LTS version is recommended as it's more stable and thoroughly tested. Download the installer package appropriate for your operating system (Windows, macOS, or Linux).

### Step 3: Install Node.js on Windows or macOS

For Windows and macOS, the installation process is straightforward. Locate the downloaded installer file (usually a .msi for Windows or .pkg for macOS) and double-click to run it. Follow the prompts in the installation wizard, accepting the license agreement and choosing the default installation options. Ensure that 'npm package manager' is selected for installation, which it is by default. Complete the installation.

### Step 4: Install Node.js on Linux (Ubuntu/Debian Example)

On Linux distributions like Ubuntu or Debian, you can install Node.js and npm via your system's package manager. First, update your package list by running `sudo apt update`. Then, install Node.js by executing `sudo apt install nodejs npm`. This command will install both Node.js and npm. Some Linux distributions might require additional steps to get the latest versions; refer to Node.js documentation for specific distribution instructions.

### Step 5: Verify the Installation

After the installation is complete, open your terminal or Command Prompt. To verify that Node.js and npm were installed successfully, type the following commands and press Enter after each: `node -v` and `npm -v`. If the installation was successful, these commands will output the version numbers of Node.js and npm, respectively. This confirms that both tools are correctly configured in your system's PATH.

### Step 6: Update npm to the Latest Version (Optional)

While npm is installed with Node.js, it's often a good practice to update npm itself to its latest stable version independently. Open your terminal or Command Prompt and run the command: `npm install -g npm@latest`. The `-g` flag ensures that npm is updated globally across your system. This step helps you access the newest features and bug fixes of the package manager.


## Tips & Tricks

- Consider using Node Version Manager (nvm) for macOS/Linux or nvm-windows for Windows if you need to manage multiple Node.js versions on a single machine. It simplifies switching between projects requiring different Node.js versions.
- Always download installers from the official Node.js website (nodejs.org) to ensure you get legitimate, untampered software.
- If you encounter permission errors when installing packages globally, consider using nvm or configuring npm to install packages in a user-specific directory instead of using `sudo` with `npm install -g`.

## Warnings

- ⚠️ Avoid installing npm directly via `sudo npm install -g` without understanding the implications, as it can lead to permission issues for future package installations. Using a Node Version Manager (like nvm) is generally a safer and more flexible approach.

## Frequently Asked Questions

**How do I install npm on Windows?**

To install npm on Windows, download the Node.js .msi installer from the official Node.js website (nodejs.org). Run the installer and follow the wizard's steps, accepting default options. npm is bundled with Node.js and will be installed automatically.

**How do I install npm on Mac?**

To install npm on Mac, download the Node.js .pkg installer from nodejs.org. Double-click the file and proceed through the installation wizard. npm comes included with Node.js, so once Node.js is installed, npm will be available.

**How do I install npm in Ubuntu?**

To install npm in Ubuntu, open your terminal and run `sudo apt update` followed by `sudo apt install nodejs npm`. This command will install both Node.js and its bundled package manager, npm, from Ubuntu's repositories.

**Does npm come with Node.js?**

Yes, npm (Node Package Manager) is automatically installed as part of the Node.js installation process. When you download and install Node.js, npm is included by default, making it readily available for managing your JavaScript packages.

**How can I check if npm is installed correctly?**

To verify if npm is installed correctly, open your terminal or Command Prompt and type `npm -v`. Press Enter, and if npm is installed, it will display its version number. You can also check Node.js with `node -v`.

**What is the best way to update npm?**

The best way to update npm is by running `npm install -g npm@latest` in your terminal or Command Prompt. This command globally installs the latest stable version of npm, ensuring you have the most up-to-date features and bug fixes.

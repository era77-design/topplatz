To install npm, you first need to install Node.js, as npm is bundled with it. The recommended method is to download the official Node.js installer for your operating system from the Node.js website. This process ensures you get both Node.js and npm set up correctly on your system.

## What You Need

- Computer with internet access
- Web browser
- Administrator privileges

## Steps

### Step 1: Check for Existing Node.js and npm

Before proceeding with a fresh installation, it's a good practice to check if Node.js or npm are already present on your system. Open your terminal (macOS/Linux) or Command Prompt (Windows) and type `node -v`, then press Enter. Follow this by typing `npm -v` and pressing Enter. If versions are displayed, they are installed; otherwise, you'll likely see an error message, indicating they are not found. This check helps prevent conflicts and ensures a clean installation.

### Step 2: Download the Node.js Installer

Navigate to the official Node.js website at `nodejs.org` using your web browser. On the homepage, you will typically see two main download options: the LTS (Long Term Support) version and the Current version. It is highly recommended to download the LTS version, as it offers greater stability and is suitable for most users and production environments. Click on the LTS download button, and the installer for your operating system will begin to download automatically.

### Step 3: Run the Node.js Installer

Once the download is complete, locate the installer file (e.g., `.msi` for Windows, `.pkg` for macOS) in your downloads folder and double-click to run it. Follow the on-screen prompts of the installation wizard, which typically involve clicking "Continue" or "Next" and agreeing to the license terms. For most users, accepting the default installation location and components is perfectly fine and recommended. Ensure you grant any necessary administrator permissions when prompted to proceed with the installation.

### Step 4: Verify Node.js and npm Installation

After the installation wizard finishes, close and then reopen your terminal or Command Prompt to ensure that the system's PATH variable is updated. In the new terminal window, run `node -v` again. You should now see the installed Node.js version number. Similarly, execute `npm -v` to confirm that npm has also been successfully installed and displays its version number. If both commands return version numbers, your installation was successful, and you're ready to use npm.

### Step 5: Update npm to the Latest Version

While npm is bundled with Node.js, it often receives updates independently. To ensure you have the latest features, bug fixes, and security patches for npm itself, it's a good practice to update it. Open your terminal or Command Prompt and run the command: `npm install -g npm@latest`. The `-g` flag ensures npm is installed globally, making it available system-wide. This command will download and install the newest version of npm, replacing your current global installation. For a more in-depth understanding of npm management, refer to a [complete guide for all OS](/en/how-to-install-npm-complete-guide).

> 💡 **Tip:** Regularly updating npm helps maintain a secure and efficient development environment.

### Step 6: Start Using npm

With Node.js and npm successfully installed and updated, you can now begin using npm to manage packages for your projects. Navigate to a project directory in your terminal and initialize a new Node.js project using `npm init`. You can then install external packages by running `npm install <package-name>`, which will add the package to your project's `node_modules` folder and update your `package.json` file. Explore the vast npm registry to find libraries and tools for your development needs.


## Tips & Tricks

- Always download installers from the official Node.js website (nodejs.org) to ensure authenticity and security.
- Consider using a Node.js version manager (like nvm for macOS/Linux or nvm-windows for Windows) if you need to switch between different Node.js versions for various projects.
- If you encounter issues, clearing the npm cache with `npm cache clean --force` can sometimes resolve persistent problems.
- Familiarize yourself with basic npm commands like `npm init`, `npm install`, `npm uninstall`, and `npm update` for efficient package management.

## Warnings

- ⚠️ Always download Node.js installers from the official nodejs.org website to avoid potential security risks from unofficial sources.
- ⚠️ Be cautious when running commands with `sudo` (macOS/Linux) or as an Administrator (Windows); ensure you understand their purpose to prevent unintended system changes.

## Frequently Asked Questions

**How do I install npm on Windows?**

On Windows, npm is installed automatically when you download and run the official Node.js MSI installer from nodejs.org. Simply follow the wizard, accept defaults, and npm will be ready to use in your Command Prompt. Verify by typing `npm -v` after installation.

**How do I install npm on macOS?**

For macOS, download the Node.js `.pkg` installer from nodejs.org. Run the installer and follow the prompts, which will install both Node.js and npm. After installation, open your Terminal and use `npm -v` to confirm it's correctly set up.

**How do I install npm on Ubuntu or other Linux distributions?**

On Ubuntu and other Linux distributions, the recommended way to install npm is by first installing Node.js using your distribution's package manager or an official NodeSource PPA. For example, on Ubuntu, you can often use `sudo apt install nodejs npm` after adding the NodeSource PPA. Always verify the installation with `npm -v`.

**Is npm automatically installed with Node.js?**

Yes, npm (Node Package Manager) is automatically bundled and installed alongside Node.js when you use the official Node.js installers from nodejs.org. This simplifies the setup process, ensuring you have both essential tools from the start.

**How can I check if npm is installed correctly?**

To verify your npm installation, open your terminal or Command Prompt and execute the command `npm -v`. If npm is installed correctly, it will display its version number, indicating it's ready for use. If you receive an error, the installation may not have completed successfully or the PATH variable isn't updated.

**What should I do if npm is not found after installing Node.js?**

If npm isn't found, first ensure you've restarted your terminal or Command Prompt after installing Node.js, as this often refreshes the system's PATH. If the issue persists, you might need to reinstall Node.js, ensuring you use the official installer, or manually check your system's PATH environment variable.

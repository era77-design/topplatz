To install npm, you primarily need to install Node.js, as npm (Node Package Manager) is bundled with it. This process involves downloading the appropriate Node.js installer for your operating system and following the installation prompts. Once Node.js is installed, npm will be available from your command line.

## What You Need

- Computer with an internet connection
- Command-line interface (Terminal/Command Prompt)
- Administrator privileges (for installation)

## Steps

### Step 1: Understand Node.js and npm

Before you begin, it's important to know that npm is the default package manager for Node.js. This means when you install Node.js, npm is automatically installed alongside it. You do not need to install npm separately in most cases, as the Node.js installer handles both. Understanding this simplifies the installation process significantly.

> 💡 **Tip:** For a more detailed introduction to npm and Node.js, refer to our [How to Install npm: A Beginner's Step-by-Step Guide](/en/how-to-install-npm-beginner-guide).

### Step 2: Download Node.js Installer

Visit the official Node.js website (nodejs.org) to download the installer. You will typically see two recommended versions: an LTS (Long Term Support) version and a Current version. For most users, the LTS version is recommended as it's more stable and thoroughly tested. Select the installer that matches your operating system (Windows, macOS, or Linux) and system architecture (32-bit or 64-bit).

### Step 3: Run the Node.js Installer

Locate the downloaded installer file and double-click it to begin the installation process. Follow the on-screen prompts, accepting the license agreement and choosing the default installation options. The installer will automatically configure Node.js and npm for your system. Ensure that 'npm package manager' is selected as a component to be installed, which is usually the default.

> 💡 **Tip:** On macOS, you might be prompted for your administrator password. On Windows, you might see a User Account Control prompt asking for permission to make changes to your device.

### Step 4: Verify Node.js and npm Installation

After the installation completes, open your command-line interface (Command Prompt on Windows, Terminal on macOS/Linux). Type `node -v` and press Enter. This command should display the installed Node.js version. Next, type `npm -v` and press Enter. This command should display the installed npm version. If both commands return version numbers, Node.js and npm are successfully installed.

> 💡 **Tip:** If the commands are not recognized, try restarting your computer or opening a new command-line window to refresh environment variables.

### Step 5: Update npm (Optional but Recommended)

While npm is installed with Node.js, the bundled version might not always be the very latest. It's good practice to update npm to its latest stable version. In your command-line interface, run the command `npm install -g npm@latest`. The `-g` flag ensures npm is updated globally. This command will download and install the newest version of npm.

> 💡 **Tip:** Updating npm regularly helps you access the latest features and bug fixes, improving your development workflow.

### Step 6: Test Your npm Installation

To confirm that npm is fully functional, you can try installing a simple package. For example, open your command line and type `npm install -g express` to globally install the Express.js framework. If the installation completes without errors, your npm setup is working correctly and ready for use. You can then remove the package with `npm uninstall -g express` if you don't need it immediately.

> 💡 **Tip:** Experiment with installing other small, common packages to build confidence in your npm environment.


## Tips & Tricks

- Always use the LTS version of Node.js for production environments due to its stability and long-term support.
- Consider using a Node Version Manager (like NVM for Mac/Linux or NVM-Windows) if you need to switch between different Node.js and npm versions for various projects.
- Regularly update npm using `npm install -g npm@latest` to benefit from the newest features and security patches.
- If you encounter permission errors on macOS or Linux, try running your npm commands with `sudo` (e.g., `sudo npm install -g <package>`), but be mindful of the security implications.

## Warnings

- ⚠️ Installing global packages using `sudo` on Linux/macOS can sometimes lead to permission issues in your user directory. Consider setting up npm to work without `sudo`.
- ⚠️ Avoid installing packages globally unless absolutely necessary. Most project-specific dependencies should be installed locally within your project directory using `npm install <package-name>` without the `-g` flag.

## Frequently Asked Questions

**What is npm?**

npm stands for Node Package Manager. It is the default package manager for Node.js, used to install, share, and manage project dependencies. npm allows developers to easily access and utilize a vast ecosystem of open-source libraries and tools.

**How to install npm in Windows?**

To install npm in Windows, download the Windows Installer (.msi) from the official Node.js website (nodejs.org). Run the installer and follow the prompts, ensuring that the 'npm package manager' component is selected during installation. After installation, verify by opening Command Prompt and typing `node -v` and `npm -v`.

**How to install npm on Mac?**

To install npm on Mac, download the macOS Installer (.pkg) from the official Node.js website. Run the package installer and proceed through the steps. Alternatively, you can use Homebrew with `brew install node`. Verify your installation by opening Terminal and running `node -v` and `npm -v`.

**How to install npm on Ubuntu?**

To install npm on Ubuntu, the recommended method is to install Node.js via the official NodeSource repository. First, add the repository using `curl -fsSL https://deb.nodesource.com/setup_lts.x | sudo -E bash -`, then install with `sudo apt-get install -y nodejs`. Verify with `node -v` and `npm -v` in your terminal.

**Do I need to install npm separately from Node.js?**

No, in most modern installations, npm comes bundled with Node.js. When you download and install Node.js from its official website, npm is automatically included. You typically do not need to perform a separate installation for npm itself.

**How do I update npm to the latest version?**

To update npm to its latest version, open your command-line interface and run the command `npm install -g npm@latest`. This command globally installs the newest stable version of npm, overwriting the existing one. It's a good practice to do this periodically.

**What if the 'npm' command is not found after installation?**

If the 'npm' command is not found, it usually means your system's PATH environment variable hasn't been updated or refreshed. Try restarting your command-line interface or your computer. Ensure that Node.js was installed correctly and that the installation directory is included in your system's PATH.

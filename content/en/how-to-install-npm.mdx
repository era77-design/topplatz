Installing npm, the Node.js package manager, is typically done by installing Node.js itself, as npm comes bundled with it. This guide will walk you through the most common and recommended methods to get npm up and running on your system, preparing you for web development tasks. For a more comprehensive overview, you can refer to [How to Install npm: A Complete Guide for All OS](/en/how-to-install-npm-complete-guide).

## What You Need

- A computer (Windows, macOS, or Linux)
- Internet connection
- Administrator or sudo privileges
- Terminal or Command Prompt

## Steps

### Step 1: Understand npm and Node.js

npm, which stands for 'Node Package Manager', is the default package manager for Node.js, a JavaScript runtime environment. When you install Node.js, npm is automatically installed alongside it, allowing you to manage libraries and packages for your JavaScript projects. Familiarizing yourself with both is the first step to effective development.

### Step 2: Download the Node.js Installer

The simplest and most recommended way to install npm is by downloading the Node.js installer from its official website. Visit `nodejs.org` and download the LTS (Long Term Support) version, which is typically more stable and suitable for most users. This installer package includes both Node.js and npm.

> 💡 **Tip:** Always download Node.js from the official website to ensure you get a legitimate and secure version of the software.

### Step 3: Install Node.js (and npm) on Windows or macOS

Once the installer package is downloaded, run it. On Windows, follow the prompts, accepting the license agreement and choosing the installation location. On macOS, double-click the .pkg file and proceed through the installation wizard. In most cases, you can accept the default settings, as they will correctly configure Node.js and npm for your system.

### Step 4: Install Node.js (and npm) on Linux (Ubuntu/Debian)

For Linux distributions like Ubuntu or Debian, you can often install Node.js and npm using your system's package manager. Open your terminal and run `sudo apt update` to refresh your package list, then use `sudo apt install nodejs npm`. This command will fetch and install both Node.js and npm directly from your distribution's repositories.

> 💡 **Tip:** For more advanced Linux installations or managing multiple Node.js versions, consider using Node Version Manager (NVM).

### Step 5: Verify Your Installation

After the installation is complete, open your terminal or command prompt and verify that both Node.js and npm are installed correctly. Type `node -v` and press Enter; you should see the installed Node.js version. Similarly, type `npm -v` and press Enter to see the npm version. If both commands return version numbers, your installation was successful.

### Step 6: Update npm to the Latest Version

While npm comes bundled with Node.js, it's often updated more frequently than Node.js itself. To ensure you have the latest features and security patches for npm, you can update it independently. Open your terminal and run the command `npm install -g npm@latest`. This will globally update npm to its newest stable version without affecting your Node.js installation.


## Tips & Tricks

- Consider using a Node Version Manager (like NVM for macOS/Linux or NVM-Windows) if you need to switch between different Node.js and npm versions for various projects.
- If `npm` commands are not recognized after installation, ensure that the Node.js installation directory (which contains npm) is added to your system's PATH environment variable.
- Regularly check for updates to both Node.js and npm to benefit from performance improvements, new features, and security fixes.

## Warnings

- ⚠️ Always download Node.js and npm installers from the official `nodejs.org` website to avoid potential security risks from unofficial sources.
- ⚠️ Be cautious when installing global npm packages (`npm install -g package-name`), as they can sometimes conflict with other global packages or system settings.

## Frequently Asked Questions

**How to install npm in Windows?**

To install npm in Windows, download the official Node.js installer from nodejs.org. Run the .msi file and follow the setup wizard. npm is automatically included with the Node.js installation.

**How to install npm on Mac?**

On a Mac, you can install npm by downloading the Node.js .pkg installer from nodejs.org. Execute the installer and follow the prompts. Alternatively, you can use Homebrew with `brew install node`.

**How to install npm on Ubuntu or other Linux distributions?**

For Ubuntu and similar Linux distributions, open your terminal and use the command `sudo apt install nodejs npm`. This will install both Node.js and npm from your distribution's repositories.

**What is the recommended way to install npm?**

The most recommended way to install npm for general use is by downloading and installing the official Node.js installer package from nodejs.org, as npm is bundled with Node.js.

**How do I verify if npm is installed correctly?**

To verify npm installation, open your terminal or command prompt and type `npm -v`. If npm is installed correctly, it will display its version number.

**Can I install npm without Node.js?**

No, npm is the package manager for Node.js and is fundamentally tied to it. You cannot install npm independently; it always comes bundled with a Node.js installation.

**Why should I update npm separately?**

You should update npm separately because it often receives updates more frequently than Node.js. Updating npm ensures you have the latest features, bug fixes, and security enhancements for your package manager.

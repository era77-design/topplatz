Installing npm, the Node Package Manager, is essential for JavaScript development as it allows you to manage and share packages. The easiest and most common way to install npm is by installing Node.js, which bundles npm automatically. This guide will walk you through the process for various operating systems, ensuring you're ready to start your projects. For a more in-depth guide covering specific nuances for each OS, you can refer to our [How to Install npm: A Complete Step-by-Step Guide](/en/how-to-install-npm).

## What You Need

- Computer with internet access
- Administrator/sudo privileges
- Web browser
- Terminal or Command Prompt

## Steps

### Step 1: Understand Node.js and npm's Relationship

Before you begin, it's important to know that npm (Node Package Manager) is distributed with Node.js. This means when you install Node.js, npm is automatically installed alongside it. Node.js is a JavaScript runtime environment that allows you to run JavaScript code outside of a web browser, and npm is the default package manager for Node.js.

### Step 2: Download the Node.js Installer

Visit the official Node.js website at `nodejs.org`. You will see two recommended versions for download: the LTS (Long Term Support) version and the Current version. For most users, especially beginners, the LTS version is recommended due to its stability and active support. Click on the LTS version to download the appropriate installer for your operating system (Windows, macOS, or Linux).

### Step 3: Run the Node.js Installer

Locate the downloaded installer file (e.g., `.msi` for Windows, `.pkg` for macOS, or a binary for Linux). Double-click the installer to start the installation wizard. Follow the prompts, accepting the license agreement, choosing the installation directory (the default is usually fine), and ensuring 'npm package manager' is selected for installation. On Windows, ensure 'Add to PATH' is also selected. Complete the wizard.

### Step 4: Verify Node.js Installation

After the installation is complete, open your terminal (macOS/Linux) or Command Prompt/PowerShell (Windows). Type `node -v` and press Enter. If Node.js was installed successfully, you will see its version number displayed (e.g., `v18.17.0`). This confirms that Node.js is correctly set up on your system.

### Step 5: Verify npm Installation

With Node.js verified, you can now check npm. In the same terminal or command prompt, type `npm -v` and press Enter. You should see the npm version number displayed (e.g., `9.6.7`). If both commands return version numbers, then npm has been successfully installed and is ready for use on your system.

### Step 6: Update npm (Recommended)

It's a good practice to update npm to its latest version after installation, as the bundled version might not be the absolute newest. To do this, run the command `npm install -g npm@latest` in your terminal. The `-g` flag ensures that npm is updated globally. This command will download and install the most recent stable version of npm, ensuring you have the latest features and security updates.


## Tips & Tricks

- Always choose the LTS (Long Term Support) version of Node.js for production environments and general development due to its stability and longer support cycle.
- If you encounter permission errors during installation or when running npm commands, try running your terminal or command prompt as an administrator (Windows) or using `sudo` before your command (macOS/Linux).
- Periodically update npm using `npm install -g npm@latest` to benefit from performance improvements, new features, and critical security patches.

## Warnings

- ⚠️ Ensure you download Node.js from the official website (nodejs.org) to avoid installing malicious or outdated software from unofficial sources.
- ⚠️ Be cautious when running scripts or installing packages from unknown sources, as they could contain vulnerabilities or malicious code. Always review packages before adding them to your project.

## Frequently Asked Questions

**How do I install npm on Windows?**

Installing npm on Windows is straightforward. You simply download and run the Node.js MSI installer from the official Node.js website, which automatically bundles npm. Follow the wizard's prompts to complete the installation, ensuring 'npm package manager' is selected.

**How do I install npm on macOS?**

For macOS, you can install npm by downloading the Node.js `.pkg` installer from nodejs.org and following the installation prompts. Alternatively, users with Homebrew installed can easily install Node.js (and thus npm) using the command `brew install node` in their terminal.

**What's the best way to install npm on Ubuntu?**

The recommended way to install npm on Ubuntu is by first installing Node.js. You can do this using the NodeSource repository for the latest versions, or through `sudo apt install nodejs npm` for a stable version from Ubuntu's default repositories. NodeSource is generally preferred for newer versions.

**Is it possible to install npm without Node.js?**

No, npm is inextricably linked with Node.js. It is distributed as part of the Node.js installation package. When you install Node.js, npm is automatically included and installed alongside it; you cannot install npm as a standalone package.

**How do I check if npm is already installed?**

To check if npm is installed on your system, open your terminal or command prompt and type `npm -v`. If npm is installed, it will display its current version number. If it's not installed, you will typically receive an error message indicating the command was not found.

**Why should I update npm?**

Updating npm regularly ensures you have access to the latest features, performance improvements, and crucial security patches. It also helps in resolving compatibility issues that might arise with newer packages or Node.js versions, keeping your development environment robust.

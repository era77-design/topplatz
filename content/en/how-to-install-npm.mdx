To install npm, you primarily need to install Node.js, as npm is included in the Node.js installation package. The most straightforward method is to download the official Node.js installer for your specific operating system and follow the setup wizard, which will automatically set up both Node.js and npm.

## What You Need

- Computer with internet access
- Web browser
- Administrator or sudo privileges

## Steps

### Step 1: Check for Existing Node.js and npm Installations

Before you begin, it's a good idea to check if Node.js or npm are already installed on your system. Open your terminal (macOS/Linux) or Command Prompt/PowerShell (Windows) and type `node -v` and then `npm -v`. If versions are returned, they are installed. If not, or if you wish to update, proceed with the installation.

### Step 2: Download the Official Node.js Installer

Navigate to the official Node.js website (nodejs.org) using your web browser. You will typically see two recommended versions: an LTS (Long Term Support) version and the latest current version. For most users, the LTS version is recommended for its stability. Download the installer package that matches your operating system (Windows, macOS, or Linux).

### Step 3: Run the Node.js Installer

Once the download is complete, locate the installer file (e.g., `.msi` for Windows, `.pkg` for macOS, or a tarball for Linux). Double-click the installer to launch the setup wizard. You may be prompted for administrator credentials to proceed with the installation.

### Step 4: Follow the Installation Wizard Prompts

The Node.js setup wizard will guide you through the installation process. Accept the license agreement, choose the installation destination (the default path is usually fine), and ensure that the 'npm package manager' component is selected for installation. Continue clicking 'Next' and 'Install' until the process is complete.

### Step 5: Verify Your npm Installation

After the installation finishes, open a *new* terminal or Command Prompt window. This is important to ensure that your system's PATH environment variable is updated. Type `node -v` to confirm Node.js is installed, and then `npm -v` to confirm npm is also successfully installed and to see its version number. You should see version numbers displayed for both.

### Step 6: Update npm to the Latest Version (Optional)

Although npm is installed with Node.js, it's often updated more frequently. You can update npm to its latest version independently using the command line. In your terminal, type `npm install -g npm@latest`. This command globally installs the newest version of npm, ensuring you have the latest features and bug fixes.


## Tips & Tricks

- Consider using a Node Version Manager (NVM) like `nvm` for macOS/Linux or `nvm-windows` for Windows if you need to switch between different Node.js and npm versions for various projects.
- Always download Node.js installers from the official website (nodejs.org) to ensure security and prevent malware.
- If you encounter issues during installation, try restarting your computer and then running the verification steps again. For a more detailed troubleshooting guide, refer to resources like [How to Install npm: A Complete Step-by-Step Guide](/en/how-to-install-npm-guide).

## Warnings

- ⚠️ Always ensure you have administrator or sudo privileges when running the installer or performing global npm updates to avoid permission errors.
- ⚠️ Do not install Node.js or npm from untrusted sources, as this can compromise your system's security.

## Frequently Asked Questions

**How to install npm in Windows?**

To install npm in Windows, download the official Node.js `.msi` installer from nodejs.org. Run the installer, accept defaults, and ensure npm is selected. After installation, open a new Command Prompt and type `npm -v` to verify.

**How to install npm on Mac?**

On a Mac, download the official Node.js `.pkg` installer from nodejs.org. Run the package, follow the prompts, and let it complete. Open a new Terminal window and use `npm -v` to confirm the installation.

**How to install npm on Ubuntu?**

The recommended way to install npm on Ubuntu is by installing Node.js via its official package manager or using `nvm`. Alternatively, you can download the Node.js binary directly from nodejs.org. Verify with `npm -v` in your terminal.

**Why do I need npm?**

npm (Node Package Manager) is essential for JavaScript development as it allows you to install, manage, and share packages (libraries, frameworks, tools) for your Node.js projects. It's the world's largest software registry, providing access to millions of open-source packages.

**Is npm automatically installed with Node.js?**

Yes, npm is automatically installed when you install Node.js using the official installer. The Node.js installation package bundles npm, so you typically don't need to install it separately. You can verify this by checking the npm version after Node.js installation.

**How do I update npm?**

You can update npm to the latest version independently of Node.js. Open your terminal or Command Prompt and run the command `npm install -g npm@latest`. This will globally update your npm client to its most recent stable release.

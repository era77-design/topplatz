Installing npm (Node Package Manager) is essential for JavaScript development, as it allows you to manage project dependencies and run scripts. The easiest and recommended way to install npm is by first installing Node.js, which bundles npm automatically. For a more comprehensive overview, refer to our [How to Install npm: A Complete Step-by-Step Guide](/en/how-to-install-npm).

## What You Need

- A computer (Windows, macOS, or Linux)
- Internet connection
- Administrative privileges

## Steps

### Step 1: Check for Existing Node.js and npm Installation

Before proceeding, it's a good practice to check if Node.js and npm are already installed on your system. Open your terminal or command prompt and execute `node -v` to check the Node.js version and `npm -v` for the npm version. If version numbers are displayed, they are already present, and you might only need to update them.

> 💡 **Tip:** If you find an older version, you can update npm after completing the installation process by running `npm install -g npm@latest`.

### Step 2: Download the Node.js Installer

Visit the official Node.js website at nodejs.org. The website will usually recommend the LTS (Long Term Support) version, which is stable and recommended for most users. Download the installer package that corresponds to your operating system (Windows, macOS, or Linux).

> 💡 **Tip:** Always download Node.js from the official website to ensure you get a legitimate and secure version of the software.

### Step 3: Run the Node.js Installer

Once the download is complete, locate the installer file in your downloads folder and run it. Follow the on-screen prompts, accepting the license agreement and choosing the default installation location. The installer will automatically set up Node.js and npm, adding them to your system's PATH environment variable.

> 💡 **Tip:** For most users, accepting the default installation options is sufficient and recommended for a smooth setup.

### Step 4: Verify the Installation

After the installation process finishes, open a *new* terminal or command prompt window. This is important to ensure your system's PATH variable is refreshed. Run `node -v` and `npm -v` again. You should now see the version numbers for Node.js and npm, confirming that they have been successfully installed on your system.

> 💡 **Tip:** If you don't see version numbers, try restarting your computer and re-running the verification commands. Ensure you opened a new terminal after installation.

### Step 5: Update npm (Optional but Recommended)

Although npm comes bundled with Node.js, the bundled version might not be the absolute latest. To ensure you have the most current features, bug fixes, and security updates, it's a good idea to update npm. Open your terminal and run the command `npm install -g npm@latest`. This command globally installs the newest version of npm.

> 💡 **Tip:** Keeping npm updated helps prevent potential compatibility issues with newer packages and ensures you're leveraging the latest performance improvements. For more developer-focused insights, see [How to Install npm: Your Essential Guide for Developers](/en/how-to-install-npm-essential-guide).


## Tips & Tricks

- Consider using a Node Version Manager (NVM) like `nvm` for Linux/macOS or `nvm-windows` for Windows if you need to manage multiple Node.js versions for different projects.
- If you encounter permission errors when installing global packages, try running your terminal or command prompt as an administrator (Windows) or using `sudo` (Linux/macOS).
- Familiarize yourself with basic npm commands such as `npm init`, `npm install <package>`, `npm uninstall <package>`, and `npm update` for efficient package management.

## Warnings

- ⚠️ Be cautious when installing packages globally (`npm install -g`). While convenient, globally installed packages can sometimes lead to version conflicts between different projects. Prefer local installations within your project directories whenever possible.

## Frequently Asked Questions

**How do I install npm in Windows?**

To install npm in Windows, download the official Node.js `.msi` installer from nodejs.org. Run the installer and follow the on-screen instructions. Node.js comes pre-bundled with npm, so installing one will automatically install the other.

**How do I install npm on Mac?**

On a Mac, the simplest way to install npm is by downloading the Node.js `.pkg` installer from nodejs.org and running it. Alternatively, if you use Homebrew, you can install Node.js (and thus npm) by running `brew install node` in your terminal.

**How do I install npm on Ubuntu or other Linux distributions?**

For Ubuntu and most Linux distributions, the recommended method to install npm is by first installing Node.js. You can use the official NodeSource PPA for the latest versions or download the pre-built binary from nodejs.org, which includes npm.

**What is npm and why do I need it?**

npm, or Node Package Manager, is the default package manager for the JavaScript runtime Node.js. It allows developers to easily share and reuse code, manage project dependencies, and execute various development scripts, making it indispensable for modern JavaScript development.

**Can I install npm without Node.js?**

While technically possible, it is strongly recommended to install Node.js, as npm is tightly integrated with it. Node.js comes bundled with npm, and installing them together ensures compatibility and a smoother development experience.

**How do I verify if npm is installed correctly?**

After installation, open a new terminal or command prompt and type `npm -v`. If npm is installed correctly, its version number will be displayed in the console, confirming a successful setup.

Installing npm, the Node Package Manager, is crucial for JavaScript development as it allows you to manage project dependencies and run various development tools. The easiest way to install npm is by installing Node.js, which bundles npm automatically. For a more in-depth resource covering all operating systems, refer to our [How to Install npm: A Complete Guide for All OS](/en/how-to-install-npm-complete-guide).

## What You Need

- Computer with internet access
- Administrator privileges (for some installations)
- Terminal or Command Prompt

## Steps

### Step 1: Understand Node.js and npm Relationship

npm, or Node Package Manager, is the default package manager for Node.js and comes bundled with Node.js itself. This means that when you install Node.js, npm is automatically installed alongside it, making the setup process straightforward. Therefore, the primary method for installing npm is to install Node.js first.

### Step 2: Download the Node.js Installer

Navigate to the official Node.js website (nodejs.org) to download the appropriate installer for your operating system. You'll typically find two main versions: the LTS (Long Term Support) version, which is recommended for most users due to its stability, and the Current version, which includes the latest features. Choose the LTS version unless you have a specific need for the very newest features.

> 💡 **Tip:** Ensure you download the correct architecture (e.g., 64-bit) for your system to avoid compatibility issues.

### Step 3: Run the Node.js Installer

Locate the downloaded installer file and run it. Follow the prompts in the installation wizard. For most users, accepting the default installation settings is perfectly fine, as they include Node.js runtime, npm package manager, and necessary development tools. Make sure to check the option to install npm.

> 💡 **Tip:** On Windows, the installer will add Node.js and npm to your system's PATH environment variable automatically, allowing you to run commands from any directory.

### Step 4: Verify the Installation

After the installation completes, open a new terminal or command prompt window. To confirm that Node.js and npm have been installed correctly, type `node -v` and press Enter. Then, type `npm -v` and press Enter. Both commands should display their respective version numbers, indicating a successful installation.

> 💡 **Tip:** If the commands are not recognized, restart your computer and try again. For detailed troubleshooting specific to your OS, refer to our [How to Install npm: Step-by-Step Guide for All OS](/en/how-to-install-npm-guide-all-os).

### Step 5: Update npm to the Latest Version (Recommended)

While npm is installed with Node.js, it might not always be the very latest version. It's good practice to update npm periodically to ensure you have access to the newest features and security patches. To update npm, open your terminal or command prompt and run the command: `npm install -g npm@latest`. This command globally installs the newest version of npm.

> 💡 **Tip:** The `-g` flag ensures npm is installed globally, making it available for all your projects.

### Step 6: Test npm by Installing a Package

To further confirm npm's functionality, you can try installing a simple global package. A common choice is `create-react-app` or `nodemon`. Open your terminal and run `npm install -g create-react-app`. If the installation completes without errors, npm is fully operational and ready for use in your development workflow.

> 💡 **Tip:** You can always uninstall global packages later using `npm uninstall -g [package-name]`.


## Tips & Tricks

- Always prefer the LTS (Long Term Support) version of Node.js for stability in production environments.
- Understand the difference between global (`-g`) and local package installations. Global packages are for tools, while local packages are for project dependencies.
- Regularly update npm using `npm install -g npm@latest` to benefit from the latest features, bug fixes, and security improvements.

## Warnings

- ⚠️ Ensure you have administrator or root privileges when running the Node.js installer or performing global npm installations to avoid permission errors.
- ⚠️ Be cautious when installing packages globally, as they can sometimes interfere with other projects if not managed carefully.

## Frequently Asked Questions

**How to install npm in Windows?**

To install npm in Windows, the recommended method is to download and run the official Node.js installer from nodejs.org. The installer automatically includes npm and configures the necessary environment variables for you. After installation, open Command Prompt and verify with `npm -v`.

**How to install npm on Mac?**

Installing npm on a Mac is straightforward by installing Node.js. Visit the Node.js official website, download the macOS installer package, and follow the on-screen instructions. npm will be bundled with Node.js and automatically set up for your system.

**How to install npm on Ubuntu?**

For Ubuntu and similar Linux distributions, you can install npm by first installing Node.js. The recommended way is to use a NodeSource PPA for the latest stable version, or you can use your distribution's package manager (`apt` for Ubuntu) to install `nodejs` and `npm` packages. After installation, verify with `npm -v`.

**Do I need Node.js to use npm?**

Yes, npm is the default package manager for Node.js and is bundled with Node.js itself. Therefore, you must install Node.js to get npm. npm relies on the Node.js runtime to execute its operations and manage packages.

**What is the difference between global and local npm packages?**

Local packages are installed in the `node_modules` directory of your specific project and are only available within that project. Global packages are installed in a central location on your system and can be used by any project or directly from the command line, often for tools like `create-react-app` or `nodemon`.

**How do I update npm?**

To update npm to its latest version, open your terminal or command prompt and run the command `npm install -g npm@latest`. This command will globally install the most recent stable version of npm, ensuring you have the latest features and bug fixes.

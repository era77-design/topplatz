To install npm, you first need to install Node.js, as npm is bundled with it. The recommended method is to download the official Node.js installer from the Node.js website, which includes npm. Once Node.js is installed, you can verify npm's installation and version via your command line. For a more in-depth look at installing npm across various systems, you can also consult [How to Install npm: Step-by-Step Guide for All OS](/en/how-to-install-npm-guide-all-os).

## What You Need

- Computer
- Internet connection
- Command Line/Terminal

## Steps

### Step 1: Download the Node.js Installer

Visit the official Node.js website (nodejs.org) and download the recommended LTS (Long Term Support) version installer for your operating system. This installer package includes both Node.js and npm. Choosing the LTS version ensures stability and long-term support for your projects.

### Step 2: Run the Node.js Installer

Locate the downloaded installer file (e.g., .msi for Windows, .pkg for macOS) and run it. Follow the on-screen prompts, accepting the license agreement and choosing the default installation location. Ensure that the "npm package manager" component is selected for installation, which it usually is by default.

> 💡 **Tip:** Always prefer the LTS version unless you have a specific reason to use the current release, as it's more stable for production environments.

### Step 3: Verify Node.js Installation

After the installation completes, open your command line interface (Command Prompt/PowerShell on Windows, Terminal on macOS/Linux). Type `node -v` and press Enter. You should see the installed Node.js version printed, confirming a successful installation.

### Step 4: Verify npm Installation

In the same command line window, type `npm -v` and press Enter. This command will display the installed npm version. If you see a version number, npm has been successfully installed along with Node.js. If you encounter an error, restart your terminal or computer and try again.

### Step 5: Update npm to the Latest Version (Optional but Recommended)

While npm is installed with Node.js, it might not be the absolute latest version. To update npm, run the command `npm install -g npm@latest` in your command line. This command globally installs the newest stable version of npm, ensuring you have access to the latest features and bug fixes. For more detailed guidance on updating npm, refer to [How to Install npm: A Beginner's Step-by-Step Guide](/en/how-to-install-npm-beginner-guide).

### Step 6: Test npm Installation with a Simple Project

To confirm npm is fully functional, create a new directory, navigate into it in your terminal, and run `npm init -y`. Then, install a small package like `lodash` by running `npm install lodash`. If both commands execute without errors and a `node_modules` folder appears with `lodash` inside, your npm installation is ready for use.


## Tips & Tricks

- Always install the LTS (Long Term Support) version of Node.js for stability, especially for production environments.
- Consider using a Node Version Manager (like `nvm` for macOS/Linux or `nvm-windows` for Windows) if you need to switch between different Node.js and npm versions for various projects.
- Regularly update npm using `npm install -g npm@latest` to benefit from the latest features, performance improvements, and security patches.

## Warnings

- ⚠️ Installing Node.js and npm often requires administrator or root privileges. Ensure you have the necessary permissions to avoid installation failures.
- ⚠️ Be cautious when installing packages globally (`npm install -g <package>`), as this can sometimes lead to conflicts if not managed properly. Prefer local installations for project dependencies.

## Frequently Asked Questions

**How do I install npm on Windows?**

To install npm on Windows, download the .msi installer from the official Node.js website (nodejs.org). Run the installer and follow the prompts, ensuring the npm package manager component is selected. Once installed, verify by typing `npm -v` in Command Prompt or PowerShell.

**How do I install npm on Mac?**

To install npm on Mac, download the .pkg installer from the official Node.js website. Run the installer and follow the instructions. Alternatively, you can use Homebrew with `brew install node`. Verify your installation by opening Terminal and running `npm -v`.

**How do I install npm on Ubuntu?**

To install npm on Ubuntu, it's recommended to use the official NodeSource repositories to get the latest versions. First, update your package list, then add the NodeSource PPA, and finally install Node.js (which includes npm) using `sudo apt install nodejs`. Verify with `npm -v`.

**What is npm and why do I need it?**

npm (Node Package Manager) is the default package manager for Node.js. It's used to install, share, and manage project dependencies and development tools. You need npm to work with most JavaScript projects, install frameworks, libraries, and utilities that extend Node.js functionality.

**How can I check if npm is already installed?**

To check if npm is already installed, open your command line interface (Terminal, Command Prompt, or PowerShell) and type `npm -v`. If npm is installed, it will display its version number. If it's not installed, you'll typically receive an error message indicating the command is not found.

**Is it safe to install npm using Node.js?**

Yes, it is the safest and recommended method to install npm by installing Node.js from its official website (nodejs.org). npm is bundled with all Node.js installers, ensuring compatibility and proper integration. This method minimizes potential issues and provides a stable environment for development.

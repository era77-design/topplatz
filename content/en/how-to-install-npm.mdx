Installing npm (Node Package Manager) is typically done by installing Node.js, as npm comes bundled with it. This process is straightforward and involves downloading the official Node.js installer or using a package manager specific to your operating system.

## What You Need

- Computer (Windows, macOS, or Linux)
- Internet connection
- Administrator/sudo privileges

## Steps

### Step 1: Understand npm and Node.js

Before you begin, it's helpful to know that npm is the default package manager for Node.js, a JavaScript runtime environment. When you install Node.js, npm is automatically installed alongside it. This means you don't usually install npm separately; you install Node.js to get both.

> 💡 **Tip:** Node.js allows you to run JavaScript code outside of a web browser, making it crucial for backend development, build tools, and more.

### Step 2: Check for Existing Node.js and npm

First, open your command prompt (Windows), Terminal (macOS), or a shell (Linux) and check if Node.js or npm are already installed. Type `node -v` and then `npm -v`. If you see version numbers, they are installed. If you get an error like 'command not found,' you need to install them.

> 💡 **Tip:** Knowing if you have an existing installation helps avoid potential conflicts or unnecessary re-installations.

### Step 3: Download the Node.js Installer (Windows/macOS)

For Windows and macOS, the simplest way to install npm is by downloading the Node.js installer from the official Node.js website (nodejs.org). It's recommended to download the 'LTS' (Long Term Support) version, as it's the most stable and reliable for most users. This installer package includes both Node.js and npm.

> 💡 **Tip:** Always download installers from official sources to ensure authenticity and security. Avoid third-party sites.

### Step 4: Run the Node.js Installer (Windows/macOS)

Once the installer is downloaded, run it. Follow the on-screen prompts, accepting the license agreement and choosing the default installation location. The installer will guide you through the process, ensuring both Node.js and npm are correctly set up on your system. Administrator privileges will be required during this step.

> 💡 **Tip:** Restart your terminal or command prompt after installation to ensure that the system's PATH variable is updated and recognizes the new commands.

### Step 5: Install Node.js and npm on Linux (Ubuntu Example)

For Linux distributions like Ubuntu, you can install Node.js and npm using your system's package manager. Open your terminal and run `sudo apt update` to update your package lists, then `sudo apt install nodejs npm`. This command will install both Node.js and npm. If you are looking for a more comprehensive guide for all operating systems, consider checking out [How to Install npm: A Complete Guide for All OS](/en/how-to-install-npm-complete-guide).

> 💡 **Tip:** Using `nvm` (Node Version Manager) is a popular alternative for Linux and macOS, allowing you to easily switch between different Node.js and npm versions.

### Step 6: Verify Your Installation

After the installation is complete, open a *new* command prompt or terminal window. Type `node -v` and `npm -v` again. You should now see the installed version numbers for both Node.js and npm, confirming a successful installation. If you still encounter issues, double-check your installation steps.

> 💡 **Tip:** If the commands still don't work, try restarting your computer, as some system environment variables might need a full refresh.

### Step 7: Update npm to the Latest Version (Optional)

While npm comes bundled with Node.js, it's often updated more frequently than Node.js itself. You can update npm to its latest version independently by running `npm install -g npm@latest` in your terminal. This ensures you have access to the newest features and bug fixes for the package manager.

> 💡 **Tip:** It's good practice to keep npm updated, especially if you encounter issues with package installations or project dependencies.


## Tips & Tricks

- Always use the official Node.js website for downloads to ensure security and stability.
- Consider using a Node Version Manager (like nvm for macOS/Linux or nvm-windows) if you need to work with multiple Node.js and npm versions on the same machine.
- After installing, try running `npm init` in a new directory to create your first `package.json` file and start a new project.

## Warnings

- ⚠️ Ensure you have administrator or sudo privileges to perform the installation, as it modifies system files.
- ⚠️ Installing Node.js and npm from untrusted sources can pose security risks to your system.

## Frequently Asked Questions

**How to install npm in Windows?**

To install npm in Windows, download and run the official Node.js installer from nodejs.org. The installer automatically includes npm, so following the on-screen prompts will set up both Node.js and npm on your system.

**How to install npm on Mac?**

Installing npm on Mac is best done by downloading the Node.js installer from the official Node.js website. Run the `.pkg` file, and it will guide you through the process, installing Node.js and npm together.

**How to install npm on Ubuntu?**

To install npm on Ubuntu, open your terminal and use the command `sudo apt update && sudo apt install nodejs npm`. This will install both Node.js and npm through the official Ubuntu package repositories.

**Why do I need Node.js to install npm?**

You need Node.js to install npm because npm is the default package manager for Node.js. It's designed to manage Node.js packages and modules, so it's bundled with the Node.js runtime environment itself.

**How do I verify if npm is installed correctly?**

To verify npm installation, open a new terminal or command prompt and type `npm -v`. If you see a version number displayed, npm is installed correctly. You can also check Node.js with `node -v`.

**Can I install npm without administrator privileges?**

Typically, installing Node.js and npm system-wide requires administrator or sudo privileges to write to system directories. However, you can use a Node Version Manager (like nvm) to install Node.js and npm into your user directory, which often doesn't require admin rights.

Installing npm (Node Package Manager) is essential for JavaScript development, as it allows you to manage project dependencies and share code. The easiest way to get npm is by installing Node.js, which bundles npm automatically. This guide will walk you through the process, ensuring you have npm ready for your projects.

## What You Need

- A computer with an internet connection
- Administrator/sudo privileges

## Steps

### Step 1: Check for Existing Node.js and npm Installation

Before you begin, it's a good idea to check if Node.js and npm are already installed on your system. Open your terminal (macOS/Linux) or command prompt (Windows) and run `node -v` and then `npm -v`. If version numbers are displayed for both, you already have them installed and can skip to the 'Update npm' step. Otherwise, proceed with the installation.

### Step 2: Download the Node.js Installer

The simplest and most recommended way to install npm is by installing Node.js, as npm is bundled with it. Visit the official Node.js website (nodejs.org) and download the recommended LTS (Long Term Support) version for your operating system. LTS versions are stable and suitable for most users and production environments.

### Step 3: Run the Node.js Installer

Once the installer has downloaded, double-click it to begin the installation process. On Windows and macOS, follow the on-screen prompts, accepting the license agreement and using the default installation location. Ensure that both 'Node.js runtime' and 'npm package manager' components are selected for installation. For Linux, specific commands are often used, as detailed in the next step.

### Step 4: Install Node.js and npm (Linux Specific)

For Linux distributions like Ubuntu, it's best to use a package manager with the NodeSource PPA for the latest LTS versions. Open your terminal and run `curl -fsSL https://deb.nodesource.com/setup_lts.x | sudo -E bash -` to add the PPA. Then, execute `sudo apt-get install -y nodejs` to install Node.js and npm. For other distributions or advanced methods, consult a comprehensive guide like [How to Install npm: A Comprehensive Guide for All OS](/en/how-to-install-npm).

### Step 5: Verify the Installation

After the installation completes, close and reopen your terminal or command prompt to ensure the system's PATH variable is updated. Then, run `node -v` and `npm -v` again. You should now see the version numbers for both Node.js and npm, confirming a successful installation. If you encounter any issues, double-check your installation steps.

### Step 6: Update npm to the Latest Version (Optional but Recommended)

Even with a fresh Node.js installation, the bundled npm might not be the absolute latest version. It's good practice to update npm globally to ensure you have the most recent features and bug fixes. In your terminal, run the command `npm install -g npm@latest`. This command safely updates your npm client without affecting Node.js.

### Step 7: Install Your First npm Package (Optional Example)

To confirm npm is fully functional, try installing a global package. For example, to install `create-react-app`, which is a popular tool for building React applications, run `npm install -g create-react-app`. This command will download and install the package globally, making it available for use from any directory in your terminal.


## Tips & Tricks

- Always use the LTS (Long Term Support) version of Node.js for production environments to ensure stability and long-term support.
- If you encounter permissions errors on Linux or macOS when installing global packages, consider using a Node Version Manager (NVM) or ensure you have appropriate user permissions. Using `sudo` for global installs is an option but should be done with caution.
- Regularly update npm and your project dependencies to benefit from bug fixes, security patches, and new features.

## Warnings

- ⚠️ Installing Node.js and npm requires administrator or root privileges. Ensure you understand the commands you are executing, especially when using `sudo` on Linux/macOS, to avoid unintended system changes.
- ⚠️ Always download Node.js installers from the official nodejs.org website to ensure you are getting legitimate and secure software.

## Frequently Asked Questions

**How do I install npm on Windows?**

To install npm on Windows, the simplest method is to download the official Node.js installer (.msi file) from nodejs.org. Run the installer and follow the on-screen prompts. Node.js comes bundled with npm, so installing one installs the other automatically. Remember to restart your command prompt after installation.

**How do I install npm on macOS?**

To install npm on macOS, download the official Node.js installer (.pkg file) from the nodejs.org website. Double-click the package and follow the installation wizard. Alternatively, for command-line users, Homebrew can be used with `brew install node` to install both Node.js and npm.

**How do I install npm on Ubuntu?**

To install npm on Ubuntu, the recommended approach is to use the NodeSource PPA, which provides the latest LTS versions. First, add the PPA to your system with a `curl` command (e.g., `curl -fsSL https://deb.nodesource.com/setup_lts.x | sudo -E bash -`), then install Node.js and npm using `sudo apt install -y nodejs`.

**Is npm automatically installed with Node.js?**

Yes, npm (Node Package Manager) is automatically bundled and installed when you install Node.js using the official installers or most package managers. This means you typically don't need to install npm separately after setting up Node.js, as they are integrated.

**How can I check if npm is already installed?**

To verify if npm is installed, open your terminal or command prompt and type `npm -v`. If npm is present on your system, it will display its version number. If you receive an error message like 'command not found', then npm is not installed or not correctly configured in your system's PATH.

**What is the difference between Node.js and npm?**

Node.js is a JavaScript runtime environment that allows you to execute JavaScript code outside of a web browser. npm (Node Package Manager) is the default package manager for Node.js, used to install, manage, and share reusable code packages (modules or libraries) for your Node.js projects. They are distinct but work hand-in-hand.

**Should I update npm after installing Node.js?**

It's generally a good practice to update npm after installing Node.js, even if it's a fresh installation. While Node.js comes with a bundled npm version, a newer npm version might be available with important bug fixes or new features. You can update it by running `npm install -g npm@latest`.

Installing npm (Node Package Manager) is primarily achieved by installing Node.js, as npm comes bundled with Node.js. This process involves downloading the appropriate Node.js installer for your operating system and running it, which will automatically set up both Node.js and npm on your system. For a comprehensive overview, consider our [How to Install npm: Your Essential Guide for Developers](/en/how-to-install-npm-essential-guide).

## What You Need

- Computer with internet access
- Administrator or sudo privileges

## Steps

### Step 1: Understand Node.js and npm's Relationship

Before you begin, it's helpful to understand that npm is the default package manager for Node.js. This means when you install Node.js, npm is automatically installed alongside it. You don't typically install npm as a standalone application; it's part of the Node.js ecosystem. Node.js is a JavaScript runtime environment that allows you to run JavaScript code outside of a web browser.

### Step 2: Download the Node.js Installer

Navigate to the official Node.js website (nodejs.org). On the homepage, you'll see two recommended versions: the LTS (Long Term Support) version and the Current version. For most users and production environments, the LTS version is recommended due to its stability and ongoing support. Download the installer package appropriate for your operating system (Windows, macOS, or Linux).

### Step 3: Install Node.js (and npm)

Run the downloaded Node.js installer. For Windows, this will be an .msi file; for macOS, a .pkg file. Follow the prompts in the installation wizard, accepting the license agreement and choosing the default installation location and components. Ensure that 'npm package manager' is selected if you customize the installation, though it's usually included by default. Administrator privileges will be required to complete the installation.

### Step 4: Verify Your Installation

After the installation is complete, open your terminal or command prompt. To verify that Node.js and npm have been installed correctly, type `node -v` and press Enter. This should display the installed Node.js version. Next, type `npm -v` and press Enter to see the installed npm version. If both commands return version numbers, your installation was successful.

### Step 5: Update npm to the Latest Version (Optional but Recommended)

While npm comes bundled with Node.js, it's often updated more frequently than Node.js itself. To ensure you're using the latest features and bug fixes, it's good practice to update npm. In your terminal or command prompt, run the command `npm install -g npm@latest`. The `-g` flag ensures the update is global, making the latest npm version available system-wide.

### Step 6: Troubleshoot Common Installation Issues

If you encounter issues like 'command not found' after installation, try restarting your terminal or computer to ensure environment variables are refreshed. On Linux, if you installed via a package manager, you might need to ensure Node.js and npm binaries are symlinked correctly. Permission errors (e.g., 'EACCES') often indicate that you're trying to install global packages without sufficient privileges; use `sudo` on Linux/macOS or run your command prompt as administrator on Windows for global installations.


## Tips & Tricks

- Always prefer the LTS (Long Term Support) version of Node.js for stability, especially in production environments.
- After installing Node.js, close and reopen your terminal or command prompt to ensure that the system's PATH environment variable is updated.
- Consider using a Node Version Manager (NVM) like `nvm` for Linux/macOS or `nvm-windows` for Windows if you need to switch between multiple Node.js versions for different projects. For platform-specific insights, see [How to Install npm: A Step-by-Step Guide for All Platforms](/en/how-to-install-npm-guide-all-platforms).

## Warnings

- ⚠️ Ensure you have administrator (Windows) or sudo (Linux/macOS) privileges when running the installer or installing global npm packages, as this process modifies system files.

## Frequently Asked Questions

**How to install npm in Windows?**

To install npm in Windows, download the official Node.js .msi installer from nodejs.org. Run the installer and follow the on-screen prompts. npm is included with the Node.js installation, so both will be set up automatically.

**How to install npm on Mac?**

On Mac, you can install npm by downloading the Node.js .pkg installer from nodejs.org and running it. Alternatively, use Homebrew by opening your terminal and typing `brew install node`, which will install both Node.js and npm.

**How to install npm on Ubuntu?**

To install npm on Ubuntu, open your terminal and use the system's package manager. First, update your package list with `sudo apt update`, then install Node.js and npm using `sudo apt install nodejs npm`. This command will fetch and install both packages.

**What is npm?**

npm stands for Node Package Manager. It is the default package manager for JavaScript's runtime Node.js. npm is used to install, manage, and share JavaScript packages (libraries and modules) for your projects, making development faster and more efficient.

**Do I need Node.js to install npm?**

Yes, npm is distributed as part of the Node.js installation. You cannot install npm independently without first installing Node.js. When you download and install Node.js from its official website, npm is automatically included and set up on your system.

**How do I update npm?**

To update npm to its latest version, open your terminal or command prompt and execute the command `npm install -g npm@latest`. The `-g` flag ensures that the update is applied globally, making the newest npm version available for all your projects.

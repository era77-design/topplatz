npm (Node Package Manager) is the default package manager for Node.js, essential for managing JavaScript libraries and dependencies in your projects. Installing npm is straightforward as it comes bundled with Node.js. This guide will walk you through the process on various operating systems. For a more comprehensive overview, you can refer to our [How to Install npm: A Beginner's Guide for All OS](/en/how-to-install-npm).

## What You Need

- Computer (Windows, macOS, or Linux)
- Stable internet connection
- Administrative privileges

## Steps

### Step 1: Check for Existing Node.js and npm Installation

Before proceeding, it's good practice to check if Node.js and npm are already installed on your system. Open your terminal (macOS/Linux) or Command Prompt/PowerShell (Windows). Type `node -v` and then `npm -v` and press Enter after each command. If version numbers are displayed, they are installed. If you receive an error, you'll need to install them.

### Step 2: Download the Node.js Installer

npm is bundled with Node.js, so you'll install both simultaneously. Visit the official Node.js website (nodejs.org). Download the recommended LTS (Long Term Support) version for your specific operating system (Windows, macOS, or Linux). This installer package contains everything you need for both Node.js and npm.

### Step 3: Install Node.js (Windows & macOS)

Locate the downloaded installer file (e.g., a `.msi` file for Windows or a `.pkg` file for macOS). Run the installer and follow the on-screen prompts. Accept the license agreement, choose the default installation path, and ensure that the 'npm package manager' component is selected for installation. Complete the installation process. For a quick visual walkthrough, check out our [How to Install npm: A Simple Step-by-Step Guide](/en/how-to-install-npm-step-by-step).

> 💡 **Tip:** Most users can accept the default settings during the installation process for a hassle-free setup.

### Step 4: Install Node.js (Linux/Ubuntu using Package Manager)

For Linux distributions like Ubuntu or Debian, you can use your system's package manager. First, update your package list by running `sudo apt update` in your terminal. Then, install Node.js and npm with the command `sudo apt install nodejs npm`. This method conveniently installs both components from your distribution's repositories.

> 💡 **Tip:** Consider using Node Version Manager (NVM) on Linux for easier management of multiple Node.js versions, if you're a developer working on diverse projects.

### Step 5: Verify the Installation

After the installation is complete, open a *new* terminal or command prompt window. Type `node -v` and press Enter, then type `npm -v` and press Enter. You should now see the installed version numbers for both Node.js and npm. This confirms that both components have been successfully installed and are accessible from your command line.

### Step 6: Update npm to the Latest Version (Optional but Recommended)

While npm comes bundled with Node.js, the bundled version might not always be the absolute latest. To ensure you have the most recent features and security updates for npm, you can update it separately. Run the command `npm install -g npm@latest` in your terminal or command prompt. This command globally updates npm to its newest available version.

> 💡 **Tip:** Keeping npm updated helps prevent potential issues with package installations and ensures compatibility with newer JavaScript libraries.


## Tips & Tricks

- **Use a Node Version Manager (NVM):** For developers who work on multiple projects requiring different Node.js versions, NVM (or similar tools like `fnm` or `volta`) is highly recommended. It allows you to install and switch between Node.js and npm versions easily without conflicts.
- **Keep npm Updated:** Regularly update npm using `npm install -g npm@latest` to benefit from the latest features, bug fixes, and security patches. This ensures a smoother development workflow.
- **Understand Global vs. Local Packages:** Packages installed with the `-g` flag (global) are available system-wide, while local packages are installed within your project's `node_modules` directory. Most project dependencies are installed locally.

## Warnings

- ⚠️ **Administrative Privileges:** You will need administrative rights on your computer to install Node.js and npm, especially when using system-wide installers or package managers.
- ⚠️ **Path Environment Variable:** Ensure that Node.js and npm are correctly added to your system's PATH environment variable. The official installers usually handle this automatically, but manual adjustment might be needed in some custom setups.
- ⚠️ **Avoid Mixed Installations:** Do not mix installations from different sources (e.g., using the official installer and then trying to install via a package manager) as this can lead to conflicts and difficult-to-resolve issues. Stick to one installation method.

## Frequently Asked Questions

**What is npm and why do I need it?**

npm (Node Package Manager) is the default package manager for Node.js, used to install, share, and manage project dependencies. You need it to easily incorporate and manage external JavaScript libraries and tools in your development projects, streamlining your workflow.

**How to install npm in Windows?**

To install npm in Windows, download the official Node.js `.msi` installer from nodejs.org. Run the installer and follow the on-screen prompts, as npm is bundled with Node.js. After installation, open a new command prompt and verify with `npm -v`.

**How to install npm on Mac?**

For Mac users, download the official Node.js `.pkg` installer from nodejs.org. Execute the installer and proceed through the steps. npm comes pre-packaged with Node.js, so once Node.js is installed, npm will be available for use in your terminal.

**How to install npm on Ubuntu?**

On Ubuntu, you can install npm via the apt package manager. First, update your package list with `sudo apt update`, then install both Node.js and npm using `sudo apt install nodejs npm`. Verify the installation by checking versions in your terminal.

**How do I verify if npm is successfully installed?**

After installation, open a *new* terminal or command prompt. Type `node -v` and then `npm -v`. If you see version numbers displayed for both commands, then Node.js and npm have been successfully installed and configured on your system.

**Can I install npm without Node.js?**

No, npm is tightly coupled with Node.js and is automatically installed when you install Node.js. It functions as the package manager for Node.js projects, so having Node.js is a prerequisite for npm to operate correctly.

**How do I update npm to the latest version?**

To update npm to its latest version, open your terminal or command prompt and run the command `npm install -g npm@latest`. This will globally update your npm client, ensuring you have the most current features, bug fixes, and security improvements.

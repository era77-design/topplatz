Installing npm (Node Package Manager) is a fundamental step for any JavaScript developer, as it allows you to manage project dependencies and run development tools. npm is automatically installed with Node.js, so your primary task will be installing Node.js itself. This guide will walk you through the process across different operating systems to get you up and running.

## What You Need

- A computer with an internet connection
- Administrator privileges (for installation)

## Steps

### Step 1: Understand npm and Node.js

Before starting, it's important to know that npm is the default package manager for Node.js, a JavaScript runtime environment. This means that when you install Node.js, npm is automatically installed alongside it. Therefore, the main focus of installing npm is actually installing Node.js, which bundles npm for you. This simplifies the process considerably, making it a single download and install operation.

> 💡 **Tip:** Node.js is crucial for running server-side JavaScript and many front-end build tools. Always install the LTS (Long Term Support) version for stability in production environments.

### Step 2: Check for Existing Installation

Before proceeding, it's a good idea to check if Node.js and npm are already installed on your system. Open your terminal or command prompt and type `node -v` and then `npm -v`. If you see version numbers returned for both, they are installed. If you receive a 'command not found' error, you'll need to install them.

> 💡 **Tip:** Checking existing versions helps prevent conflicts and ensures you don't unnecessarily reinstall software already present.

### Step 3: Download the Node.js Installer

The recommended way to install npm is by downloading the Node.js installer from the official Node.js website (nodejs.org). On the homepage, you'll typically see two versions: the LTS (Long Term Support) version and the Current version. For most users, the LTS version is recommended due to its stability and long-term support. Click on the LTS version to download the appropriate installer for your operating system (Windows, macOS, or Linux).

> 💡 **Tip:** Always download installers from official sources to ensure authenticity and avoid potential security risks.

### Step 4: Run the Installer (Windows and macOS)

Once the Node.js installer file (e.g., .msi for Windows, .pkg for macOS) has downloaded, locate it and double-click to run. Follow the prompts in the installation wizard, accepting the license agreement and clicking 'Next' through the default settings. It is generally safe to accept the default installation path and components, as these ensure npm is properly configured and added to your system's PATH. Complete the installation by clicking 'Finish'.

> 💡 **Tip:** Ensure you have administrator privileges when running the installer, as it needs to make system-wide changes to install Node.js and npm correctly.

### Step 5: Install on Linux (Ubuntu Example)

For Linux distributions like Ubuntu, you can often install Node.js and npm using your system's package manager. First, update your package list with `sudo apt update`. Then, you can install Node.js using `sudo apt install nodejs npm`. This command will fetch and install both Node.js and npm from the Ubuntu repositories. Alternatively, consider using Node Version Manager (NVM) for more flexible version management, as detailed in our [How to Install npm: Step-by-Step Guide for All OS](/en/how-to-install-npm-guide-all-os).

> 💡 **Tip:** Using a package manager like `apt` is generally the easiest way to install software on Linux, ensuring dependencies are handled correctly.

### Step 6: Verify the Installation

After the installation is complete, open a *new* terminal or command prompt window. This is important because the system's PATH variable needs to refresh to recognize the new commands. Type `node -v` and press Enter; you should see the Node.js version number. Then, type `npm -v` and press Enter; you should see the npm version number. If both commands return version numbers, Node.js and npm have been successfully installed.

> 💡 **Tip:** If commands are not recognized, try restarting your computer, especially on Windows, to ensure all environment variables are updated.

### Step 7: Update npm to the Latest Version (Optional)

While npm comes bundled with Node.js, it often receives updates independently. It's good practice to keep npm itself updated to the latest stable version. In your terminal, run the command `npm install -g npm@latest`. The `-g` flag ensures npm is updated globally across your system. This process ensures you have access to the newest features and bug fixes from the npm team.

> 💡 **Tip:** Regularly updating npm can improve performance and compatibility with the latest JavaScript packages and tools.


## Tips & Tricks

- Always prefer the LTS (Long Term Support) version of Node.js for production environments due to its stability and longer maintenance period.
- If you encounter issues with permissions during global package installation, consider using Node Version Manager (NVM) or fixing npm's default directory permissions.
- Restart your terminal or command prompt after installation to ensure that the system's PATH variable is correctly updated and recognizes the `node` and `npm` commands.

## Warnings

- ⚠️ Installing Node.js and npm without administrator privileges may lead to incomplete installations or permission errors when managing packages.
- ⚠️ Be cautious when using `sudo npm install` on Linux, as it can sometimes lead to permission issues with packages installed globally by npm. Consider configuring npm to install packages in a user-owned directory instead.

## Frequently Asked Questions

**What is npm and why do I need it?**

npm stands for Node Package Manager, and it's the world's largest software registry. Developers use npm to share and reuse code, manage project dependencies, and run various development tools. You need it to install libraries like React, Angular, Vue, or build tools like Webpack.

**How to install npm in Windows?**

To install npm in Windows, the easiest method is to download and run the official Node.js installer (.msi file) from nodejs.org. The installer automatically includes npm and adds it to your system's PATH. Follow the wizard's prompts, accepting default settings, and then verify the installation in a new command prompt window using `node -v` and `npm -v`.

**How to install npm on Mac?**

Installing npm on Mac is straightforward by downloading the Node.js installer (.pkg file) from nodejs.org. Run the installer and follow the instructions. Alternatively, you can use Homebrew by running `brew install node` in your terminal, which will also install npm. Verify the installation by opening a new terminal and typing `node -v` and `npm -v`.

**How to install npm on Ubuntu?**

To install npm on Ubuntu, you can use the `apt` package manager. First, update your package list with `sudo apt update`, then install Node.js and npm using `sudo apt install nodejs npm`. For a more flexible setup, consider using Node Version Manager (NVM) to manage multiple Node.js versions, as detailed in our guide [How to Install npm: A Complete Guide for All OS](/en/how-to-install-npm-complete-guide).

**What if npm is not recognized after installation?**

If npm is not recognized, ensure you have opened a *new* terminal or command prompt window after installation, as existing windows might not have updated their PATH environment variable. If the issue persists, try restarting your computer. On Windows, you might need to manually add the Node.js installation directory (containing `npm.cmd`) to your system's PATH variable.

**How do I update npm to the latest version?**

You can update npm to its latest version independently of Node.js by running `npm install -g npm@latest` in your terminal or command prompt. The `-g` flag ensures the update is applied globally across your system. This ensures you have the most current features and bug fixes for the package manager itself.

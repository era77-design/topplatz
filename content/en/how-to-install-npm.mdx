npm (Node Package Manager) is the default package manager for Node.js, essential for installing and managing project dependencies. Installing npm is typically done by installing Node.js, which bundles npm automatically. This guide will walk you through the process, ensuring you have npm ready for your development needs.

## What You Need

- Computer with internet access
- Command Line Interface (Terminal, CMD, PowerShell)

## Steps

### Step 1: Understand Node.js and npm

Before you begin, it's important to know that npm is distributed with Node.js. This means that when you install Node.js, npm is automatically installed alongside it. Node.js is a JavaScript runtime that allows you to run JavaScript code outside of a web browser, and npm helps manage the packages (libraries and tools) for your Node.js projects.

### Step 2: Check for Existing Installation

Open your command line interface (Terminal on Mac/Linux, Command Prompt or PowerShell on Windows). Type `node -v` and `npm -v` and press Enter. If you see version numbers, Node.js and npm are already installed. If not, or if the versions are very old, proceed with a fresh installation or update.

### Step 3: Download and Install Node.js (which includes npm)

The easiest and most recommended way to install npm is by downloading the official Node.js installer from the Node.js website (nodejs.org). Choose the LTS (Long Term Support) version, which is stable and widely used. The installer will guide you through the process, automatically setting up both Node.js and npm on your system. For detailed, OS-specific instructions, you can refer to our [How to Install npm: Step-by-Step for Windows, Mac & Linux](/en/how-to-install-npm-windows-mac-linux) guide.

### Step 4: Verify the Installation

After running the installer, close and reopen your command line interface to ensure that the system's PATH variable is updated. Then, type `node -v` and `npm -v` again. You should now see the version numbers for Node.js and npm, confirming a successful installation. If you encounter issues, ensure the installation completed without errors.

### Step 5: Update npm to the Latest Version (Optional but Recommended)

While npm comes bundled with Node.js, it might not always be the absolute latest version. To update npm independently, run the command `npm install -g npm@latest` in your terminal. The `-g` flag ensures that npm is updated globally on your system, making the latest features and security patches available.

### Step 6: Troubleshoot Common Installation Issues

If npm commands are not recognized after installation, try restarting your computer or ensuring the Node.js installation directory is correctly added to your system's PATH environment variable. Permission errors during global package installations often require running your terminal with administrator privileges (on Windows) or using `sudo` (on Mac/Linux) before the `npm install -g` command.

### Step 7: Perform a Test Installation

To confirm npm is working correctly, you can try installing a simple package. Create a new empty directory, navigate into it using your terminal, and then run `npm init -y` to create a `package.json` file. Finally, try `npm install express`. This command will install the 'express' web framework locally into your project, creating a `node_modules` folder and updating `package.json`.


## Tips & Tricks

- Always use the LTS (Long Term Support) version of Node.js for production environments, as it offers long-term stability and support.
- Consider using Node Version Manager (NVM) or Volta if you need to manage multiple Node.js versions on your system for different projects.
- Regularly update npm to benefit from the latest features, performance improvements, and security patches.

## Warnings

- ⚠️ Installing global packages (using `-g`) sometimes requires administrator or root privileges. Use `sudo` on Linux/macOS or run your terminal as administrator on Windows if you encounter permission errors.
- ⚠️ Be cautious when installing packages from unknown sources, as they could contain malicious code. Always verify the source and reputation of packages before adding them to your projects.

## Frequently Asked Questions

**How do I install npm in Windows?**

The easiest way to install npm in Windows is by downloading and running the official Node.js installer from the Node.js website (nodejs.org). This installer includes both Node.js and npm, guiding you through the setup process with simple prompts.

**What's the recommended way to install npm on Mac?**

For Mac users, installing npm is best done via the official Node.js installer from nodejs.org or by using a version manager like NVM (Node Version Manager). Both methods ensure you get Node.js bundled with npm, providing a robust development environment.

**Can I install npm on Ubuntu using apt?**

Yes, you can install npm on Ubuntu by installing Node.js via `apt`. It's recommended to use the NodeSource PPA for the latest stable Node.js/npm versions rather than the default Ubuntu repositories, which might offer older versions. Add the PPA, then run `sudo apt update` and `sudo apt install nodejs`.

**Why do I need Node.js to install npm?**

npm is the default package manager for Node.js, meaning it's built to work specifically with Node.js projects and modules. It's bundled with Node.js because it relies on Node.js to execute its operations and manage JavaScript packages, making them inseparable for most development workflows.

**How do I update npm to the latest version?**

To update npm to its latest version, open your terminal or command prompt and run `npm install -g npm@latest`. The `-g` flag ensures npm is updated globally on your system, allowing you to access the most recent features and improvements.

**What should I do if npm is not recognized after installation?**

If npm is not recognized, it usually means the Node.js installation directory is not correctly added to your system's PATH environment variable. Try restarting your terminal or computer first. If the issue persists, you might need to manually add the Node.js installation path to your system's PATH settings.

**Is it safe to install npm packages globally?**

Installing npm packages globally (`-g`) is generally safe for tools and utilities that you want to use across multiple projects or directly from the command line, such as `create-react-app` or `nodemon`. However, project-specific dependencies should always be installed locally within your project directory without the `-g` flag to ensure project isolation and version control.

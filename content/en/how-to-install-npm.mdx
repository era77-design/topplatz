To install npm, you typically install Node.js, as npm is included with Node.js. The easiest and recommended method is to download the Node.js installer for your operating system and follow the installation prompts, which will automatically set up npm for you.

## What You Need

- Internet connection
- Administrator or root privileges

## Steps

### Step 1: 1. Check for Existing Node.js and npm Installation

Before proceeding, it's good practice to check if Node.js and npm are already installed on your system. Open your terminal or command prompt and type `node -v` and then `npm -v`. If versions are returned, they are installed; otherwise, you'll see an error message indicating they are not found.

> 💡 **Tip:** If you have an older version of Node.js and npm, you might consider updating them rather than a fresh install. However, for a clean setup, uninstalling old versions first is recommended.

### Step 2: 2. Download the Node.js Installer

The most straightforward way to install npm is by installing Node.js, which bundles npm. Visit the official Node.js website (nodejs.org) and download the LTS (Long Term Support) version installer recommended for your operating system. This version is stable and suitable for most users.

> 💡 **Tip:** Always prefer the LTS version unless you have a specific need for the 'Current' release, which might contain newer features but is less stable.

### Step 3: 3. Run the Node.js Installer (Windows/macOS)

Locate the downloaded Node.js installer file and double-click to run it. Follow the on-screen prompts, accepting the license agreement and choosing the default installation options. The installer will automatically configure Node.js and npm, including adding them to your system's PATH environment variable.

> 💡 **Tip:** Ensure you have administrator privileges to run the installer successfully. Restarting your terminal or command prompt after installation is often necessary for the changes to take effect.

### Step 4: 4. Install Node.js and npm on Linux (Ubuntu/Debian)

For Linux distributions like Ubuntu, you can install Node.js and npm using your system's package manager. First, update your package list with `sudo apt update`. Then, install Node.js and npm by running `sudo apt install nodejs npm`. This command will fetch and install both packages from the official repositories.

> 💡 **Tip:** Using a Node.js version manager like `nvm` (Node Version Manager) is often preferred on Linux, especially if you need to switch between different Node.js versions. You can find more details in our [How to Install npm: A Complete Guide for All OS](/en/how-to-install-npm-complete-guide).

### Step 5: 5. Verify the Installation

After the installation is complete, open a *new* terminal or command prompt window. Type `node -v` and press Enter. You should see the installed Node.js version. Next, type `npm -v` and press Enter. This should display the npm version, confirming that both Node.js and npm have been successfully installed on your system.

> 💡 **Tip:** If you don't see the versions, try restarting your computer, especially on Windows, to ensure all system paths are updated correctly.

### Step 6: 6. Update npm to the Latest Version (Optional)

While npm comes bundled with Node.js, it's often updated more frequently. To ensure you have the very latest version of npm, you can update it independently. In your terminal, run the command `npm install -g npm@latest`. This will globally install the newest npm version, ready for use.

> 💡 **Tip:** Updating npm regularly helps you access the latest features, bug fixes, and security patches. It's a good habit to incorporate into your development workflow.


## Tips & Tricks

- Always download Node.js from the official website (nodejs.org) to ensure authenticity and avoid potential security risks.
- If you encounter 'command not found' errors after installation, verify that Node.js and npm are added to your system's PATH environment variable. You may need to manually add them or reinstall.
- Consider using `nvm` (Node Version Manager) for macOS and Linux if you need to manage multiple Node.js versions on a single machine, which is common in development.

## Warnings

- ⚠️ Installing Node.js and npm requires administrator or root privileges. Ensure you have the necessary permissions to avoid installation failures.
- ⚠️ Be cautious when running `npm install -g` commands, as global installations can sometimes cause conflicts if not managed properly. Use `nvm` or similar tools for better version management.

## Frequently Asked Questions

**How to install npm on Windows?**

To install npm on Windows, download the Node.js `.msi` installer from the official Node.js website. Run the installer and follow the default prompts; npm is automatically included with the Node.js installation package.

**How to install npm on macOS?**

On macOS, the simplest way to install npm is by downloading the Node.js `.pkg` installer from nodejs.org. Execute the package and follow the installation wizard. Alternatively, you can use Homebrew with `brew install node`.

**How to install npm on Ubuntu?**

To install npm on Ubuntu, you can use the system's package manager. First, update your package list with `sudo apt update`, then install Node.js and npm using `sudo apt install nodejs npm`. This will install both necessary components.

**What is npm?**

npm (Node Package Manager) is the default package manager for Node.js. It's a command-line utility for interacting with a repository of open-source Node.js projects, allowing developers to easily install, share, and manage project dependencies.

**Why do I need npm?**

You need npm to manage packages and dependencies for your JavaScript projects, especially those built with Node.js. It simplifies the process of adding external libraries, running scripts, and sharing your own code with others.

**Does Node.js come with npm?**

Yes, when you install Node.js using its official installer or recommended package manager methods, npm is typically bundled and installed alongside it. This ensures you have both tools ready for development.

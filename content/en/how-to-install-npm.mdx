npm, or Node Package Manager, is the default package manager for Node.js, essential for managing JavaScript packages and dependencies in your projects. Installing npm is typically done by installing Node.js, as npm comes bundled with it. This guide will walk you through the process on various operating systems.

## What You Need

- Computer
- Internet connection
- Administrative privileges (for installation)

## Steps

### Step 1: Understand Node.js and npm

npm is the package manager for JavaScript, and it's installed automatically when you install Node.js. Node.js is a JavaScript runtime built on Chrome's V8 JavaScript engine, allowing you to run JavaScript code outside of a web browser. Before installing npm, you'll first need to ensure Node.js is on your system.

### Step 2: Check for Existing Installation

Open your terminal (or Command Prompt on Windows) and type `node -v` and `npm -v`. If Node.js and npm are already installed, these commands will display their version numbers. If not, you'll see an error message, indicating you need to proceed with installation.

### Step 3: Install Node.js (and npm)

The recommended way to install npm is by installing Node.js. Visit the official Node.js website (nodejs.org) and download the LTS (Long Term Support) version installer for your operating system (Windows, macOS, or Linux). Run the installer and follow the on-screen prompts, accepting the default settings. This will automatically install both Node.js and npm.

> 💡 **Tip:** For Linux users, consider using a version manager like `nvm` (Node Version Manager) for more flexible control over Node.js versions. For more detailed OS-specific instructions, check out our [How to Install npm: Step-by-Step Guide for All OS](/en/how-to-install-npm-guide).

### Step 4: Verify the Installation

After the installation is complete, close and reopen your terminal or Command Prompt. Type `node -v` and `npm -v` again. You should now see the version numbers for both Node.js and npm, confirming a successful installation. If you encounter issues, double-check your installation steps.

### Step 5: Update npm (Optional but Recommended)

While npm comes bundled with Node.js, it's often updated more frequently. To ensure you have the latest stable version of npm, run the command `npm install -g npm@latest` in your terminal. The `-g` flag ensures it's installed globally, making it available system-wide.

### Step 6: Run Your First npm Command

To confirm npm is fully functional, you can try initializing a new project. Navigate to a new directory in your terminal and run `npm init -y`. This will create a `package.json` file, which is crucial for managing project dependencies and scripts, demonstrating npm's core functionality.


## Tips & Tricks

- Always download Node.js from the official website (nodejs.org) to ensure authenticity and security.
- Consider using a Node Version Manager (like `nvm` for Linux/macOS or `nvm-windows` for Windows) if you need to switch between different Node.js and npm versions for various projects.
- If you encounter permission errors on Linux/macOS, avoid using `sudo` with npm install commands unless absolutely necessary, and instead fix your npm permissions or use `nvm`.

## Warnings

- ⚠️ Installing Node.js and npm requires administrative privileges on your system. Ensure you have the necessary permissions before starting the installation process to avoid errors.

## Frequently Asked Questions

**How to install npm in Windows?**

The simplest way to install npm on Windows is by downloading and running the Node.js Windows Installer (.msi) from the official Node.js website (nodejs.org). The installer will automatically include npm. Follow the on-screen prompts to complete the installation.

**How to install npm on Mac?**

To install npm on a Mac, download the macOS Installer (.pkg) from the official Node.js website (nodejs.org). Run the installer and follow the instructions. Alternatively, you can use Homebrew by running `brew install node` in your terminal.

**How to install npm on Ubuntu?**

On Ubuntu, you can install npm by first installing Node.js. The recommended method is to use a Node.js version manager like `nvm` or to download the official Node.js binary, which includes npm, from nodejs.org. You can also use `sudo apt install nodejs npm` for a quick installation, though this might provide an older version.

**What is npm and why do I need it?**

npm (Node Package Manager) is the default package manager for Node.js, used to install, manage, and share JavaScript packages and modules. You need it to easily add external libraries and dependencies to your JavaScript projects, simplifying development and collaboration.

**Do I need to install Node.js separately from npm?**

No, when you install Node.js from its official website using the recommended installer, npm is automatically included and installed alongside it. You do not need to perform a separate installation for npm.

**How do I check if npm is already installed?**

To check if npm is installed, open your terminal or command prompt and type `npm -v`. If npm is installed, it will display its version number. If not, you will receive an error message.

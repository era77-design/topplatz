Installing npm, the Node Package Manager, is essential for JavaScript development as it allows you to manage project dependencies and share code. The simplest and most recommended way to install npm is by first installing Node.js, which bundles npm automatically.

## What You Need

- Computer with internet access
- Administrator or sudo privileges
- Terminal or Command Prompt

## Steps

### Step 1: Understand Node.js and npm

Before starting the installation, it's helpful to understand the relationship between Node.js and npm. Node.js is a JavaScript runtime built on Chrome's V8 JavaScript engine, allowing you to run JavaScript code outside a web browser. npm, the Node Package Manager, is the default package manager for Node.js and comes bundled with Node.js installers. This means installing Node.js will automatically install npm for you.

> 💡 **Tip:** Always install Node.js first to get npm. They are designed to work together seamlessly.

### Step 2: Download the Node.js Installer

Visit the official Node.js website (nodejs.org). On the homepage, you will typically see two recommended versions: the LTS (Long Term Support) version and the Current version. For most users and production environments, the LTS version is recommended due to its stability and ongoing support. Download the installer package appropriate for your operating system (Windows, macOS, or Linux). The website usually auto-detects your OS.

> 💡 **Tip:** Choose the LTS version for stability unless you need the absolute latest features for development.

### Step 3: Install Node.js (and npm)

Locate the downloaded installer file (e.g., .msi for Windows, .pkg for macOS, or a tarball for Linux). Run the installer and follow the on-screen prompts. For most users, accepting the default installation settings is sufficient. The installer will guide you through the process, which includes agreeing to the license, choosing an installation directory, and confirming the components to install (npm package manager will be checked by default).

> 💡 **Tip:** You may need administrator privileges on Windows or sudo privileges on Linux/macOS to complete the installation.

### Step 4: Verify the Installation

After the installation is complete, open your terminal (macOS/Linux) or Command Prompt/PowerShell (Windows). To verify that Node.js and npm have been installed correctly, type the following commands and press Enter after each: `node -v` and `npm -v`. These commands should display the installed versions of Node.js and npm, respectively. If you see version numbers, your installation was successful.

> 💡 **Tip:** If the commands are not found, try restarting your terminal or computer. Ensure the Node.js installation directory is added to your system's PATH environment variable.

### Step 5: Update npm to the Latest Version

While npm is installed with Node.js, the bundled version might not always be the very latest available. It's a good practice to update npm to its most current version. In your terminal or command prompt, run the command: `npm install -g npm@latest`. The `-g` flag ensures that npm is updated globally on your system. This process ensures you have access to the newest features and bug fixes.

> 💡 **Tip:** Keeping npm updated can prevent compatibility issues with newer packages and improve performance.

### Step 6: Start Using npm

With npm successfully installed and updated, you are now ready to manage packages for your JavaScript projects. You can use commands like `npm init` to start a new project, `npm install <package-name>` to add dependencies, or `npm run <script-name>` to execute scripts defined in your `package.json` file. Explore the vast npm registry to find packages for virtually any development need.

> 💡 **Tip:** Consider using `nvm` (Node Version Manager) for macOS/Linux or `nvm-windows` for Windows if you need to switch between multiple Node.js versions for different projects.


## Tips & Tricks

- Always install the LTS (Long Term Support) version of Node.js for production environments due to its stability.
- Regularly update npm using `npm install -g npm@latest` to benefit from the latest features, security patches, and performance improvements.
- Understand the difference between local (`npm install <package>`) and global (`npm install -g <package>`) package installations. Local installs are project-specific, while global installs are for command-line tools.

## Warnings

- ⚠️ Ensure you have stable internet connectivity during the download and installation process.
- ⚠️ Always download installers from the official Node.js website (nodejs.org) to avoid malicious software.
- ⚠️ Be cautious when running commands with `sudo` (Linux/macOS) or as an administrator (Windows); ensure you understand what the command does before executing it.

## Frequently Asked Questions

**How to install npm in Windows?**

To install npm on Windows, first download the Node.js `.msi` installer from the official Node.js website. Run the installer and follow the setup wizard, accepting the default options. Node.js comes bundled with npm, so both will be installed simultaneously. For more detailed instructions, refer to our guide on [How to Install npm: Step-by-Step for Windows, Mac & Linux](/en/how-to-install-npm-windows-mac-linux).

**How to install npm on Mac?**

Installing npm on macOS is straightforward. Download the Node.js `.pkg` installer from the Node.js official website. Execute the installer and proceed through the steps, typically accepting the defaults. npm will be installed automatically along with Node.js, ready for use in your terminal.

**How to install npm on Ubuntu?**

For Ubuntu users, the recommended way to install npm is by first installing Node.js. You can do this via your system's package manager, typically using `sudo apt update` followed by `sudo apt install nodejs npm`. Alternatively, use the official NodeSource repositories for the latest versions and better control over specific Node.js versions.

**What is npm used for?**

npm (Node Package Manager) is primarily used for managing project dependencies in JavaScript development. It allows developers to install, share, and manage packages (libraries and tools) needed for their Node.js applications or front-end projects, streamlining the development workflow.

**Do I need to install Node.js separately to get npm?**

Yes, in most cases, installing Node.js is the simplest and recommended way to get npm. The official Node.js installers for Windows, macOS, and many Linux distributions bundle npm automatically, ensuring you have both tools ready for development without separate installations.

**How do I update npm to the latest version?**

To update npm to its latest version, open your terminal or command prompt and run the command `npm install -g npm@latest`. This command globally updates your npm installation, giving you access to the newest features and ensuring compatibility with modern packages.

**What if npm is not recognized after installation?**

If npm is not recognized after installation, ensure that Node.js was added to your system's PATH environment variable. You might need to restart your terminal or command prompt, or even your computer, for the changes to take effect. If the issue persists, you may need to manually add the Node.js installation directory to your PATH.

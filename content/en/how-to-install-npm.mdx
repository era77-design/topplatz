Installing npm (Node Package Manager) is crucial for managing JavaScript packages and projects. The easiest and recommended way to get npm is by installing Node.js, which bundles npm automatically. This guide will walk you through the process on various operating systems, ensuring you're ready to start your development journey. For a more in-depth look, refer to our [How to Install npm: A Comprehensive Guide for All OS](/en/how-to-install-npm).

## What You Need

- Internet connection
- Web browser
- Administrator/sudo privileges
- Terminal or Command Prompt

## Steps

### Step 1: Check for Existing Node.js and npm Installation

Before proceeding, it's a good idea to check if Node.js and npm are already installed on your system. Open your terminal (macOS/Linux) or Command Prompt/PowerShell (Windows) and type `node -v` then press Enter. Do the same for `npm -v`. If you see version numbers, they are installed. If not, or if the versions are very old, you'll proceed with installation.

> 💡 **Tip:** If Node.js and npm are already installed, consider updating them to their latest stable versions. You can update npm separately later in this guide.

### Step 2: Download the Node.js Installer

The recommended way to install npm is by installing Node.js, as npm is bundled with it. Visit the official Node.js website (nodejs.org) in your web browser. Look for the 'LTS' (Long Term Support) version, as this is the most stable and recommended option for most users. Download the installer package appropriate for your operating system (Windows, macOS, or Linux).

> 💡 **Tip:** Always download Node.js from the official website to ensure you get a legitimate and secure version of the software.

### Step 3: Install Node.js (and npm) on Your System

Once the installer finishes downloading, run it. For Windows and macOS, simply follow the prompts in the installation wizard, accepting the default settings. On Linux, you might use your distribution's package manager (e.g., `sudo apt install nodejs npm` for Debian/Ubuntu or `sudo yum install nodejs npm` for RHEL/CentOS) after adding the NodeSource repository for the latest versions. This process will install both Node.js and npm on your machine.

> 💡 **Tip:** Ensure you have administrator or sudo privileges to perform the installation successfully.

### Step 4: Verify the Installation

After the installation completes, open a *new* terminal or Command Prompt window. This is important to ensure your system's PATH variable is updated. Run `node -v` and `npm -v` again. You should now see the version numbers for both Node.js and npm, confirming that they have been successfully installed and are ready for use on your system.

> 💡 **Tip:** If you don't see version numbers, try restarting your computer and then re-checking. Sometimes a reboot helps with environment variable updates.

### Step 5: Update npm to the Latest Version (Optional but Recommended)

While npm comes bundled with Node.js, it often receives updates more frequently. It's good practice to update npm to its very latest version independently. In your terminal or Command Prompt, run the command `npm install -g npm@latest`. The `-g` flag ensures it's installed globally, making the latest version available system-wide. This step keeps your package manager up-to-date with new features and bug fixes.

> 💡 **Tip:** After updating npm, run `npm -v` again to confirm that you are now using the most recent version.

### Step 6: Start Using npm for Your Projects

With Node.js and npm successfully installed, you're ready to begin managing JavaScript packages. You can navigate to a project directory and use `npm init` to create a `package.json` file, which tracks your project's dependencies. To install a package, simply use `npm install <package-name>`, and npm will handle downloading and managing it for your project.

> 💡 **Tip:** Explore the npm documentation to learn more about commands like `npm run`, `npm uninstall`, and `npm audit` for efficient project management.


## Tips & Tricks

- Consider using `nvm` (Node Version Manager) for macOS/Linux or `nvm-windows` for Windows if you need to switch between different Node.js versions for various projects.
- Always prefer installing the LTS (Long Term Support) version of Node.js for production environments due to its stability and longer maintenance period.
- If you encounter issues with package installations, try clearing your npm cache with `npm cache clean --force` and then retrying the installation.

## Warnings

- ⚠️ Be cautious when running `npm install -g` for global packages. Always ensure you trust the package source, as global installations can affect your entire system. If you encounter permission errors on macOS/Linux, avoid using `sudo` directly for global npm installs without understanding the implications; consider fixing npm's permissions or using nvm instead.

## Frequently Asked Questions

**How to install npm in Windows?**

The easiest way to install npm in Windows is by downloading and running the official Node.js installer from nodejs.org. npm is bundled with Node.js, so once Node.js is installed, npm will also be available on your system.

**How to install npm on Mac?**

To install npm on a Mac, download the macOS installer from the official Node.js website (nodejs.org) and follow the installation wizard. Alternatively, you can use Homebrew with `brew install node` for a convenient command-line installation.

**How to install npm on Ubuntu?**

On Ubuntu, you can install npm by first adding the NodeSource repository for the latest Node.js versions, then using your package manager. The commands typically involve `curl -fsSL https://deb.nodesource.com/setup_lts.x | sudo -E bash -` followed by `sudo apt-get install -y nodejs`.

**What is npm and why do I need it?**

npm (Node Package Manager) is the default package manager for Node.js. It allows developers to easily share and reuse code, manage project dependencies, and automate tasks. You need it to install, update, and manage JavaScript libraries and tools for your projects.

**Can I install npm without Node.js?**

While it's technically possible to install npm separately, it's not recommended. npm is designed to work hand-in-hand with Node.js, and the easiest and most stable method is to install Node.js, which comes bundled with npm.

**How do I update npm to the latest version?**

You can update npm to its latest version by running the command `npm install -g npm@latest` in your terminal or Command Prompt. The `-g` flag ensures a global update, making the newest npm version available across your system.

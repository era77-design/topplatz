Installing npm (Node Package Manager) is typically done by installing Node.js, as npm is bundled with it. This guide will walk you through the process of getting Node.js and npm set up on your system, enabling you to manage JavaScript packages for your projects. It's an essential tool for modern web development.

## What You Need

- Computer (Windows, macOS, or Linux)
- Internet connection
- Administrator or sudo privileges

## Steps

### Step 1: Understand Node.js and npm

Before you begin, it's important to know that npm is the default package manager for Node.js. This means that when you install Node.js, npm is automatically installed alongside it. Node.js is a JavaScript runtime environment that allows you to run JavaScript code outside of a web browser, making it crucial for backend development and build tools. Understanding this relationship simplifies the installation process significantly.

### Step 2: Download the Node.js Installer

The easiest and most recommended way to install npm is by downloading the Node.js installer from the official website. Visit nodejs.org and you will typically see two download options: an LTS (Long Term Support) version and a Current version. For most users, the LTS version is recommended as it's stable and well-supported. Download the appropriate installer for your operating system (Windows, macOS, or Linux).

> 💡 **Tip:** Always download Node.js from the official website to ensure you get a legitimate and secure version.

### Step 3: Run the Node.js Installer

Once the installer file has finished downloading, locate it and run it. On Windows, this will be an .msi file; on macOS, it will be a .pkg file. Follow the prompts in the installation wizard, accepting the license agreement and choosing the default installation options. The installer will automatically add Node.js and npm to your system's PATH, making them accessible from your command line. For a more detailed walkthrough, refer to [How to Install npm: A Simple Step-by-Step Guide](/en/how-to-install-npm-step-by-step).

### Step 4: Verify Node.js and npm Installation

After the installation is complete, it's crucial to verify that both Node.js and npm have been installed correctly. Open your terminal or command prompt and type `node -v` and press Enter. You should see the installed Node.js version. Then, type `npm -v` and press Enter. This will display the npm version. If both commands return version numbers, your installation was successful. If not, you may need to restart your terminal or check your system's PATH environment variables.

### Step 5: Update npm to the Latest Version (Optional)

While npm is installed with Node.js, it often receives updates more frequently than Node.js itself. It's a good practice to ensure you're running the latest version of npm. To update npm, open your terminal or command prompt and run the command: `npm install -g npm@latest`. The `-g` flag ensures that npm is installed globally, making it available system-wide. This command will download and install the newest version of npm. For a quicker overview, see [How to Install npm: A Quick Guide for Developers](/en/how-to-install-npm-quick-guide).

### Step 6: Test Your npm Installation

To confirm your npm installation is fully functional, you can try initializing a new project or installing a simple package. Navigate to a new directory in your terminal and run `npm init -y` to create a new `package.json` file. Then, try installing a common package like `lodash` by typing `npm install lodash`. If these commands execute without errors and create a `node_modules` folder with `lodash` inside, your npm setup is ready for development.


## Tips & Tricks

- Consider using a version manager like `nvm` (Node Version Manager) for macOS/Linux or `nvm-windows` for Windows if you need to switch between different Node.js and npm versions for various projects.
- Always run `npm update` within your project directory regularly to keep your project's dependencies up to date.
- If you encounter permission errors on macOS or Linux, you might need to use `sudo` before your npm commands (e.g., `sudo npm install -g <package>`), but be cautious with `sudo`.

## Warnings

- ⚠️ Be careful when running `npm install` in an unknown project, especially if it's from an untrusted source, as packages can contain malicious code.
- ⚠️ Avoid installing Node.js and npm through unofficial channels to prevent security vulnerabilities or compatibility issues.

## Frequently Asked Questions

**What is npm and why do I need it?**

npm (Node Package Manager) is the default package manager for Node.js. It allows developers to easily install, share, and manage project dependencies (libraries and tools) written in JavaScript. You need it to access a vast ecosystem of open-source packages that streamline development.

**How to install npm in Windows?**

To install npm in Windows, download and run the Node.js .msi installer from nodejs.org. The installer will automatically include npm and configure your system's PATH. After installation, open Command Prompt and type `npm -v` to verify.

**How to install npm on Mac?**

On Mac, the simplest way to install npm is by downloading and running the Node.js .pkg installer from nodejs.org. Alternatively, you can use Homebrew with `brew install node` or a version manager like `nvm`. Verify by typing `npm -v` in your terminal.

**How to install npm on Ubuntu?**

To install npm on Ubuntu, you can use the official Node.js installer or your system's package manager. For a recent version, use NodeSource's PPA: `curl -fsSL https://deb.nodesource.com/setup_lts.x | sudo -E bash -` followed by `sudo apt-get install -y nodejs`. Verify with `npm -v`.

**How can I verify if npm is installed correctly?**

Open your terminal or command prompt and type `npm -v` (and `node -v`). If both commands return a version number without errors, then npm and Node.js are installed and configured correctly on your system.

**Can I install npm without Node.js?**

While it's technically possible to install npm separately, it's not recommended or common practice. npm is tightly integrated with Node.js and relies on its runtime environment. The standard and most stable method is to install Node.js, which bundles npm automatically.

**How do I update npm to the latest version?**

You can update npm to its latest version by running the command `npm install -g npm@latest` in your terminal or command prompt. The `-g` flag ensures it's updated globally across your system. This keeps your package manager up-to-date independently of your Node.js version.

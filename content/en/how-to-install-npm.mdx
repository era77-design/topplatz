Installing npm, the Node Package Manager, is essential for JavaScript development, allowing you to manage project dependencies and run powerful development tools. The easiest way to install npm is by first installing Node.js, which bundles npm automatically. For a more in-depth look across all systems, refer to our [How to Install npm: A Step-by-Step Guide for All OS](/en/how-to-install-npm).

## What You Need

- Internet connection
- Administrative privileges
- Web browser
- Terminal or Command Prompt

## Steps

### Step 1: Check for Existing Node.js and npm Installation

Before proceeding, it's a good practice to check if Node.js and npm are already installed on your system. Open your terminal (Command Prompt on Windows, Terminal on macOS/Linux) and type `node -v` then press Enter. Next, type `npm -v` and press Enter. If you see version numbers, they are installed. If not, or if the versions are very old, you can proceed with a fresh installation or update.

### Step 2: Download the Node.js Installer

npm is bundled with Node.js, so the primary step is to install Node.js. Visit the official Node.js website at `nodejs.org` in your web browser. You'll typically see two download options: the LTS (Long Term Support) version and the Current version. For most users, the LTS version is recommended as it's more stable and thoroughly tested. Click on the LTS version to download the appropriate installer for your operating system (Windows, macOS, or Linux).

### Step 3: Run the Node.js Installation Wizard

Once the installer file has finished downloading, locate it in your downloads folder and double-click to run it. Follow the prompts in the installation wizard. For most users, accepting the default installation settings is perfectly fine. Ensure that the 'npm package manager' component is selected for installation, which it usually is by default. Agree to the license terms and click through until the installation is complete.

### Step 4: Verify the Installation

After the installation wizard completes, it's crucial to verify that both Node.js and npm have been successfully installed and are accessible from your system's PATH. Close and reopen your terminal or command prompt to ensure the new PATH variables are loaded. Then, run `node -v` and `npm -v` again. You should now see the installed version numbers, confirming that both Node.js and npm are ready for use.

### Step 5: Update npm to the Latest Version (Recommended)

While npm is installed with Node.js, the bundled version might not always be the absolute latest. It's a good practice to update npm itself to ensure you have the newest features and bug fixes. In your terminal, run the command `npm install -g npm@latest`. The `-g` flag ensures that npm is updated globally, making the latest version available across all your projects. This process might take a few moments depending on your internet speed.

### Step 6: Start Using npm

With npm successfully installed and updated, you're ready to start managing JavaScript packages. You can now use npm commands to initialize new projects, install dependencies, and run scripts. For example, to start a new project, navigate to your desired directory in the terminal and type `npm init`. To install a package, use `npm install <package-name>`. Congratulations, you've successfully installed npm!


## Tips & Tricks

- Always download Node.js from the official website (nodejs.org) to ensure authenticity and security.
- Periodically update npm using `npm install -g npm@latest` to benefit from the latest features and security patches.
- Understand the difference between `npm install <package>` (local installation) and `npm install -g <package>` (global installation) for managing dependencies effectively.

## Warnings

- ⚠️ When prompted for administrative privileges during installation, ensure you understand what you are installing. Only proceed if you trust the source.
- ⚠️ Avoid running `npm install` with `sudo` (on Linux/macOS) or as an Administrator (on Windows) unless specifically required, as it can lead to permission issues with globally installed packages later on.

## Frequently Asked Questions

**How to install npm on Mac?**

On a Mac, you can install npm by downloading the `.pkg` installer from nodejs.org and running it, similar to Windows. Alternatively, experienced users can use Homebrew with `brew install node` which also installs npm.

**How to install npm in Ubuntu?**

To install npm in Ubuntu, first update your package list with `sudo apt update`. Then, install Node.js and npm using `sudo apt install nodejs npm`. For the latest versions, consider using the NodeSource PPA.

**What is npm and why do I need it?**

npm (Node Package Manager) is the default package manager for Node.js, enabling developers to install, share, and manage reusable code packages. You need it to handle project dependencies, run development tools, and automate tasks in JavaScript and web development.

**How do I update npm after installation?**

You can update npm to its latest version by opening your terminal or command prompt and running the command `npm install -g npm@latest`. The `-g` flag ensures a global update.

**Can I install npm without Node.js?**

No, npm is inextricably bundled with Node.js. The standard and recommended way to get npm is by installing Node.js, which automatically includes the npm package manager.

Installing npm (Node Package Manager) is typically done by first installing Node.js, as npm comes bundled with it. This process ensures you have the necessary tools to manage JavaScript packages for your development projects. Follow these steps to get npm up and running on your system.

## What You Need

- Internet connection
- Command Line Interface (Terminal/PowerShell)
- Web browser

## Steps

### Step 1: 1. Check for Existing Node.js and npm Installation

Before proceeding with a new installation, it's good practice to check if Node.js and npm are already present on your system. Open your command line interface (Terminal on macOS/Linux, Command Prompt or PowerShell on Windows) and type `node -v` and then `npm -v`. If you see version numbers, they are installed. If you receive a 'command not found' error, you'll need to install them.

### Step 2: 2. Download the Node.js Installer

Since npm is distributed with Node.js, your primary step is to install Node.js itself. Visit the official Node.js website (nodejs.org) and download the LTS (Long Term Support) version, which is recommended for most users due to its stability. The website typically detects your operating system and suggests the appropriate installer package.

### Step 3: 3. Run the Node.js Installer

Once the installer file is downloaded, execute it. For Windows and macOS, this involves a straightforward graphical wizard where you'll accept the license, choose an installation directory, and click 'Next' through the prompts until completion. On Linux distributions like Ubuntu, you might add a NodeSource PPA and then use your package manager (e.g., `sudo apt install nodejs npm`). For more detailed OS-specific instructions, you can refer to our [How to Install npm: A Complete Guide for All OS](/en/how-to-install-npm-complete-guide).

### Step 4: 4. Verify Your Node.js and npm Installation

After the installation process is complete, it's crucial to close and reopen your command line interface. This ensures that the system's PATH variable is correctly updated to include the new Node.js and npm executables. Then, run `node -v` and `npm -v` again. You should now see the installed version numbers for both Node.js and npm, confirming a successful setup.

### Step 5: 5. Update npm to the Latest Version (Recommended)

Although npm comes bundled with Node.js, it might not always be the absolute latest version. To benefit from the newest features, bug fixes, and security updates, it's recommended to update npm. Open your command line and execute the command `npm install -g npm@latest`. The `-g` flag ensures that npm is installed globally, making the updated version available across your entire system.

### Step 6: 6. Test npm by Installing a Global Package (Optional)

To confirm that npm is fully functional and correctly configured, you can try installing a small, globally available package. For example, type `npm install -g http-server` to install a simple HTTP server. After the installation completes, you can verify it by typing `http-server -h` to display its help message, indicating that npm successfully installed and linked the package.


## Tips & Tricks

- Always prefer the LTS (Long Term Support) version of Node.js for new projects, as it offers the best stability and long-term maintenance.
- Understand the distinction between global (`-g`) and local npm package installations. Global packages are for tools used across projects, while local packages are dependencies specific to a single project.
- If you encounter network-related errors during installation or package downloads, check your internet connection and any firewall or proxy settings that might be interfering with npm's access.

## Warnings

- ⚠️ Avoid running npm commands with `sudo` (on Linux/macOS) or as an Administrator (on Windows) unless absolutely necessary. Improper permissions can lead to security vulnerabilities or issues with future package installations. If you face permission errors, consider fixing your npm directory permissions instead.

## Frequently Asked Questions

**How do I install npm?**

You install npm by first installing Node.js, as npm is automatically bundled with the Node.js installation package. Visit nodejs.org, download the recommended LTS installer for your operating system, and follow the installation wizard. After completing the setup, verify the installation by running `npm -v` in your terminal.

**How to install npm in Windows?**

To install npm on Windows, download the Windows installer (MSI file) for the LTS version from nodejs.org. Run the `.msi` file and follow the step-by-step instructions in the installation wizard. npm will be installed alongside Node.js. It's important to restart your Command Prompt or PowerShell after installation to ensure the PATH variable is updated.

**How to install npm on Mac?**

On a Mac, you can install npm by downloading the macOS installer (.pkg file) from nodejs.org (LTS version) and running it, following the installation prompts. Alternatively, a popular method is using Homebrew; simply run `brew install node` in your terminal, which will install both Node.js and npm. Verify with `npm -v`.

**How to install npm on Ubuntu?**

To install npm on Ubuntu, the recommended approach is to use the NodeSource PPA for the latest stable versions. First, update your package list, then add the NodeSource PPA, and finally install Node.js and npm using `sudo apt install nodejs`. This method ensures you get a recent and well-maintained version.

**What if npm is not recognized after installation?**

If npm is not recognized, first ensure you have closed and reopened your terminal or command prompt after the installation to refresh the system's PATH environment variable. If the issue persists, verify that Node.js was installed correctly and check your system's PATH settings to confirm the Node.js installation directory is included.

**Do I need to install Node.js separately from npm?**

No, you do not need to install Node.js and npm separately. When you download and install Node.js from its official website (nodejs.org), npm is automatically included and installed alongside it. This integrated approach simplifies the setup process, providing both essential tools together for managing JavaScript packages.

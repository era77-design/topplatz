npm, or Node Package Manager, is an essential command-line tool for JavaScript development, allowing you to manage packages and dependencies for your projects. Installing npm typically involves installing Node.js, as npm comes bundled with it. This guide will walk you through the straightforward process on various operating systems, ensuring you're ready to build and manage your applications.

## What You Need

- Computer with internet access
- Administrator or root privileges
- Terminal (macOS/Linux) or Command Prompt/PowerShell (Windows)

## Steps

### Step 1: 1. Check for Existing Node.js and npm Installation

Before proceeding, it's good practice to check if Node.js and npm are already installed on your system. Open your terminal or command prompt and type `node -v` and then `npm -v`. If versions are displayed, they are installed. If you see 'command not found' errors, you'll need to install them.

### Step 2: 2. Download the Node.js Installer

The simplest and most recommended way to install npm is by downloading the Node.js installer from the official website (nodejs.org). Visit the site and choose the 'LTS' (Long Term Support) version, which is stable and recommended for most users. The website will automatically detect your operating system and suggest the appropriate installer (Windows Installer, macOS Installer, or source code/binary for Linux).

### Step 3: 3. Run the Node.js Installer

Once the download is complete, locate the installer file (e.g., `.msi` for Windows, `.pkg` for macOS) and run it. Follow the on-screen prompts, accepting the license agreement, choosing the default installation location, and ensuring that 'Node.js runtime' and 'npm package manager' components are selected for installation. Administrator privileges will be required to complete this step.

### Step 4: 4. Verify the Installation

After the installation finishes, close and reopen your terminal or command prompt to ensure that your system's PATH variable is updated. Then, run `node -v` and `npm -v` again. You should now see the version numbers for both Node.js and npm, confirming a successful installation. If you encounter issues, refer to our [How to Install npm: A Comprehensive Guide for All OS](/en/how-to-install-npm) for detailed troubleshooting.

### Step 5: 5. Update npm to the Latest Version (Recommended)

Although npm comes bundled with Node.js, it's often a slightly older version. To ensure you have the latest features and security updates, it's a good idea to update npm itself. In your terminal, run the command `npm install -g npm@latest`. The `-g` flag ensures npm is installed globally, making it accessible from any directory.

### Step 6: 6. Test npm Installation with a Simple Package

To confirm that npm is fully functional, you can try installing a simple global package. A common test is `npm install -g express-generator`. This command will download and install the Express application generator. If it completes without errors, your npm installation is working correctly and ready for your development projects.


## Tips & Tricks

- Consider using a Node Version Manager (like NVM for macOS/Linux or NVM-Windows) if you need to switch between different Node.js and npm versions for various projects.
- Always run `npm install -g npm@latest` after a fresh Node.js installation to ensure you have the most up-to-date npm client.
- If you encounter 'command not found' errors after installation, verify that the Node.js installation directory is correctly added to your system's PATH environment variable.

## Warnings

- ⚠️ Always download installers from the official Node.js website (nodejs.org) to avoid malicious software.
- ⚠️ Be cautious when running commands with `sudo` (Linux/macOS) or as an administrator (Windows); ensure you understand what the command does before execution.

## Frequently Asked Questions

**What is npm and why do I need to install it?**

npm (Node Package Manager) is the default package manager for Node.js, used to install, share, and manage project dependencies. You need to install it to easily add libraries, frameworks, and tools to your JavaScript projects, streamlining development workflows.

**How to install npm in Windows?**

To install npm in Windows, download the official Node.js Windows Installer (.msi) from nodejs.org. Run the installer and follow the wizard, ensuring npm is selected as a component. npm is bundled with Node.js, so installing Node.js automatically installs npm.

**How to install npm on Mac?**

Installing npm on Mac involves downloading the Node.js macOS Installer (.pkg) from nodejs.org. Execute the installer and follow the steps. Alternatively, you can use Homebrew with `brew install node` which also installs npm. For a more detailed walkthrough, see [How to Install npm: Step-by-Step Guide for All OS](/en/how-to-install-npm-guide-all-os).

**How to install npm on Ubuntu?**

To install npm on Ubuntu, the recommended method is to use the NodeSource PPA for the latest versions, or `sudo apt install nodejs npm` for a stable version from the default repositories. After installation, verify with `node -v` and `npm -v`. Using a PPA ensures you get more recent updates.

**Can I install npm without Node.js?**

No, npm is inextricably bundled with Node.js. When you install Node.js, npm is automatically included as part of the installation process. There is no separate standalone installer for npm.

**How do I update npm after installation?**

To update npm to its latest version after installation, open your terminal or command prompt and run `npm install -g npm@latest`. This command will globally update your npm client to the newest available release.

**What if the 'npm' command is not found after installation?**

If 'npm' command is not found, it usually indicates that the Node.js installation directory is not correctly added to your system's PATH environment variable. Try restarting your terminal or computer, or manually add the Node.js installation path to your system's PATH settings.

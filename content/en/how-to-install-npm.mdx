Installing npm (Node Package Manager) is crucial for JavaScript development, as it allows you to manage and share packages. The easiest and most recommended way to install npm is by installing Node.js, which bundles npm automatically. This guide will walk you through the process for various operating systems.

## What You Need

- Computer with internet access
- Administrator/sudo privileges
- Terminal or Command Prompt

## Steps

### Step 1: Check for Existing Node.js and npm

Before starting, it's a good practice to check if Node.js and npm are already installed on your system. Open your terminal or command prompt and type `node -v` and then `npm -v`. If version numbers are returned, they are installed. Otherwise, you'll likely see a 'command not found' error, indicating you need to proceed with the installation.

> 💡 **Tip:** If you have an older version, consider uninstalling it or using a version manager like NVM for better control over Node.js and npm versions.

### Step 2: Download the Node.js Installer

The most straightforward way to [install npm](/en/how-to-install-npm-guide) is by installing Node.js, as npm is bundled with it. Visit the official Node.js website (nodejs.org) and download the recommended LTS (Long Term Support) version for your operating system (Windows, macOS, or Linux). The website typically auto-detects your OS and suggests the correct installer.

> 💡 **Tip:** Always choose the LTS version for stability unless you specifically need the latest experimental features from the Current version.

### Step 3: Install Node.js on Windows and macOS

Once the installer (a `.msi` file for Windows or a `.pkg` file for macOS) is downloaded, locate and run it. Follow the on-screen prompts, accepting the license agreement and default installation paths. Ensure that the 'npm package manager' component is selected, which it is by default. Complete the installation wizard to finish the process.

> 💡 **Tip:** You typically don't need to customize the installation path unless you have specific system requirements or multiple development environments.

### Step 4: Install Node.js on Linux (Ubuntu Example)

For Linux distributions like Ubuntu, you can install Node.js and npm using your system's package manager. First, ensure your package list is updated by running `sudo apt update`. Then, install Node.js and npm with `sudo apt install nodejs npm`. Alternatively, for more control over versions, consider using Node Version Manager (NVM), which allows easy switching between different Node.js installations.

> 💡 **Tip:** Using NVM (Node Version Manager) is highly recommended for developers who need to work with multiple Node.js and npm versions across different projects.

### Step 5: Verify the Installation

After the installation is complete, open a *new* terminal or command prompt window. Type `node -v` and press Enter to check the Node.js version. Then, type `npm -v` and press Enter to check the npm version. Both commands should display version numbers, confirming a successful [installation of npm](/en/how-to-install-npm-step-by-step-guide).

> 💡 **Tip:** If the commands are not found, try restarting your computer, or check your system's PATH environment variable to ensure Node.js is correctly added.

### Step 6: Update npm to the Latest Version (Optional)

While npm comes bundled with Node.js, it's often updated more frequently than Node.js itself. To ensure you have the latest features, bug fixes, and security patches, you can update npm separately. Open your terminal and run: `npm install -g npm@latest`. The `-g` flag ensures it's installed globally across your system.

> 💡 **Tip:** Regularly updating npm can prevent compatibility issues with newer packages and improve overall development workflow.


## Tips & Tricks

- Always download Node.js installers from the official nodejs.org website to ensure authenticity and security.
- Consider using a Node Version Manager (NVM) if you need to switch between different Node.js and npm versions for various projects.
- If you encounter permission errors during global package installations, try running the command with `sudo` (Linux/macOS) or as an Administrator (Windows).

## Warnings

- ⚠️ Ensure you have administrator or sudo privileges on your system to avoid permission errors during the installation process.
- ⚠️ Be cautious when installing packages or running scripts from unknown sources, as they could pose security risks to your system.

## Frequently Asked Questions

**How do I install npm?**

The easiest and most recommended way to install npm is by installing Node.js, as npm comes bundled with it. Simply download the Node.js installer from the official website (nodejs.org), run it, and follow the on-screen instructions for your operating system.

**How to install npm in Windows?**

To install npm in Windows, download the `.msi` installer from the official Node.js website. Run the installer, accept the default settings, and ensure the npm package manager component is selected during the installation process. Follow the prompts to complete the setup.

**How to install npm on Mac?**

To install npm on Mac, download the `.pkg` installer from the Node.js website (nodejs.org). Execute the installer and follow the prompts to complete the installation. Alternatively, experienced users can use Homebrew for a command-line-centric installation with more control.

**How to install npm on Ubuntu?**

To install npm on Ubuntu, open your terminal and first update your package list with `sudo apt update`. Then, install both Node.js and npm by running `sudo apt install nodejs npm`. This method uses Ubuntu's official repositories for installation.

**What is the best way to install npm?**

For most users, installing Node.js directly from its official website (nodejs.org) is the best and simplest method, as it includes npm by default. For developers needing to manage multiple Node.js versions, using a tool like NVM (Node Version Manager) is highly recommended for flexibility.

**Do I need to install Node.js separately?**

No, when you install Node.js using its official installer or most package managers, npm is automatically included as part of the installation. You typically don't need to perform a separate installation for npm after installing Node.js.

**How can I check if npm is installed?**

To check if npm is installed, open your terminal or command prompt and type `npm -v`. If npm is installed, it will display its version number. If not, you'll receive a 'command not found' error, indicating it needs to be installed.

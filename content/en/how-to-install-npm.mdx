To install npm, you typically install Node.js, which bundles npm by default. The recommended method is to download the official Node.js installer for your operating system (Windows, macOS, or Linux) and follow the installation prompts. This ensures you get a stable version of both Node.js and npm. For a more detailed guide covering all systems, refer to [How to Install npm: A Step-by-Step Guide for All OS](/en/how-to-install-npm).

## What You Need

- Computer with internet access
- Administrator privileges
- Web browser
- Terminal or Command Prompt

## Steps

### Step 1: Understand Node.js and npm

npm (Node Package Manager) is the default package manager for Node.js, a powerful JavaScript runtime. When you install Node.js, npm is usually installed alongside it. npm helps you manage project dependencies, install development tools, and share reusable code within the Node.js ecosystem.

### Step 2: Download the Node.js Installer

Visit the official Node.js website at `nodejs.org`. You'll typically see two recommended versions for your operating system: an LTS (Long Term Support) version and a Current version. For most users, the LTS version is recommended due to its stability. Download the appropriate installer file for Windows (.msi), macOS (.pkg), or refer to instructions for Linux distributions.

### Step 3: Install Node.js on Windows and macOS

Locate the downloaded installer file (e.g., `node-vX.Y.Z.msi` for Windows, `node-vX.Y.Z.pkg` for macOS) and double-click to run it. Follow the on-screen prompts, accepting the license agreement and default installation settings. Ensure the option to 'Add to PATH' is selected, as this makes Node.js and npm accessible from your terminal. You will likely need administrator privileges to complete the installation.

> 💡 **Tip:** During the installation process, ensure that 'Node.js runtime' and 'npm package manager' components are selected for installation.

### Step 4: Install Node.js on Linux (Debian/Ubuntu Example)

For Debian-based systems like Ubuntu, it's recommended to use NodeSource repositories for the latest stable versions. First, update your package list: `sudo apt update`. Then, install curl if you don't have it: `sudo apt install curl`. Add the NodeSource PPA and install Node.js by running: `curl -fsSL https://deb.nodesource.com/setup_lts.x | sudo -E bash -` followed by `sudo apt install nodejs`. This command fetches and installs Node.js along with npm.

> 💡 **Tip:** Replace `lts.x` in the `curl` command with a specific Node.js version (e.g., `node_18.x`) if you need an older LTS release.

### Step 5: Verify the Installation

After the installation is complete, open your terminal or command prompt. Type `node -v` and press Enter. This should display the installed Node.js version. Next, type `npm -v` and press Enter. This will show the installed npm version, confirming that both Node.js and npm are successfully installed and accessible in your system's PATH.

> 💡 **Tip:** If commands are not found, restart your terminal or computer, as environment variables might need to refresh.

### Step 6: Update npm to the Latest Version (Optional)

While npm comes bundled with Node.js, it often receives updates more frequently. To ensure you have the very latest version of npm, you can update it independently. Open your terminal and run the command: `npm install -g npm@latest`. This command globally installs the newest npm version available.

> 💡 **Tip:** The `-g` flag ensures npm is installed globally, making it available system-wide. You might need `sudo` on Linux/macOS if global permissions are restricted, but it's often better to fix permissions for your npm global directory.

### Step 7: Start Using npm

With npm successfully installed and verified, you're ready to start managing your JavaScript projects. You can now initialize new projects using `npm init`, install packages required for your project with `npm install <package-name>`, and run custom scripts defined in your `package.json` file. Explore the vast npm registry to find libraries and tools for your development needs.


## Tips & Tricks

- Consider using NVM (Node Version Manager) for Linux/macOS or `nvm-windows` if you need to switch between different Node.js and npm versions frequently for various projects.
- Regularly update Node.js and npm to benefit from the latest features, performance improvements, and security patches.
- When installing packages, use `npm install <package-name>` for local project dependencies and `npm install -g <package-name>` for global command-line tools.

## Warnings

- ⚠️ Always download Node.js installers from the official `nodejs.org` website to ensure authenticity and avoid security risks from unofficial sources.
- ⚠️ Be cautious when using `sudo` with `npm` commands on Linux/macOS for global installations. It's generally safer to configure npm to install global packages in a user-owned directory than to run `npm` as root.

## Frequently Asked Questions

**How do I install npm?**

npm is typically installed automatically when you install Node.js. The recommended method is to download the official Node.js installer from nodejs.org, which bundles npm, and follow the installation prompts for your operating system.

**How to install npm in Windows?**

On Windows, download the `.msi` installer from nodejs.org. Run the installer, accept the default settings, and follow the on-screen prompts. npm will be installed alongside Node.js, and will be added to your system's PATH.

**How to install npm on Mac?**

For macOS, download the `.pkg` installer from nodejs.org. Execute the installer and proceed through the installation steps, accepting defaults. Node.js and npm will be installed on your system, ready for use in the terminal.

**How to install npm on Ubuntu?**

On Ubuntu, the recommended way is to use NodeSource repositories for the latest versions. After updating your package list, use `curl -fsSL https://deb.nodesource.com/setup_lts.x | sudo -E bash -` followed by `sudo apt install nodejs` to install Node.js and npm.

**How do I verify if npm is installed correctly?**

Open your terminal or command prompt and type `npm -v`. If npm is installed correctly, it will display its version number. You can also check `node -v` for the Node.js version, confirming both are operational.

**What if I need a specific version of Node.js or npm?**

For managing multiple Node.js versions (and consequently different npm versions) on your system, consider using a Node Version Manager like `nvm` (Node Version Manager) for Linux/macOS or `nvm-windows` for Windows. These tools allow you to easily switch between versions.

**Can I install npm without Node.js?**

No, npm is intrinsically linked to Node.js. It functions as the package manager specifically designed for the Node.js runtime environment. Therefore, you must install Node.js to get npm.

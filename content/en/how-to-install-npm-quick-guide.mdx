Installing npm, the Node Package Manager, is essential for any JavaScript developer working with Node.js. It allows you to easily manage project dependencies, install tools, and share packages within your development environment. The most common and recommended way to get npm is by installing Node.js, as npm is automatically bundled with it.

## What You Need

- Computer with an internet connection
- Administrator/sudo privileges
- Command-line interface (CLI) or Terminal

## Steps

### Step 1: 1. Check for Existing Node.js and npm Installation

Before proceeding, it's good practice to check if Node.js and npm are already installed on your system. Open your command-line interface (CLI) or Terminal and run the following commands. If you see version numbers, you already have them installed; otherwise, you'll see an error message indicating they are not found.

> 💡 **Tip:** If you already have Node.js and npm, consider updating them to their latest stable versions for better performance and security.

### Step 2: 2. Choose an Installation Method

The simplest method to install npm is by installing Node.js, as npm comes bundled with it. You can download the official installer directly from the Node.js website, which is suitable for Windows and macOS. For Linux users, using your system's package manager is often more convenient. Another popular method, especially for managing multiple Node.js versions, is to use a Node Version Manager (NVM).

> 💡 **Tip:** For a more in-depth look at various installation methods and troubleshooting, consult [How to Install npm: A Complete Guide for All OS](/en/how-to-install-npm-complete-guide).

### Step 3: 3. Install Node.js (and npm) via Official Installer (Windows/macOS)

Visit the official Node.js website (nodejs.org) and download the recommended LTS (Long Term Support) version installer for your operating system. Run the downloaded installer and follow the on-screen prompts. Accept the default installation options, which include npm. Once the installation is complete, restart your terminal to ensure the new PATH variables are loaded.

> 💡 **Tip:** The LTS version is generally recommended for most users due to its stability and long-term support.

### Step 4: 4. Install Node.js (and npm) on Linux (e.g., Ubuntu)

For Debian-based systems like Ubuntu, you can use `apt` to install Node.js and npm. First, update your package list, then install Node.js. This command will typically install npm alongside Node.js. If `npm` is not installed automatically, you might need to install it separately using `sudo apt install npm`.

> 💡 **Tip:** Older Ubuntu versions might require adding a Node.js PPA (Personal Package Archive) to get the latest versions. Search for 'Node.js PPA Ubuntu' if the default `apt` package is outdated.

### Step 5: 5. Verify Your Installation

After the installation process is complete, open a new command-line interface or terminal window to verify that both Node.js and npm have been successfully installed. Run the `node -v` command to check the Node.js version and `npm -v` to check the npm version. Seeing version numbers confirms a successful installation.

> 💡 **Tip:** If you encounter 'command not found' errors, ensure your system's PATH variable includes the Node.js installation directory. Restarting your computer can sometimes resolve this.

### Step 6: 6. Update npm to the Latest Version (Optional but Recommended)

While npm comes bundled with Node.js, it's often updated more frequently. To ensure you're using the latest features and bug fixes, you can update npm separately. Use the following command to update npm to its newest version globally. This command ensures that your npm is always up-to-date, independent of your Node.js version.

> 💡 **Tip:** If you experience permission errors during the update, consider using `nvm` or fixing npm permissions on your system.


## Tips & Tricks

- Consider using a Node Version Manager (like NVM) if you need to work with multiple Node.js or npm versions on the same machine.
- Always refer to the official Node.js documentation for the most accurate and up-to-date installation instructions specific to your operating system.
- If you face issues, try clearing the npm cache with `npm cache clean --force` before re-attempting an installation or update.

## Warnings

- ⚠️ Avoid using `sudo npm install -g` unless absolutely necessary, as it can lead to permission issues. It's often better to fix npm permissions or use NVM.
- ⚠️ Be cautious when installing packages from untrusted sources, as they could contain malicious code. Always verify the source and reputation of packages.

## Frequently Asked Questions

**How to install npm in Windows?**

The easiest way to install npm in Windows is by downloading and running the official Node.js installer from nodejs.org. This installer includes npm by default. Follow the on-screen prompts, accept the default settings, and restart your command prompt after installation.

**How to install npm on Mac?**

To install npm on Mac, download the official Node.js installer (.pkg file) from nodejs.org and run it. Alternatively, you can use Homebrew by running `brew install node` in your terminal, which will install both Node.js and npm.

**How to install npm on Ubuntu?**

To install npm on Ubuntu, first update your package list with `sudo apt update`, then install Node.js using `sudo apt install nodejs`. This typically includes npm. If not, install npm separately with `sudo apt install npm`.

**What is npm and why do I need it?**

npm (Node Package Manager) is the default package manager for Node.js. You need it to install, share, and manage project dependencies and tools for your JavaScript development, especially when working with Node.js applications.

**How do I update npm to the latest version?**

You can update npm to its latest version by running the command `npm install -g npm@latest` in your terminal. This command updates npm globally, ensuring you have the most current features and bug fixes.

**What is the best way to install npm?**

For most users, installing Node.js via its official installer (from nodejs.org) is the best way to get npm, as it's bundled together. For more advanced users who need to manage multiple Node.js versions, using a Node Version Manager (like NVM) is highly recommended.

**How can I check if npm is installed correctly?**

To check if npm is installed correctly, open your terminal or command prompt and type `npm -v`. If npm is installed and configured correctly, it will display its version number. You can also check Node.js with `node -v`.

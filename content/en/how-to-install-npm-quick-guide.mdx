To install npm, the Node Package Manager, you primarily install Node.js, which bundles npm automatically. This process involves downloading the appropriate Node.js installer for your operating system and running it, followed by a quick verification in your terminal. This guide will walk you through the steps to get npm up and running on your system.

## What You Need

- Computer (Windows, macOS, or Linux)
- Stable internet connection
- Administrator privileges

## Steps

### Step 1: Check for Existing Node.js and npm Installation

Before starting, verify if Node.js and npm are already installed on your system. Open your terminal or command prompt and run `node -v` and `npm -v`. If version numbers are displayed, you might only need to update them. If not, proceed with the installation.

### Step 2: Download the Node.js Installer

Visit the official Node.js website (nodejs.org) and download the recommended LTS (Long Term Support) version for your operating system. The Node.js installer package includes npm automatically, so you don't need to download it separately. This is the most straightforward way to begin [installing npm](/en/how-to-install-npm-essential-guide).

### Step 3: Run the Node.js Installer

Locate the downloaded installer file (e.g., `.msi` for Windows, `.pkg` for macOS, or use package managers for Linux). Double-click to run it and follow the on-screen prompts. Ensure that both "Node.js runtime" and "npm package manager" components are selected during the installation process.

### Step 4: Complete the Installation Process

Accept the license agreement, choose your installation destination, and click through the prompts until the installation is complete. For most users, accepting the default settings is recommended. You may be prompted to restart your computer to finalize the installation and update system paths correctly, which is a good practice.

### Step 5: Verify the Installation

Open a *new* terminal or command prompt window (important for path updates to take effect). Run `node -v` and `npm -v` again. You should now see the installed version numbers, confirming that Node.js and npm are successfully installed on your system and ready for use. For more detailed, OS-specific instructions, see [How to Install npm: Step-by-Step for Windows, Mac & Linux](/en/how-to-install-npm-windows-mac-linux).

### Step 6: Update npm (Optional but Recommended)

Although npm comes bundled with Node.js, it's often updated independently. To ensure you're using the latest stable version of npm, run the command `npm install -g npm@latest` in your terminal. This global update ensures you have access to the newest features, performance improvements, and security patches.


## Tips & Tricks

- Always download Node.js from the official website to ensure authenticity and security.
- Regularly update npm to benefit from the latest features, bug fixes, and security enhancements.
- If you encounter path issues, restarting your computer or your terminal application can often resolve them.

## Warnings

- ⚠️ Always ensure you have administrator privileges when running the installer, as it modifies system files.
- ⚠️ Be cautious when installing packages globally, as they can affect all projects on your system.

## Frequently Asked Questions

**How do I install npm in Windows?**

To install npm in Windows, download the Windows installer (.msi) from the official Node.js website (nodejs.org). Run the installer, following the prompts, and npm will be automatically included with Node.js. After installation, open a new command prompt and verify with `npm -v`.

**How do I install npm on Mac?**

Installing npm on Mac involves downloading the macOS installer (.pkg) from the Node.js website. Execute the installer, accepting the default settings, which will install both Node.js and npm. Verify the installation by opening a new terminal window and running `npm -v`.

**How do I install npm on Ubuntu?**

To install npm on Ubuntu, the recommended method is to use NodeSource repositories to get the latest LTS version of Node.js, which includes npm. Alternatively, you can install it via `sudo apt install nodejs npm` after updating your package lists. Always verify the installation with `npm -v` in your terminal.

**How do I check if npm is already installed on my system?**

You can easily check for an existing npm installation by opening your terminal or command prompt. Type `npm -v` and press Enter. If npm is installed, its version number will be displayed; otherwise, you'll receive an error message.

**What is npm, and why do I need it?**

npm stands for Node Package Manager, and it's the default package manager for Node.js. You need it to install, manage, and share JavaScript packages or "modules" for your projects, making development faster and more efficient. It also helps manage project dependencies.

**Should I install the LTS or Current version of Node.js?**

For most users and production environments, it is highly recommended to install the LTS (Long Term Support) version of Node.js. LTS versions are stable, well-tested, and receive active maintenance for an extended period. The "Current" version contains the latest features but might be less stable.
